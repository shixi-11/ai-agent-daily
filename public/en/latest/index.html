RISC Machine Primer

RISC = the four systems of a production-grade agent or robot

A production-grade agent needs more than a brain. It must keep operating, survive failure, resist overreach, and participate in real organizational workflows.

The industry has delivered an excellent brain, but a production-grade agent also needs a body, an immune system, and a social layer.ALUX is building that complete machine.
R | Resilience — BodyDurable execution, fault tolerance, recovery, and horizontal scale. Without a resilient body, one failure can erase progress.
I | Intelligence — BrainModel loops, memory, tools, and orchestration. This system determines how an agent reasons, uses tools, and completes complex work.
S | Security — Immune SystemObject-capability security, policy-based approvals, rollback, and audit. Without an immune system, recovery and connectivity expand the blast radius.
C | Connectivity — Social LayerCross-company authorization, neutral substrate, session types, and ecosystem connectors. Without a social interface, an agent remains confined to one product.

AI Agent Radar

Runtime controls

Platforms Make Assurances Inspectable

Shirudo requires approval and signatures, EFS identifies who holds copies, and Vercel calls for public audits. Each control addresses a distinct boundary.

Context

Assistants Separate Reading From Acting

Search’s Wallet connection is read-only, Qwen separates conversation from tasks, and Gemini narrows file input. More context does not automatically grant more authority.

Scientific checks

Scientific Agents Need Different Verification Tools

Lean checks quantum proofs, Spark supports local simulations, and AVF requires a matching processor and runtime fork. Mathematics, simulation, and integration answer different questions.

New Features Worth Watching

02Search Personal IntelligenceUnited StatesPublished 2026-11-23 / Observed 2026-11-24Primary source

Google Search Adds Read-Only Spending Context

What changed: Google began rolling out a Wallet connection for Personal Intelligence in AI Mode. Users opt in to receive answers informed by spending and card benefits. Drive documents and Gemini chat context are due in the coming weeks, not all available today. Users can enable or disable each connection and manage search personalization.

Why it matters: Personal search now draws on authorized account context as well as queries and public information. Reading that context is distinct from authority to act on funds.

Who should care: Teams designing personal assistants, connected search, and account permissions.

Try it

Check Connected Apps in Search Personalization on an eligible account. Review available connections and revocation before trying nonsensitive examples.

Keep in mind

Wallet is rolling out; Drive and Gemini connections follow in the coming weeks. Google says Wallet access is read-only and cannot move or invest money. We have not tested it.

05ScaleDown Extract-1United StatesPublished 2026-11-23 / Observed 2026-11-24Primary source

Brief: AI Gateway Supports Extraction Models

What changed: AI Gateway now offers extraction models, starting with ScaleDown Extract-1. It returns text fields or lists from text, images, and PDFs. For text inputs, results can include character offsets; missing values are null.

Why it matters: Extraction gains a dedicated interface rather than relying only on general chat prompts.

Who should care: Developers processing invoices, contracts, and forms.

Try it

Try public samples using experimental_extract in an up-to-date AI SDK.

Keep in mind

Currently available through the AI SDK only. Confidence scores are not calibrated accuracy guarantees; we have not tested it.

09Qwen-Audio-3.1-LiveChinaPublished 2026-11-23 / Observed 2026-11-24Primary source

Qwen Live Keeps Talking While Background Tasks Run

What changed: QwenCloud released qwen-audio-3.1-live for real-time voice conversations. The frontend can keep receiving audio and responding while an application or background model works, then speak the result. Documentation offers platform Responses and application-managed delegation modes, with results linked by delegation identifiers.

Why it matters: Separating conversation from task execution avoids silence during a lookup or calculation. Fluent conversation still does not prove the backend succeeded; applications must validate results and prevent duplicate tool execution.

Who should care: Teams building voice support, real-time assistants, and background delegation.

Try it

Validate audio transport first, then use a fixed inventory response to test delegation. Check timeouts, duplicate events, and spoken-result matching before connecting real services.

Keep in mind

This is a hosted model, not open weights. Some documentation examples use inconsistent model identifiers; verify the supported identifier and access. We have not tested API latency or success rates.

10Claude EFSUnited StatesPublished 2026-11-23 / Observed 2026-11-24Primary source

Claude EFS Places Sealed Safety Data in Customer-Owned Storage

What changed: Anthropic launched Enterprise Frontier Safeguards in beta on Claude Platform and its Anthropic-managed AWS and Google Cloud offerings. Eligible organizations receive ZDR: Anthropic does not retain prompts or responses, while encrypted Sealed Safety Data goes to a customer-owned cloud bucket. New webhooks report failures and recoveries in daily storage checks.

Why it matters: Retention boundaries include who holds a copy and how configuration failures surface. Customer-owned storage and Vercel’s independent-audit approach provide different layers of assurance.

Who should care: Platform teams evaluating frontier Claude data controls, enterprise storage, and monitoring.

Try it

Check eligibility and bucket setup. Map access and deletion for encrypted copies, then test failure and recovery notifications before using business data.

Keep in mind

This is a beta for eligible organizations, not universal access. Workspaces using Anthropic-managed storage are not on EFS. ZDR does not mean no encrypted copy exists in the customer bucket.

12Gemini File SlicingUnited StatesPublished 2026-11-18 / Observed 2026-11-24Primary source

Brief: Gemini Selects File Pages, Cells, and Time Ranges

What changed: Gemini API added multimodal file slicing in prompts and function responses. Select pages, worksheet tabs, cell ranges, audio/video intervals, or layers such as images, extracted text, formulas, and transcripts instead of processing the whole file.

Why it matters: Agents can narrow file scope and billable content before processing.

Who should care: Teams building document, spreadsheet, and long-media assistants.

Try it

Compare whole-file and selected-range input on public samples; inspect citations and billing.

Keep in mind

This is the November 18 slicing update, not the earlier launch of Office support. We have not tested it.

13AudioVisual FlamingoUnited StatesPublished 2026-11-15 / Observed 2026-11-24Primary source

AVF Converts Existing Audiovisual Weights to Transformers Format

What changed: NVIDIA converted AudioVisual Flamingo to the Transformers layout on November 15 without changing weight values. Configurations, the processor, and chat template were regenerated, followed by updated inference API examples the next day. The model interleaves synchronized audio and video segments for text answers; the checkpoint does not include speech synthesis.

Why it matters: Running an openly available model requires matching processors, templates, and backends as well as weights. Format conversion can simplify integration without retraining the model or establishing support in an upstream stable release.

Who should care: Developers researching long-video understanding, audiovisual alignment, and local multimodal inference.

Try it

Use the model card’s Transformers fork and torchcodec dependencies, pin the revision, and test public clips that require both sound and images. Inspect temporal alignment and resource use.

Keep in mind

Noncommercial research only under NVIDIA’s OneWay Noncommercial License, not OSI open source. The documented fork and FFmpeg dependencies are required. This is a new format for existing weights, not a model launch today.

01ShirudoUnited StatesPublished 2026-11-23 / Observed 2026-11-24Primary sourceGitHub Stars 287License BSD-2-Clause

Shirudo Adds Live Shields to Running Linux Systems

What changed: OpenAI and Cisco launched Shirudo, an eBPF runtime for temporary protection on running Linux systems. Operators can observe effects before approving enforcement. Shields are signed, and TPM-backed records track loading and removal. In a controlled test, a Codex-generated input check blocked a Java4Shell exploit attempt without restarting Elasticsearch.

Why it matters: Temporary, testable shields address the gap between disclosure and patch deployment. Blocking one exploit does not repair the underlying vulnerability or validate every legitimate workload.

Who should care: Linux operators and teams developing eBPF defenses or security agents.

Try it

Use the official VM quickstart in isolation to sign, load, and verify a test shield. Check legitimate requests and recovery behavior.

Keep in mind

Pre-release software. Production targets require kernel patches and TPM 2.0. The runtime uses BSD-2-Clause; BPF programs have BSD/GPL dual licensing. We have not deployed it. Shields do not replace patches.

03Formal Quantum ComputationUnited StatesPublished 2026-11-23 / Observed 2026-11-24Primary sourceGitHub Stars 32License Apache-2.0

Gemini Teams Share Quantum Improvements After Proof Checks

What changed: DeepMind described independent Gemini 4 teams searching for quantum algorithm improvements. Lean proofs precede entry into a shared notebook; teams exchange ideas every four hours. The Lean library, specifications, and verified solutions are public. For a fusion-related calculation, the authors report an 11.8-fold cost reduction. It uses 4,338 error-corrected qubits, down from 5,650.

Why it matters: Proof checks filter ideas before teams share them. Mathematical correctness does not turn estimated resource reductions into measured speedups on current quantum hardware.

Who should care: Researchers working on scientific agents, multi-team search, formal verification, and quantum algorithms.

Try it

Read the paper’s cost definition, then inspect specifications and verified programs on the discoveries branch. Build a small example with the pinned toolchain; distinguish modeled resources from hardware costs.

Keep in mind

These workloads still exceed resources expected in early error-corrected quantum computers. Results are author-reported, not our tests; proofs are not hardware experiments.

11AlterGlobalPublished 2026-11-22 / Observed 2026-11-24Primary sourceGitHub Stars 1License MIT

Brief: Describe a Website Change and Keep It

What changed: Alter v0.2.0 is publicly released. Ask it to hide a sidebar or create a dark mode, preview the change, and save it for later visits. Reviewed, approved one-time scripts can also export articles or tables.

Why it matters: Users can save and undo changes instead of repeatedly adapting to an awkward website layout.

Who should care: Readers and developers of browser tools.

Try it

Load the extension manually in Chrome 138 or later and start with a public page.

Keep in mind

Not in the Chrome Web Store; requires your own Anthropic service. Review scripts before approval. We have not installed it.

Global Technology and Market Watch

04Audited ZDRUnited StatesPublished 2026-11-23 / Observed 2026-11-24Primary source

Vercel Introduces Independent Audits for Zero-Retention Claims

What changed: Vercel announced an Audited ZDR tier. Providers qualify only after an independent firm examines code, infrastructure, and live traffic and publishes a report. Baseten, Modal, and Wafer have begun audits, with reports expected by December 8. Canary prompts containing unique URLs add a signal for access outside the inference path.

Why it matters: Public evidence can strengthen contractual retention promises. Routing and failover must respect the same boundaries. Audits and monitoring complement each other; neither guarantees that a future incident is impossible.

Who should care: Platform and procurement teams handling proprietary code, customer records, or regulated data.

Try it

Read the scope and exception rules. Once reports appear, check covered models, tools, and endpoints. Distinguish stated ZDR from completed audits.

Keep in mind

Launch partners are still undergoing audits; they have not all earned the Audited ZDR designation. Canaries cannot detect data written to disk and never read. We have not independently tested these controls.

06Richpanel Boss AIAsia-Pacific and OceaniaPublished 2026-11-23 / Observed 2026-11-24Primary source

Brief: One Agent Configures Tools for Customer-Support Agents

What changed: OpenAI published a Richpanel case study. Boss AI uses GPT-6 Astra and GPT-6.1 Sol to write procedures and define tool calls; frontline conversations use models including GPT-6 Luna to balance cost and capability.

Why it matters: Automation investment extends to setup and integration, not just individual answers.

Who should care: Teams building support agents or deployment services.

Try it

Compare the setup/frontline split with your integration and human-handoff costs.

Keep in mind

Roughly 300 deployments were reported as of an October 2026 interview. The claim of 50% automation within 30 days is customer-reported, not independently evaluated.

07DGX Spark HPC Developer KitUnited StatesPublished 2026-11-16 / Observed 2026-11-24Primary source

Brief: Four DGX Sparks Form a Desktop Research Cluster

What changed: NVIDIA introduced a four-node DGX Spark HPC Developer Kit. ConnectX-7 links the nodes in a ring without an extra switch. The cluster provides 512GB of combined memory and 16TB of storage for local multinode research development.

Why it matters: Desktop debugging can expose communication and data-placement issues before a larger cluster run.

Who should care: Researchers building scientific simulations and multinode AI workflows.

Try it

Review the topology and example workloads, then price systems and cables.

Keep in mind

Hardware is on sale; the HPC SDK playbook is still forthcoming. Combined memory is not memory available on one node.

08NVIDIA Rubin HPCUnited StatesPublished 2026-11-16 / Observed 2026-11-24Primary source

Brief: Rubin HPC Targets Simulations Used by Scientific Agents

What changed: NVIDIA announced Rubin HPC for scientific simulation and analytics. The design includes more than 50,000 CUDA cores, sparse-data acceleration, and seventh-generation NVLink. Availability is expected in 2028.

Why it matters: Agents exploring more candidates also increase demand for simulations that test those ideas.

Who should care: Teams planning scientific compute and agent toolchains.

Try it

Compare the design with your sparse-matrix and data-movement bottlenecks.

Keep in mind

This is a future hardware announcement, not a shipping product or a benchmark we ran. Performance needs validation on actual systems.
