RISC Machine Guide

RISC = four systems for a production-grade agent or robot

A production-grade agent needs more than a brain. It must keep working, withstand failures, prevent overreach, and collaborate across real organizations.

The industry has delivered a capable brain. Production agents also need a body, an immune system, and a social interface.ALUX is building that complete machine.
R | Resilience / BodyDurable execution, fault tolerance, recovery, and horizontal scaling. One failure should not erase the work.
I | Intelligence / BrainModel loops, memory, tools, and orchestration determine how an agent reasons and completes complex work.
S | Security / ImmunityObject capabilities, policy approvals, rollback, and audit limit the reach of failures and unauthorized actions.
C | Connectivity / SocietyCross-company authorization, a neutral substrate, session types, and ecosystem connections let agents work beyond one product.

New Features Worth Watching

01GPT-6 Sol and LunaUnited StatesPublished 2026-09-22 / Observed 2026-09-23Primary sources

GPT-6 adds two capability and price tiers

What changed: OpenAI released GPT-6 Sol and Luna on September 22. Both accept text and images, generate text, and support a 1.05M-token context window with up to 128K output tokens. At standard rates for shorter prompts, Sol costs $2 per million input tokens and $10 per million output tokens; Luna costs $0.10 and $0.50, respectively. Both offer reasoning settings and tool use.

Why it matters: The family offers lower-cost options for assigning complex coding and high-volume, focused tasks to different models. Compare the total cost of a successful task, not token prices alone.

Who should care: Developers and product teams choosing models for coding, document processing, and batch agent workloads.

Try it

Run the same tasks on Sol and Luna, recording success, retries, and cost. Check the Responses API requirements for tools rather than merely changing the model name.

Watch for

Prompts above 272K input tokens incur higher rates; cache writes have separate pricing. Function calling through Chat Completions requires reasoning to be disabled.

02Claude Opus 5.5United StatesPublished 2026-09-22 / Observed 2026-09-23Primary sources

Opus 5.5 targets cheaper long-running work

What changed: Anthropic released Opus 5.5 on September 22, saying it performs at the level of Claude Fable 5.1 on most tasks. Input and output cost $4 and $20 per million tokens; cache reads cost $0.20 per million tokens. The company reports 40% lower typical task costs than Opus 5 at default settings and over 30% faster output, alongside behavioral audits and external evaluations.

Why it matters: Agent costs reflect token rates, token use, and repeated attempts. Beyond lower prices, test whether the model needs fewer steps to finish real work.

Who should care: Developers and enterprise teams using coding assistants for cross-repository changes and automating knowledge work.

Try it

Compare Opus 5 and 5.5 on a migration with existing regression tests. Record elapsed time, change scope, and total cost before changing the default model.

Watch for

The cost and speed figures are vendor measurements, not guarantees for every task. Fast mode has separate rates; some biology and cybersecurity access remains subject to verification.

03MiMo-V2.6ChinaWeights and model card published 2026-09-22 / Observed 2026-09-23License MITPrimary sources

Xiaomi releases open-weight MiMo omnimodal RL checkpoints

What changed: Xiaomi published MiMo-V2.6 model cards and weights on September 22 Beijing time. Pro-RL has 1.02T total and 42B active parameters; Flash-RL has 309B total and 15B active parameters. Both support text, images, video, and audio, with a 1M-token context window. A Qwen3.5-9B-based distilled SFT checkpoint is also available. The releases declare MIT licensing.

Why it matters: The release offers research starting points at different scales, not just API access. Unified mixed reinforcement learning and within-group trajectory grading make the training approach worth examining beyond benchmark scores.

Who should care: Researchers and engineers working on multimodal agents, long-horizon RL, and deploying open models.

Try it

Compare hardware requirements, training recipes, and evaluation conditions in the Pro and Flash cards. Smaller teams can examine task transfer with the 9B checkpoint instead of deploying a trillion-parameter model.

Watch for

The 9B release is an SFT checkpoint, not a completed RL model. Reported results include internal tests. Sparse activation and long context do not imply small memory requirements.

04Grok 4.7United StatesPublished 2026-09-21 / Observed 2026-09-23Primary sources

Grok 4.7 brings tiered reasoning to the public API

What changed: xAI released Grok 4.7 on September 21 with a 500K-token context window, text and image inputs, text output, and four reasoning levels. Below 200K prompt tokens, input, cached input, and output cost $2, $0.50, and $6 per million tokens. The Fast version, with twice the token rate, is available only through Cursor and Grok Build.

Why it matters: The same model name does not imply identical speed or pricing across products. Compare endpoint access, long-context rates, and reasoning settings together.

Who should care: Product and infrastructure teams comparing coding and knowledge-work models or managing multiple providers.

Try it

Test the public API with fixed prompts and reasoning settings. Compare partner-only Fast access separately; for long documents, record prompt length and cost.

Watch for

Rates rise above 200K prompt tokens. Fast is not offered on the public API. Although the documentation lists no text-output limit, context, usage, and cost constraints still apply.

05Hy Image3.5 previewChinaPublished 2026-09-22 / Observed 2026-09-23Primary sources

Hunyuan previews five-reference image editing

What changed: Tencent released Hy Image3.5 preview on September 22. It supports text-to-image generation, image editing, up to five references, and iterative edits using conversation history, with output up to 2K. Demonstrations emphasize small Chinese and English text, complex layouts, and subject consistency. Tencent Cloud’s China API charges RMB 0.15 per image at 2K or below, with no input charge.

Why it matters: Multiple references and iterative edits could help turn one design into a coordinated asset set. Cheaper iterations still need accurate text, stable subjects, and controlled changes.

Who should care: Creators and teams producing product images, infographics, marketing assets, and film characters or scenes.

Try it

Open the official AI Studio to combine five of your own references. Change text and materials over several turns, checking that unrelated details remain intact.

Watch for

This is a preview, not a final release, and 2K is not 4K. Vendor blind tests and partner reports do not replace testing your assets. Check product access and cloud API pricing separately.

06Qwen3.8-Omni-Flash-RealtimeChinaPublished 2026-09-21 / Observed 2026-09-23Primary sources

Brief: Qwen adds a real-time omnimodal endpoint

What changed: Qwen listed Qwen3.8-Omni-Flash-Realtime on September 21. It supports live audio/video interaction, text and audio output, multichannel audio, video aggregation, and remote MCP tools.

Why it matters: Omnimodal understanding can support continuous interaction rather than only uploaded files.

Who should care: Developers building live assistants and multimodal apps.

Try it

Read the real-time model documentation and test one complete tool-call flow.

Watch for

This is a separate real-time model. Protocol support does not establish access for every region or account.

07Qwen-Audio-3.1-Realtime-PlusChinaPublished 2026-09-20 / Observed 2026-09-23Primary sources

Brief: Qwen adds voices to full-duplex speech

What changed: Qwen launched Qwen-Audio-3.1-Realtime-Plus on September 20. It retains the 3.0 Plus integration protocol and existing voices, adds eight system voices, and supports full-duplex conversations and voice cloning.

Why it matters: Existing speech apps can compare the new model without rebuilding their integration.

Who should care: Voice-assistant and real-time support developers.

Try it

Check model IDs and voice lists, then compare interruptions and function calls.

Watch for

Additional voices do not imply unrestricted voice-cloning access. Check the service requirements.

08Clueso MCPGlobalPublished 2026-09-22 / Observed 2026-09-23Primary sources

Brief: Chat edits videos without flattening the project

What changed: Clueso launched its MCP integration on September 22. External assistants can create, recreate, and edit videos, changing assets, captions, branding, and section order while keeping projects editable in a shared workspace.

Why it matters: Conversation can change the video project itself, rather than merely suggest edits.

Who should care: Creators making tutorials and product demonstrations.

Try it

Connect through the official MCP page and try a targeted edit on your own short video.

Watch for

This is a cloud service requiring sign-in. Example workflows do not establish free access or automatic setup of every integration.

09Microduck SandboxEuropeUpdated 2026-09-10 / Observed 2026-09-23Primary sources

Brief: Microduck’s browser playground loads new robot movements

What changed: Microduck’s simulation playground added manifest-based loading for gaits, one-shot moves, and command scripts on September 10. MuJoCo physics and ONNX policies run in the browser, with keyboard or gamepad control.

Why it matters: You can explore how control policies change motion before buying hardware.

Who should care: Robotics enthusiasts and developers building interactive experiments.

Try it

Try walking, sitting, and standing up in the official Space; read how to load movements.

Watch for

This item covers the earlier September 10 update. Playable simulation does not establish equivalent stability on physical hardware.

10reloreGlobalPublished 2026-09-21 / Observed 2026-09-23GitHub Stars 6License Apache-2.0Primary sources

relore helps coding agents find work already underway

What changed: Hugging Face introduced relore on September 21 to connect GitHub issues, reviews, and pull requests to current code. It distinguishes maintainer decisions, contributor claims, and bot comments; it can find fixes underway and trace a line of code back to the relevant discussion. Queries run locally, while ingestion and index refresh contact GitHub. The license is Apache-2.0.

Why it matters: Repository memory needs more than text. Who made a decision, whether a fix already exists, and which code it concerns determine whether an agent repeats work or follows the maintainer’s intent.

Who should care: Developers maintaining mature repositories, code-review assistants, and team knowledge-search tools.

Try it

Index a familiar repository and trace a resolved issue to related fixes and reviews. Check roles and chronology before relying on the results in an agent workflow.

Watch for

Local queries do not guarantee a current index. One reported token-saving example is not a universal benefit. Check permissions, ingestion scope, and missing discussions.

11Unreal AgentGlobalPublished 2026-09-22 / Observed 2026-09-23GitHub Stars 905License MITPrimary sources

Unreal Agent moves tool waiting outside model turns

What changed: Unreal Labs introduced its asynchronous agent harness on September 22. Tool calls immediately enter an in-progress state; completion appends results and wakes the model, while users can steer work during the wait. The project provides a Go library, a command-line runner, and Harbor integration. The authors report lower costs with GPT-6 Astra at xhigh reasoning effort and link their evaluation runs.

Why it matters: Reducing polling, waiting, and redundant tool output can potentially save more than switching models. A harness determines how much work happens between model calls and deserves separate evaluation.

Who should care: Infrastructure teams building long-running agents, tool schedulers, and coding evaluation environments.

Try it

Read the event-log and asynchronous-tool examples, then compare harnesses with the same model, tasks, and reasoning effort. Record success, token use, and elapsed time.

Watch for

Savings of up to 40% come from the authors’ particular comparisons, not every workload. Some providers reject an in-progress result followed by a final result for one call; validate compatibility.

Global Technology and Market Watch

12Transformers GGUFGlobalPublished 2026-09-22 / Observed 2026-09-23Primary sources

Brief: Transformers runs quantized GGUF models directly

What changed: On September 22, Hugging Face described GGUF inference in Transformers using ggml kernels. Initial support focuses on Apple Silicon and Qwen3.5, retaining the familiar Python generation interface.

Why it matters: Quantized models can plug into established evaluation and experimentation workflows.

Who should care: Local-model and PyTorch developers.

Try it

Follow the official setup instructions for the Transformers main branch and the kernels library, starting with a small checkpoint.

Watch for

An incompatible setup may dequantize weights and use more memory. Hugging Face still recommends llama.cpp for efficient local inference.

13AISI and EvalEvalUnited KingdomPublished 2026-09-22 / Observed 2026-09-23Primary sources

Brief: AISI publishes the setup behind benchmark scores

What changed: On September 22, the UK’s AISI and EvalEval described sharing results through Evaluation Cards. The release covers five main benchmarks and six models, with configurations and two additional cybersecurity evaluations.

Why it matters: Apparently comparable scores may use different compute budgets and feedback protocols.

Who should care: Readers evaluating models or comparing them for procurement.

Try it

Inspect evaluation cards by model and align protocols and inference budgets before comparing scores.

Watch for

The main experiment and supplementary cybersecurity evaluations use different, partially overlapping model sets.

14Hunyuan Batch Size ScalingChinaPublished 2026-09-22 / Observed 2026-09-23Primary sources

Brief: Larger RL batches do not always train faster

What changed: Tencent’s September 22 study compares reinforcement-learning sample efficiency with system throughput. On fixed hardware, its best GRPO configuration reached the same validation target 29% sooner, while oversized batches slowed progress.

Why it matters: Faster training means reaching the same quality sooner, not simply processing more samples.

Who should care: Reinforcement-learning and compute-planning teams.

Try it

Read the learning-rate retuning method and compare cumulative samples with time to target.

Watch for

The 29% result applies to a particular model and task setup, not arbitrary training workloads.

This issue: Model prices, agent turns, and training throughput each capture only part of cost. Compare costs at the same quality target to see whether savings come from eliminating waste or skipping necessary work.
