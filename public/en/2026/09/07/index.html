RISC Machine Primer

RISC = the four systems that make an agent production-ready

A production-grade agent needs more than a brain. It must keep operating, survive failure, resist overreach, and participate in real organizational workflows.

The industry has delivered an excellent brain, but a production-grade agent also needs a body, an immune system, and a social layer.ALUX is building that complete machine.
R | Robust — BodyDurable execution, fault tolerance, recovery, and horizontal scale. Without a resilient body, one failure can erase progress.
I | Intelligent — BrainModel loops, memory, tools, and orchestration. This system determines how an agent reasons, uses tools, and completes complex work.
S | Secure — Immune SystemObject-capability security, policy controls, rollback, and audit. Without an immune system, recovery and connectivity expand the blast radius.
C | Connected — SocialCross-company authorization, neutral substrate, session types, and ecosystem connectors. Without a social interface, an agent remains confined to one product.

New Features Worth Watching

01Microsoft VibeVoice ASR StreamingUnited States / GlobalPublished 2026-09-02 / Observed 2026-09-07Official model card

VibeVoice Streams Transcripts With Speaker Attribution

What changed: Microsoft released weights and code for VibeVoice-ASR-Streaming-7B. The 7B speech-recognition model produces speaker-attributed transcripts while audio is still arriving and supports custom hotwords. Its official model card lists ten languages, including Chinese, English, Japanese, and Korean.

Why it matters: Live meetings and voice agents need more than speech-to-text. They must preserve who is speaking, recognize domain terms, and keep turns from crossing. Combining streaming ASR and speaker attribution can shorten that processing chain.

Who should care: Teams building meeting notes, contact-center QA, live captions, interview workflows, or voice agents.

Try it

Create a short clip with two alternating speakers, one overlap, and five domain-specific hotwords. Check speaker changes, hotword recall, and latency in the official demo or local code.

Keep in mind

The MIT license and public weights were verified. Ten-language support comes from the official model card; this issue did not independently measure real-time factor, overlap accuracy, or accent coverage.

02Qwen-Drive 1.0 4BChina / GlobalPublished 2026-08-27 / Observed 2026-09-07Official model card

Qwen-Drive Uses One 4B Backbone to See, Explain, and Plan

What changed: Qwen-Drive 1.0 adds a bird’s-eye-view perception head and a flow-matching planning expert to a Qwen3.5-4B backbone. One system handles 3D detection, occupancy and map perception, visual question answering, and vehicle-motion planning. Qwen published weights and code under Apache-2.0.

Why it matters: Autonomous-driving stacks often separate perception, language understanding, and planning. This compact model brings them into one backbone and offers a reproducible starting point for vehicle and edge-robotics research.

Who should care: Autonomous-driving, mobile-robotics, embodied-AI, simulation, and edge teams.

Try it

Reproduce the official example, then send one driving clip through both visual QA and planning. Check whether objects, lane semantics, and trajectories remain consistent.

Keep in mind

The architecture, weights, and license were verified; this issue did not reproduce the vendor benchmarks. The 4B figure describes the backbone, not the resource cost of the complete training and deployment stack.

03InclusionAI LLaDA-ImageChina / GlobalPublished 2026-09-04 / Observed 2026-09-07Official open-source releaseGitHub Stars 147License not declared

LLaDA-Image Uses One 6B Model for Generation and Editing

What changed: InclusionAI released inference code and weights for LLaDA-Image. The same 6B diffusion language model handles text-to-image generation and image editing. The base model runs for 50 steps, while the Turbo variant reduces that to four and emphasizes Chinese and English text rendering.

Why it matters: A shared model can keep generation and local edits inside one conversational workflow instead of moving state between separate systems. The four-step variant is also better suited to interactive iteration.

Who should care: Teams building visual-creation tools, advertising assets, images containing Chinese text, image-editing workflows, or multimodal agents.

Try it

Make three consecutive local edits to one image and include short Chinese and English titles. Check subject identity, untouched regions, and text stability.

Keep in mind

GitHub does not declare a repository license, while the model card lists Apache-2.0 for the model. Weights and inference code are available, but training code is still marked as coming soon, so the full training recipe is not yet open. This issue did not independently test four-step speed or quality.

04IFM K2-Horizon MoVAUnited States / GlobalPublished 2026-09-01 / Observed 2026-09-07Official model card

K2-Horizon Activates 4B Parameters Across a 512K Context

What changed: IFM released the final K2-Horizon-MoVA-36B-A4B weights. The model has 36B total parameters, activates about 4B per token, and offers a native 512K context window. Its MoVA routing selects among several attention mechanisms at the token level.

Why it matters: The cost of long context depends not only on total parameters but also on how much computation each token traverses. Token-level routing across attention and experts offers another efficiency trade-off for document-heavy agents.

Who should care: Teams working on long-document retrieval, repository understanding, research agents, inference serving, or model architecture.

Try it

Test one short-task set and one very long source pack. Measure time to first token, throughput, memory use, and answer traceability instead of comparing context labels alone.

Keep in mind

The final weights and Apache-2.0 license were verified. Training code, data, and intermediate checkpoints are still listed as forthcoming. The 512K figure is vendor-reported and was not stress-tested for this issue.

05Viggle AnimateCanada / GlobalPublished 2026-08-31 / Observed 2026-09-07Official model card

Viggle Animate Replaces a Character From One Repainted Frame

What changed: Viggle Animate lets a user repaint one representative video frame and propagates that character through the clip while preserving source motion, camera movement, and timing. The project says it does not require an external pose estimator, segmenter, face tracker, or text encoder.

Why it matters: Character replacement shifts from regenerating the entire video to defining identity in one frame and inheriting motion across the clip. That is closer to an editor-controlled workflow and lowers the cost of revision.

Who should care: Short-form video, advertising previsualization, virtual-character, dance-content, and video-editing teams.

Try it

Choose a clip with a fast turn and an occlusion in the public demo. Edit one representative frame, then inspect hands, edges, identity after reappearance, and camera consistency.

Keep in mind

Viggle reports 26 seconds for 124 frames on one B200 and a 6.1× speedup over Wan 2.2 under its test setup. Those vendor results were not independently verified. The model uses the MiniMax H3 community license, not Apache or MIT.

06Video DeltaNet VDN-H3Global researchPublished 2026-09-02 / Observed 2026-09-07Official open-source releaseGitHub Stars 303License Apache-2.0

Video DeltaNet Adds a Linear Branch to Reduce Generation Time

What changed: Video DeltaNet adds a separate linear-attention branch to the MiniMax H3 video-diffusion backbone and aligns it with two LoRA adapters. The project released eight-step and 50-step checkpoints plus training and inference code.

Why it matters: Video acceleration does not always require retraining the entire foundation model. A lightweight learned branch can make research improvements easier to integrate into an existing generation pipeline.

Who should care: Video infrastructure, diffusion research, inference optimization, and creative tools.

Try it

Use the same prompt, resolution, and seed to compare the eight-step and 50-step variants. Record steady-state time, memory use, and motion continuity separately.

Keep in mind

The project reports 11.23 seconds of steady-state denoising on eight B200 GPUs, excluding loading, warm-up, encoding, and VAE time. That figure is not end-to-end generation time. Code is Apache-2.0, while model weights inherit MiniMax H3 geographic and redistribution terms.

07CogEvol-4BGlobal open sourcePublished 2026-08-31 / Observed 2026-09-07Official open-source releaseGitHub Stars 40License MIT

CogEvol-4B Generates Playable Lessons and Interactive Web Pages

What changed: CogEvol-4B is based on Qwen3.5-4B and directly produces structured JSON slide decks or self-contained interactive HTML lessons. The project describes a training sequence of supervised fine-tuning, slide-focused reinforcement learning, and interactive-HTML reinforcement learning, and provides a roughly 2.4GB Q4_K_M quantized file.

Why it matters: A small model can now deliver a playable, clickable, offline learning artifact instead of only a script. For personal devices and internal knowledge workflows, that is closer to a usable product than another block of cloud-generated text.

Who should care: Education products, corporate training, instructional design, local-model, and offline-content teams.

Try it

Download the quantized build and request one topic with a formula, a chart, and three interactive questions. Verify offline operation, button behavior, and factual consistency.

Keep in mind

The model card lists Apache-2.0, while the code repository lists MIT. The roughly 2.4GB figure is one quantized file size, not runtime memory. Training-sample volume and filtering details come from the project.

08Microsoft SQuadGenUnited States / GlobalPublished 2026-08-27 / Observed 2026-09-07Official open-source releaseGitHub Stars 20License MIT

SQuadGen Makes Quad Meshes Generative

What changed: Microsoft released SQuadGen weights and code, combining a continuous surface representation with diffusion to generate quad-dominant 3D meshes.

Why it matters: Editable topology is closer to modeling, animation, and downstream production than visual appearance alone.

Who should care: 3D-asset, game, animation, and geometry-generation researchers.

Try it

Run one official checkpoint and inspect quad coverage, seams, and downstream editability.

Keep in mind

The model and code use MIT. This remains a research release, and sample quality does not prove stable output for every complex object.

10Reachy Mini 3D VoiceFrance / GlobalPublished 2026-08-31 / Observed 2026-09-07Official demo

Reachy Mini Gets a Speaking 3D Body in the Browser

What changed: Pollen Robotics turned Reachy Mini into a browser-based 3D voice demo. During conversation, the model can call emotion, dance, weather, and search tools, while the robot’s head motion follows the assistant’s speech.

Why it matters: Body motion, tool feedback, and speaking rhythm can now share one front end.

Who should care: Robotics, voice products, educational exhibits, and 3D-interface teams.

Try it

Open the public Space, interrupt one turn, and call the weather tool. Watch whether speech, movement, and tool output remain in the same conversational turn.

Keep in mind

This is a browser demo, not a physical robot controller; Microduck uses procedural animation.

09Irodori-TTS v4.1 AnimeJapan / GlobalPublished 2026-09-04 / Observed 2026-09-07Official model card

Irodori-TTS Adds Local Quantized Builds for Anime-Style Japanese Voices

What changed: PhaseField Audio released Irodori-TTS v4.1 for anime-style Japanese speech with int8, int4, float8, and other quantized variants.

Why it matters: Smaller local builds let teams prototype character voices without depending on a hosted service first.

Who should care: Japanese dubbing, game, virtual-character, and local-TTS teams.

Try it

Compare the same line in the original and quantized builds, listening for pauses, emotion, sibilance, and local latency.

Keep in mind

The model card lists an MIT license. This issue did not audit training data or voice rights.

11Extropic Z1T-0United States / Global researchPublished 2026-09-04 / Observed 2026-09-07Official research release

Z1T-0 Opens the First Sparse Weights for Probabilistic Hardware

What changed: Extropic introduced the Z1T sparse transformer-like architecture for its Z1 probabilistic hardware and released the first Z1T-0 weights plus Apache-2.0 code.

Why it matters: The work studies model structure, sparse connectivity, and unconventional chips together, offering a data-center efficiency path beyond simply adding more GPUs.

Who should care: AI chips, sparse models, inference, and heterogeneous computing.

Try it

Reproduce the experiment in the digital simulation code first. Track energy estimates, model loss, and hardware assumptions separately so simulated values are not mistaken for production metrics.

Keep in mind

The project estimates roughly two orders of magnitude better energy efficiency than GPUs for selected operations. That is a team calculation, not an independent chip benchmark. Z1T-0 is architectural research and does not establish production deployment of general-purpose large models on Z1.

12NVIDIA Qwen3.8 Flash Next NVFP4United States and China / GlobalPublished 2026-08-31 / Observed 2026-09-07Official model card

NVIDIA Shrinks the Qwen3.8-Flash-Next Checkpoint by About 63%

What changed: NVIDIA released an NVFP4 checkpoint for Qwen3.8-Flash-Next and says its disk footprint is about 63% smaller than the BF16 source.

Why it matters: The large multimodal model now has a ready-to-serve quantized build.

Who should care: Blackwell, RAG, agent-service, and multimodal deployment teams.

Try it

On supported B200 or B300 hardware, compare FP8 and NVFP4 with the same business workload. Measure throughput, memory, and answer quality.

Keep in mind

The roughly 63% figure is checkpoint disk reduction, not an equal reduction in total operating cost. Official support targets B200 and B300, and MTP still needs a specific vLLM fix. Both NVIDIA and Qwen terms apply.

13OpenAI Codex Banked ResetUnited States / Eligible accountsPublished 2026-09-04 / Observed 2026-09-07Official help-center notice

Astra Rollout Included Two Banked Codex Resets

What changed: OpenAI’s Help Center says existing Plus, Pro, and Business users in good standing qualified for one banked Codex reset on September 3 and another on September 4 during the GPT-6 Astra rollout; new accounts were subject to the creation-time cutoffs stated on the page. Each reset is saved until the account-specific expiration shown in the offer and must be applied manually. Applying one refreshes both the five-hour and weekly usage windows and moves the next weekly reset date.

Why it matters: This is more than a one-time quota increase. It turns compute access into a saved account benefit that can be timed for a busy period, while the redemption date reshapes the rest of the week.

Who should care: Eligible Plus, Pro, and Business users who plan long Codex runs, team seats, or weekly quota use.

Try it

Check the Codex usage page for a reset card, its expiration, and covered windows. Record the current weekly reset date before redeeming it.

Keep in mind

This is a plan- and account-eligible benefit that requires manual redemption, not an automatic reset for every user. OpenAI does not state one universal expiration time; account status is authoritative.

14Cohere Parse v5Canada / Global enterprisePublished 2026-08-27 / Observed 2026-09-07Official changelog

Cohere Parse Gives Agents Both Reading Order and Page Position

What changed: Cohere released Parse v5, a 2.3B multimodal document model that extracts text, tables, forms, and images in reading order and returns Markdown, HTML, bounding boxes, and image descriptions.

Why it matters: Reading order and positional evidence can enter retrieval and review together.

Who should care: Contract analysis, financial documents, knowledge bases, RAG, and enterprise-document automation teams.

Try it

Test one two-column PDF and one scanned document with a complex table. Check reading order, table structure, and whether bounding boxes map back to the source page.

Keep in mind

Cohere lists an 8K context window and four access channels. This issue did not independently retest complex-layout accuracy.

15Zhipu GLM-5.3-FlashChina / GlobalPublished 2026-08-26 / Observed 2026-09-07Official release notes

GLM-5.3-Flash Uses 18B Active Parameters for Native Multimodal Workflows

What changed: Zhipu launched GLM-5.3-Flash with 320B total parameters and 18B active parameters. It combines linear and sparse attention and natively understands images and video.

Why it matters: The Flash variant brings large-scale MoE, multimodality, and tool operation into one efficiency track.

Who should care: Coding agents, browser automation, office tools, financial research, and China-focused model platforms.

Try it

Use one chart-heavy document to trigger browser research, spreadsheet organization, and a final summary. Check cross-modal citations and tool state across the workflow.

Keep in mind

Parameters, architecture, and capability scope come from Zhipu’s official release notes. This issue did not independently test performance, and “closed-loop feedback” does not mean every browser task can run without supervision.

16Microsoft MAI-Image-2.6United States / GlobalPublished 2026-09-04 / Observed 2026-09-07Official announcement

MAI-Image-2.6 Brings Multi-Reference Editing to Foundry Preview

What changed: Microsoft released MAI-Image-2.6 and a Flash variant for generation and editing with multiple reference images, and made it available in Microsoft Foundry public preview.

Why it matters: Multiple reference images can help preserve asset consistency across repeated revisions.

Who should care: Brand design, e-commerce assets, character consistency, image editing, and enterprise-generation platform teams.

Try it

Provide separate subject, scene, and style references, then revise composition and copy across several turns. Check identity, product details, and untouched regions.

Keep in mind

Availability and capability scope come from Microsoft’s announcement. This issue did not independently retest quality, cost, or multi-reference consistency and does not treat leaderboard placement as proof.

This issue’s takeaway: Agent competition is moving from isolated answers toward sustained perception, action, delivery, and compute allocation. The closer a system gets to production, the less room there is to omit access, licensing, and measurement boundaries.
