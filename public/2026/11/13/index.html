RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Gemini 4 Hydrogen美国与英国2026-11-12 发布2026-11-13 观察官方一手来源

Gemini Hydrogen把百万上下文带入日常Agent

发生了什么：Google正式开放Gemini 4 Hydrogen API，支持文本、图像、音视频与PDF输入，输出文本。统一输入输出窗口为1048576 token；默认同步输出上限65536，使用long decode可扩展，但仍受统一窗口约束。模型也成为托管Antigravity Agent的默认选项。

为什么值得关注：长输出与长上下文需要共同预算，不能把两项上限相加。对编码和多步工具任务而言，迁移价值不仅在模型能力，也在输出模式、工具支持与成本的配合。

适合谁看：需要处理长文档、多模态输入和多步编码任务的应用开发者与Agent平台团队。

试试看

在AI Studio用自己的长文档比较默认同步模式；需要更长输出时再检查long decode协议、上下文余量与调用成本。

注意点

这是闭源GA API，不是开放权重；不提供图像、语音生成或Live API。长输出上限不是质量保证，本期未做性能对比。

02Claude Managed Agents美国2026-11-12 发布2026-11-13 观察官方一手来源

Claude托管Agent允许整套服务自托管

发生了什么：Anthropic推出自托管Claude Managed Agents，不再只是把沙箱放在客户环境，而是让整个服务运行在自有基础设施中，保存Agent、会话及其历史。服务器向客户选择的模型提供商发请求，默认仍为Anthropic；访问需要联系客户团队申请。

为什么值得关注：服务、执行环境和模型推理是三个不同部署层。企业可以改变会话数据与控制服务的位置，而不必把模型权重也搬到本地；采购时需要逐层确认边界。

适合谁看：对会话历史存放位置、基础设施控制与企业部署方式有要求的平台及治理团队。

试试看

按官方自托管文档画出服务、沙箱、存储与模型请求路径，再向客户团队核对接入条件，不把现有沙箱功能当作整套部署。

注意点

申请式企业访问不等于普遍可用；自托管不代表Claude权重开放，也不意味着离线推理。本文未取得部署权限或实测。

07Animate4Me全球2026-11-12 公开展示2026-11-13 观察作者一手来源

Animate4Me把角色画交成可编辑骨骼动画

发生了什么：Animate4Me接受角色图或提示，自动拆层、补画遮挡部分并生成骨骼、权重网格和物理约束。它交付Spine 4.2的JSON、atlas与PNG纹理文件，而非只有一段视频；官网还提供浏览器骨骼演示与下载样例。作者公开介绍。

为什么值得关注：生成结果可以继续进入游戏资产流程，而不是停在观看。可编辑文件、运行时版本和素材授权，直接影响开发者能否把动画真正装进产品。

适合谁看：为二维游戏制作角色待机动画、道具动效及交互素材的独立开发者和美术团队。

试试看

先看官网实时骨骼与下载样例，核对Spine 4.2兼容性；再用自有角色图测试待机模板，检查遮挡补画和网格变形。

注意点

生成按token收费，套餐起价每月19美元。角色win模板仍标预告，先看idle；产品采用官方Spine Runtime须自备许可，本期未付费测试。

03SGLang-Neuron美国2026-11-12 发布2026-11-13 观察官方一手来源GitHub Stars 8许可证 Apache-2.0

SGLang把熟悉的推理接口带到Trainium

发生了什么：AWS宣布SGLang-Neuron公开预览，由RadixArk与Annapurna Labs合作推出。它以树外插件接入Trainium，保留SGLang服务接口与生成API，底层使用原生PyTorch、torch.compile及NKI内核，并支持通过NIXL与EFA传输缓存的预填充和解码分离。

为什么值得关注：迁移硬件不必同时更换上层调用方式。插件把芯片执行与框架调度分开，但真正能否迁移，仍取决于模型支持、已验证配置和负载表现。

适合谁看：评估Trainium部署、异构推理平台与强化学习采样基础设施的工程团队。

试试看

按官方容器教程，在受支持实例上先运行示例模型，对照已有API检查结果，再测自己的并发、上下文长度与成本。

注意点

官方示例使用Trainium3和指定容器；接口相同不代表所有模型或功能一致。本文未部署验证，不据此宣称优于GPU。

08Cerulion 2.0全球2026-11-12 发布2026-11-13 观察官方一手来源GitHub Stars 108许可证 AGPL-3.0

Cerulion为机器人进程保存可核对的重跑记录

发生了什么：Cerulion 2.0新增ROS 2单进程精确重跑记录：保存输入消费顺序、等待返回与输出哈希，重跑时比较输出并记录首个分歧。版本还调整默认局域网配对访问与节点ABI；旧节点库需要重建，不能直接替换二进制。

为什么值得关注：重放消息与重新执行代码不是一回事。保存进程实际消费的顺序与输出比较结果，有助于分辨改代码后出现的变化，而不只是重新看一次传感器数据。

适合谁看：需要回查机器人故障、核对控制代码修改及维护ROS 2测试流程的研发团队。

试试看

从官方避障例子录制运行，在隔离环境重跑并查看verdict；再故意修改控制参数，确认能定位首个输入一致而输出不同的位置。

注意点

主体AGPL加商业许可，托管MCP等另有闭源部分；重跑会发布输出，远离真实机器人。多线程执行器等情形可被拒绝，不代表任意系统都能确定性重放。

04AgentCore Runtime美国2026-11-12 发布2026-11-13 观察官方一手来源

AgentCore扩大会话资源并回收闲置内存

发生了什么：AWS更新AgentCore Runtime，继续为每个会话提供独立Firecracker微虚拟机，资源上限升至8 vCPU和32GB内存，支持10GB容器镜像。官方称会话启动低于两秒，并新增内存回收、闲置缩至零及文件系统挂载能力，覆盖多个区域。

为什么值得关注：长时间运行的Agent并非始终计算。把等待期间的资源消耗与执行时的资源峰值分开，能让成本评估更贴近真实任务，也让隔离边界延伸到工作文件。

适合谁看：部署代码执行、浏览器自动化及长期多轮会话的企业平台和基础设施团队。

试试看

从现有工作负载比较冷启动、等待期间内存计费与存储权限；验证不同会话不会读到彼此文件，再决定迁移范围。

注意点

启动与节省幅度来自AWS陈述，不是本期实测。按会话凭据绑定独立存储目录计划在re:Invent前提供，不能当作今天已经上线。

本期观察：自动化的终点不是生成完成。运行成本、服务边界与文件可编辑性决定工作能否接续；对每一处交接，找一份可以亲自检查的结果。
