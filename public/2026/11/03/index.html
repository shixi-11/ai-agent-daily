RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Claude Messages API美国2026-11-02 发布2026-11-03 观察官方一手来源

Claude对话线程让后续请求只传新消息

发生了什么：Anthropic推出Messages API对话线程测试版：首轮上传完整对话、系统提示与工具，之后只发送新消息和上次响应ID，由服务端还原上下文。它旨在减少长对话和Agent循环的重复上传与预处理，但不会自动开启提示缓存，也不替应用保存长期记录。

为什么值得关注：传输优化和持久记忆常被混为一谈。这次接口让每轮请求更轻，却仍要求应用自存完整对话、处理线程失效和重放，能帮助团队明确哪些状态由谁负责。

适合谁看：维护长对话、工具调用循环以及Claude多平台接入的开发团队。

试试看

阅读官方线程文档与测试头设置，用一份非敏感长对话比较请求体积、首字延迟，并主动测试404后的完整重放，不只测顺利路径。

注意点

线程闲置5分钟过期，最后使用后至多1小时删除；不适用ZDR或HIPAA。SDK副本仅在内存，不能代替持久存储，本期未测性能。

发生了什么：一项研究从Nature、Science及Cell系列期刊整理36项监督预测任务，让Claude Opus 5自动构建简单基线。按每项任务多次运行的中位数计，12项达到或超过论文所报深度学习成绩；整体基线强度中位数为95.5%，指相对平凡预测器填补的性能差距。

试试看

注意点
