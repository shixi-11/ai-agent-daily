RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

06NVIDIA Vera美国2026-11-05 发布2026-11-08 观察官方一手来源

Vera把Agent等待时间追到CPU执行环节

发生了什么：NVIDIA发布Vera的Agent执行测试：模型推理之外，搜索、数据库查询与代码沙箱依赖CPU。文中列出合作伙伴测试，Daytona在Vera上用10.8秒启动1000个沙箱，对比x86的88.4秒；Perplexity报告编码任务快1.5倍，并计划用于后续生产系统。

为什么值得关注：Agent交替占用GPU与CPU，工具执行慢也会拖长整条任务。采购评估因此不能只比较模型词元速度，还应看沙箱启动、并发工作完成率和功耗预算下的服务能力。

适合谁看：管理Agent沙箱、代码执行服务及异构计算采购的基础设施团队。

试试看

把自己的工具调用与代码测试单独计时，在相同并发、隔离配置和功耗边界下比较CPU；再把结果接回完整任务，区分局部加速与总耗时。

注意点

数字来自NVIDIA与合作伙伴公布的指定负载，不是本期独立复测。各项测试条件和指标不同，不能将某个沙箱启动倍数直接当成所有Agent的提速。

07NVIDIA与6G研究英国与全球2026-11-06 发布2026-11-08 观察官方一手来源

机器人只传关键关系，研究无线回路提速

发生了什么：NVIDIA汇总Aerial与Sionna研究进展：伦敦国王学院让机械臂发送物体、位置与关系等紧凑语义，而非周期性完整图像。在加入故障的水果装箱与方块堆叠实验中，团队报告任务完成时间最多缩短52.6%，并展示掉落检测和动作失败后的恢复。

为什么值得关注：云端或边缘模型参与控制时，通信内容也是决策延迟的一部分。传什么、何时传，可以和推理及恢复一起设计；这比单独追逐链路带宽更贴近机器人实际目标。

适合谁看：研究边缘机器人、无线感知与云端决策回路的开发者和实验团队。

试试看

先看语义通信实验如何定义对象关系与故障，再在小任务比较完整图像与结构化更新；同时记录完成时间、任务成功率和丢包后的行为。

注意点

这是11月6日的研究进展汇总，不是Aerial或Sionna首次开源。改善幅度来自指定实验与基线，不代表任何无线环境；本期未运行机械臂实验。
