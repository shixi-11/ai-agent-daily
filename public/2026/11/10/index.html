RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Claude Fable与Mythos 5.2美国2026-11-09 发布2026-11-10 观察官方一手来源

Fable与Mythos 5.2面向长程技术工作

发生了什么：Anthropic发布Claude Fable 5.2与Mythos 5.2，两者共享底层模型，前者保留更严格的网络与生物安全防护，后者向通过验证的机构开放。官方称生成速度较5.1最高提升30%，标准API每百万输入、输出Token分别为8美元与40美元，并提供另计费的快速模式。

为什么值得关注：这次升级把难题处理与日常任务分开：Fable可担任顾问或编排者，把较简单工作交给小模型。团队需要比较整项任务的成本与可靠性，而非只看每百万Token价格。

适合谁看：需要长时间编码、科学计算与复杂研究的团队，以及设计模型分工的Agent开发者。

试试看

从官方发布页核对平台可用性，选一个已有验收标准的难题，与Opus 5.5比较完成率、总费用和人工复核量，再决定是否升级。

注意点

快模式输入、输出价为16与80美元；Mythos需要验证资格。性能和长程案例均是厂商测试，不代表所有任务都能无人值守完成。

02Bedrock Managed Knowledge Base美国2026-11-09T12:13:18-08:00 发布2026-11-10 观察官方一手来源

同一个检索API开始按问题分配推理

发生了什么：Bedrock知识库扩展AgenticRetrieveStream：maxAgentIteration设为0时只返回片段、不调用语言模型；设为1时检索一次再生成答案；2至5保留多轮规划检索。同一接口处理简单查找与跨文档比较，应用自行决定每次使用哪种模式。

为什么值得关注：并非每个知识库问题都值得运行完整Agent循环。把直接查找、带答案的检索和复杂调查分开，有助于控制时延与模型调用量，也让成本来源更容易解释。

适合谁看：构建企业知识助手、政策检索和多知识库问答的开发与平台团队。

试试看

对同一组真实问题测试0、1和多轮配置，分别记录检索命中、答案依据与时延；仅要原文时使用0，并关闭generateResponse。

注意点

模式选择属于应用逻辑，不是服务自动判断。0轮配generateResponse=true会返回错误；文中的银行场景是示例，不是客户实测收益。

04Nuance Emma全球2026-11-09 发布2026-11-10 观察官方一手来源

Emma把表情和接话时机接进实时对话

发生了什么：Nuance Labs发布全双工视听模型Nuplex 1.0及人物Emma，同时开放Beta API。用户可在浏览器免账号与人物声画通话，模型边听边说，并利用注视、表情和停顿组织交接。Emma的脸与声音来自授权演员，不是上传照片即可克隆任意真人。

为什么值得关注：实时互动的体验不只取决于回答延迟。什么时候插话、什么时候继续听、表情如何回应，开始成为独立的模型与产品设计问题，值得语音Agent团队观察。

适合谁看：研究实时语音、虚拟人物、声画交互及工具后台协作的产品和开发团队。

试试看

在官方允许地区打开Emma体验，留意长停顿、打断与环境噪声下的行为；开发者可查看Beta API如何在持续对话时把长任务交给后台工具。

注意点

仅限18岁以上、英语及指定欧美地区，中国不在可用范围。厂商比较未获独立复测；视频理解、口型和接话仍会出错，也不能唱歌。

05Vork全球2026-11-09T03:43:46Z 发布2026-11-10 观察官方一手来源GitHub Stars 1,287README声明vork Preview License；GitHub未识别SPDX；非开源

Vork让Agent直接写三维场景程序

发生了什么：Vork作者展示面向AI Agent的三维与特效引擎，并发布0.3.0版本。Agent通过约2500 Token的核心API编写几何、材质、着色器、相机和物理逻辑，由GPU渲染后再观察修改；仓库附鸟群、黑洞近似和实拍合成等示例，无需让助手模拟点击编辑器。

为什么值得关注：把场景表示为可执行代码，意味着相机、灯光和效果可以像程序一样修改与复用。它为创作Agent提供另一条执行路径，但渲染引擎的能力不能等同生成模型的审美判断。

适合谁看：开发三维创作Agent、程序化视觉与特效工具的团队，以及具备代码基础的创作者。

试试看

从仓库的init示例创建场景，先调整相机和灯光，再读对应帮助生成预览；检查自己的GPU是否满足Metal或Vulkan光线查询要求。

注意点

这是源代码可见研究预览，不是OSI开源；许可限制修改版分发及托管渲染服务。速度对比不代表画质相同，黑洞示例也不是精确相对论求解器。

03CrossnoKaye AURA美国2026-11-09T10:55:43-08:00 发布2026-11-10 观察官方一手来源

工业Agent把计算与设备控制分开

发生了什么：AWS披露CrossnoKaye的AURA架构：Agent读取统一的工厂模型、控制联锁与历史传感器数据，在隔离微虚拟机中运行Python计算。确定性校验器检查输出表的字段和类型，失败则重新计算；设备的基础控制继续在本地边缘集群运行，云连接中断也不依赖模型接管。

为什么值得关注：工业诊断既需要设备上下游关系，也需要可核对的数值。这里值得借鉴的不是让模型直接调阀门，而是把语言推理、受检计算和已有控制逻辑放在不同责任层。

适合谁看：开发工业诊断、设备运维与时序分析Agent的工程团队及平台架构师。

试试看

阅读原文的会话与定时任务设计：交互保留短期热沙箱，自动报告每次新建环境。用离线历史数据验证表结构、失败重试与证据引用。

注意点

生产与节能数字由客户报告，不是本期实测，也不能全部归因于Agent。案例中的控制联锁与边缘安全机制不能被通用聊天模型替代。

06NVIDIA CoRL美国2026-11-09T14:00:01Z 发布2026-11-10 观察官方一手来源

发生了什么：NVIDIA在CoRL宣布GR00T 2世界动作模型，并展示机器人精细操作、工业评测与Agent编程进展。既有Isaac Lab 3.0和GaP参与演示：前者结合物理仿真与并行训练，后者让Agent把单项技能组合成可读程序，用失败结果继续改进。

试试看

注意点

GR00T 2已宣布，但本期未证实权重可下载；Isaac Lab 3.0与GaP均早已公开。官方称Arena 0.4开发者预览将在CoRL期间到来。演示和测试成功率不能外推为现场可靠性。
