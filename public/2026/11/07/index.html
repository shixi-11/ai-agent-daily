RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

注意点

06SageMaker MIG美国2026-11-06 发布2026-11-07 观察官方一手来源

SageMaker让多个模型分用隔离GPU切片

发生了什么：AWS为使用推理组件的SageMaker端点加入GPU分区支持：通过NVIDIA MIG把显卡分成独立计算和显存区域，不同模型可各占一片。配置分区布局后，再为推理组件选择切片规格，避免小模型也必须独占整卡。

为什么值得关注：多租户模型、重排器和安全分类器未必需要整张高端显卡。把硬件资源分配颗粒度缩小，可以比较更贴近负载的方案；但切片显存仍须同时容纳权重、KV缓存与运行开销。

适合谁看：部署多款中小模型、管理推理成本与GPU资源隔离的基础设施团队。

试试看

先核对实例对应的MIG规格，再用真实提示长度和并发量比较整卡与切片；把首词延迟、失败率和每百万输出词元成本一起记录。

注意点

单模型、无服务器端点与异构实例池不支持；布局变更需新端点迁移。GPU隔离不涵盖主机CPU及网络，文中成本改善仅属AWS特定测试。

试试看

先读两部分教程的身份链，分别测试用户无组、Agent身份错误、超范围与有效委派；同时确认工具列表分页和服务端用户权限检查没有遗漏。

注意点

每个Agent仍需独立网关与凭据提供方；网关策略不能替代MCP服务端用户组检查。文中片段是概念示例，不是一套完整可直接投产的部署包。
