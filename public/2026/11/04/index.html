RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

11AWS AgentCore Gateway美国2026-11-03 发布2026-11-04 观察官方一手来源

AgentCore把用户身份带到ServiceNow

发生了什么：AWS公布AgentCore Gateway的代用户令牌交换教程：Agent携带用户令牌进入网关，由微软Entra ID换取面向ServiceNow的新令牌，后者据此应用原用户权限。交换配置放在网关目标上，每次请求执行，无需应用自行编写中转逻辑。

为什么值得关注：企业助手能连上API，不代表调用仍受原用户权限约束。这套示例把应用身份与用户身份分开，让下游审批和审计能认出真正的发起者，而非只看到一个共享服务账号。

适合谁看：连接企业工单、维护跨云身份与设计Agent授权链路的工程团队。

试试看

按教程在开发实例中串起Entra、网关和ServiceNow，分别测试有权与无权用户，再核对下游记录中的用户映射是否正确。

注意点

这是配置教程，不是所有API自动继承授权；需MCP 2025-11-25网关及正确范围与同意设置。云服务有成本，本期未部署。

12Meta F3 Lightning美国2026-11-03 发布2026-11-04 观察官方一手来源

Meta让特征独立发布，计算仍然共享

发生了什么：Meta介绍F3 Lightning：把广告机器学习特征的发布单位与执行图分离，每项特征可单独验证、上线和回滚。启动时再合并重复计算，用共享内存与连续索引减少请求开销。Meta称，可比抽取特征上线约快3.6倍，基础设施计算成本没有增加。

为什么值得关注：独立部署常以重复执行和额外内存换速度。这套架构把隔离留在发布环节，把复用放到启动与执行环节，提醒团队：发布边界不必等同计算边界，也不能只统计计算次数。

适合谁看：维护在线特征平台、高吞吐推理服务与共享执行图的基础设施团队。

试试看

阅读稳定计算标识、合并执行计划、共享缓冲区与稠密索引四步，再检查自己的请求路径有哪些固定工作可以前移到启动阶段。

注意点

3.6倍指可比特征到生产的速度，并非模型推理提速；这是Meta内部系统经验，不是开源产品发布，本期未独立复现成本结论。
