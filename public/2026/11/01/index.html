RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Tencent Youtu中国2026-10-21 代码提交 北京时间2026-11-01 观察官方一手来源

腾讯为小模型补出官方GGUF权重

发生了什么：腾讯在Youtu-LLM-2B的GGUF分支新增F16与Q8_0文件，并在模型卡补充下载和llama.cpp运行方式。此次开放的是既有19.6亿参数模型的新分发格式，不是重新训练的新型号；提交时间为10月21日，本期回看补报，模型使用自定义Youtu许可。

为什么值得关注：小模型能否进入个人电脑，除了参数量，还取决于文件格式和本地运行工具。官方提供量化文件可减少自行转换环节，但不能直接推断特定机器上的速度或精度。

适合谁看：关注本地推理、小体量Agent模型，以及llama.cpp部署的开发者。

试试看

按模型卡指定GGUF分支下载Q8_0或F16文件，先核对运行器支持和许可证，再用相同提示比较输出与内存占用。

注意点

这是新格式工件而非模型首发，F16也不是低比特量化；128K上下文规格不保证个人设备满长度运行，性能未经本期实测。

07bootgpt全球2026-10-31 公开展示 北京时间2026-11-01 观察作者一手来源GitHub Stars 17许可证 MIT

bootgpt让电脑先编一段启动日志

发生了什么：bootgpt作者展示一个不用操作系统的神经网络实验：510字节汇编推理引擎位于启动扇区，从后续23个扇区加载约11.5 KB的int8模型，在386实模式下生成虚构Linux启动日志。它只看八个字符上下文，用单层隐层网络学习合成日志，代码采用MIT许可。

为什么值得关注：这不是把通用大模型压进半KB，而是为单一任务设计极小运行时。模型、推理引擎和外部数据各占多少空间，被这个小实验拆得格外直观。

适合谁看：喜欢底层计算、复古硬件及微型神经网络实验的开发者与学生。

试试看

依README安装nasm、QEMU和Python依赖，在模拟器中构建并观察输出，再对照汇编与训练代码理解整数量化。

注意点

512字节不包含模型权重、词表与字符串；生成内容是虚构日志，不能用于硬件诊断，本期也未运行模拟器复测。
