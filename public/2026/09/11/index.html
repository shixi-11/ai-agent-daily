RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01DeepSeekChina2026-09-10 发布 / 2026-09-11 观察官方页面

DeepSeek V4.1 Flash 换上原生视觉架构

发生了什么：DeepSeek 发布 V4.1 Flash：采用因果编码器—解码器与 MoE，552B 总参数，输入和输出分别激活 8B、16B。新模型原生支持视觉，API 使用 deepseek-flash，旧 Flash 与视觉实验版名称暂时转接到新模型。

为什么值得关注：变化不仅是回答能力：输入与输出拆开计算，会改变长材料处理的成本结构；原生视觉则让截图、图表与文字可以进入同一套工作流程。

适合谁看：正在做文档理解、视觉智能体，或维护 DeepSeek API 接入的团队。

试试看

用同一份带图表的材料比较旧流程与新模型，核对数字提取、推理结论和调用记录，再决定是否调整默认模型。

注意点

官方计划于北京时间 9 月 14 日中午将 V4 Pro 别名转接至 V4.1 Flash；依赖模型名称固定能力的应用应提前检查。

02OpenAIUnited States2026-09-10 发布 / 2026-09-11 观察官方页面

GPT‑Live‑1 开放 API，让语音助手边听边说

发生了什么：OpenAI 将此前用于 ChatGPT 的 GPT‑Live‑1 开放给 API 开发者。模型支持全双工对话，在说话时继续听取用户输入，处理打断、停顿与环境声音；开发者还可把后台任务交给 Astra 或其他模型。

为什么值得关注：语音产品不必再把每轮交流切成严格的先听后说。前台交谈与后台办事分开，也给客服、口语练习和电话助理更灵活的设计空间。

适合谁看：设计实时语音应用、电话服务、语言学习产品与语音交互体验的团队。

试试看

先听官方示例，再用自己的语音流程测试中途改口、短暂停顿和背景噪声，记录误打断与恢复对话的表现。

注意点

这是 API 开放，不是模型首次亮相。语音前端标价每分钟 0.05 美元；后台模型的调用成本仍需另外核算。

03CognitionUnited States2026-09-10 发布 / 2026-09-11 观察官方页面

Cognition 发布 SWE‑2，重点缩短代码探索路径

发生了什么：Cognition 发布基于 Kimi K3 后训练的 SWE‑2，并在 Devin Desktop、CLI 提供使用，向 Devin Web 与 Fusion 推进。官方重点展示仓库探索效率，并让不同推理强度来自同一次强化学习训练。

为什么值得关注：代码智能体常把大量时间花在找文件、理解依赖和反复读上下文。更短的探索路径值得关注，但最终仍要看真实修改是否正确、总成本是否下降。

适合谁看：使用 Devin 的开发团队，以及评估代码智能体效率与完成质量的工程负责人。

试试看

选一个已有测试的真实缺陷，对照不同推理强度，记录探索步骤、完成时间与测试结果，别只比较回答速度。

注意点

官方基准和步数对比来自特定任务与配置，并不能保证你的仓库同幅提升；Web 与 Fusion 的开放进度也要以账户为准。

08InceptionUnited States2026-09-11 观察，首发日未标注官方页面

Mercury 2.5 用扩散路线加速文本生成

发生了什么：Inception 的 Mercury 2.5 提供扩散式语言模型，支持 260K 上下文、并行工具调用与结构化输出，并通过自家 API 等渠道提供服务。

为什么值得关注：它为重视延迟和吞吐的智能体增加了不同技术路线。

适合谁看：评估高吞吐文本与工具调用的团队。

试试看

对比完整任务耗时、输出有效率与调用成本。

注意点

官方速度数字取决于硬件配置，不等于用户端速度。

ChatGPT Work 的 Data agent 连接企业数据

发生了什么：OpenAI 推出 Data agent，让用户连接获准的数据源、追问业务变化，并制作可分享的交互看板；查询沿用已连接账户的表、行与列权限。

为什么值得关注：自然语言分析开始与企业已有指标定义和权限结合。

04CohereCanada2026-09-10 发布 / 2026-09-11 观察官方页面

North Small Translate 开放权重，覆盖五十多种语言

发生了什么：Cohere 发布 North Small Translate，采用 218B 总参数、25B 激活参数的 MoE，支持五十多种语言，输入与输出上限各为 16K。官方同时提供量化权重、部署说明和在线演示，许可为 CC BY‑NC 4.0。

为什么值得关注：专用翻译模型给长文档与多语产品增加了可部署的选择；术语、格式和上下文一致性，比一句话翻译的流畅程度更值得实际检验。

适合谁看：多语内容团队、翻译技术研究者，以及需要自行部署翻译模型的开发者。

试试看

用一段含术语表和表格的双语材料试演示，检查专名、单位与段落对应，再根据官方指南评估量化部署资源。

注意点

开放权重采用非商业许可，不能直接等同于可自由商用的开源模型；名称中的 Small 也不代表普通电脑即可运行。

05InternLMChina2026-09-10 发布 / 2026-09-11 观察官方页面

InternLumina‑U2 放出昇腾训练权重

发生了什么：InternLM 为 InternLumina‑U2 上传昇腾训练的检查点：16B MoE、1B 激活参数，用多码本离散视觉表示连接图像理解、生成与编辑，也支持视频和三维内容理解。代码此前已公开，这次补上可下载的权重。

为什么值得关注：同一模型把看图、改图和生成放在一起，便于研究连续的视觉工作流；从只有代码走到可运行检查点，也让架构讨论有了可检验的对象。

适合谁看：研究统一多模态模型、图像编辑，以及国产算力训练与推理适配的开发者。

试试看

先核对模型卡中的运行条件，再从图像问答或单次编辑入手，观察同一对象在理解与修改之间能否保持一致。

注意点

当前公开的是 Ascend 目录权重，NVIDIA 版本与技术报告仍待发布；视频、三维理解不能写成视频或三维生成。

07GoogleUnited States2026-09-02 发布 / 2026-09-11 观察官方页面

GNM v3 让三维头像的表情可以逐项调节

发生了什么：Google 的 GNM v3 已提供可下载的参数化头部模型，能控制身份形状、表情和姿态，并单独处理眼睛、牙齿与舌头。权重发布记录在 9 月初，项目支持多种数值计算框架，代码与模型使用 Apache 2.0。

为什么值得关注：对虚拟角色来说，表情不只是生成一张脸，还需要能反复修改和组合的控制参数。公开模型让研究者更容易比较拟合、动画与感知流程。

适合谁看：制作虚拟头像、研究面部动画、三维视觉和人机交互的开发者与爱好者。

试试看

按模型卡下载头部参数，先调整单个表情或姿态，比较网格变化；熟悉后再尝试把多个控制参数组合成连续动作。

注意点

这是参数化三维头部模型，并非输入一句话就生成完整人物的视频工具；技术论文于 7 月发布，9 月开放的权重才是本次变化。

09OpenBMBChina2026-09-06 发布 / 2026-09-11 观察官方页面

MiniCPM5‑2B 提供本地智能体模型与多种格式

为什么值得关注：小模型的价值在于把部分任务留在本机完成。

适合谁看：本地模型爱好者与端侧应用开发者。

试试看

从适合设备的量化版本开始，测试一项本地任务。

注意点

长上下文仍消耗内存；官方榜单只代表对应测试集。

06IBM / NASAUnited States / Japan2026-09-10 发布 / 2026-09-11 观察官方页面

IBM 与 NASA 开放月球基础模型

发生了什么：IBM 与 NASA 公布开放的月球基础模型、数据集和技术报告，整合美国、日本任务积累的多种月球观测数据。模型面向陨石坑识别、火山活动研究与极区冰资源探测等任务，尝试适配不同空间尺度和观测角度。

为什么值得关注：基础模型的应用正在从地球遥感延伸到月球。共享预训练表示，有望减少每个科学任务从头整理数据和训练模型的重复工作。

适合谁看：对太空探索、遥感模型、行星科学和跨模态科学数据感兴趣的读者。

试试看

从官方文章里的月表图像与任务示例看起，再阅读公开数据和模型说明，比较不同观测方式各自揭示了什么。

注意点

这是科学研究模型的开放，不等于已发现新的冰储量或已用于真实探月决策；示例指标只说明相应数据集上的表现。

12OpenAI / de la Fuente LabUnited States2026-09-10 发布 / 2026-09-11 观察官方页面

从灭绝生物基因组里寻找抗菌分子线索

发生了什么：研究团队结合自有模型、ChatGPT 与 Codex，整理现生及灭绝生物的基因组数据，协助提出假设、编写程序和分析候选分子。

为什么值得关注：有趣之处在于用今天的计算工具探索远古生命信息。

适合谁看：对生命科学与 AI 交叉研究好奇的读者。

试试看

注意点

候选分子不是获批药物，仍需要实验和临床验证。
