RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Microsoft VibeVoice ASR Streaming美国 / 全球2026-09-02 发布 / 2026-09-07 观察官方模型页

VibeVoice 把“谁说了什么”带进流式转写

发生了什么：微软公开 VibeVoice-ASR-Streaming-7B 权重与代码。这款 7B 语音识别模型一边接收音频，一边输出带说话人归属的转写结果，还支持自定义热词；官方模型页列出中文、英文、日文、韩文等十种语言。

为什么值得关注：实时会议与语音 Agent 最难处理的往往不是把声音变成字，而是保持“谁在说话”、专有名词和当前轮次不串线。把说话人识别与流式转写放进同一模型，能缩短后处理链。

适合谁看：会议纪要、客服质检、实时字幕、访谈整理和语音 Agent 团队。

试试看

用两人交替发言、一次重叠说话和五个行业热词组成短音频，在官方演示或本地代码中核对说话人切换、热词命中与延迟。

注意点

MIT 许可与公开权重已核验；十语言支持来自官方模型页。本期没有独立测量实时因子、重叠语音准确率或不同口音表现。

02Qwen-Drive 1.0 4B中国 / 全球2026-08-27 发布 / 2026-09-07 观察官方模型页

Qwen-Drive 用 4B 模型同时看路、问答与规划

发生了什么：Qwen-Drive 1.0 在 Qwen3.5-4B 主干上加入鸟瞰感知头与基于流匹配的规划专家，用同一套 4B 模型完成三维检测、占用与地图感知、视觉问答和车辆运动规划。官方同时开放模型权重、代码与 Apache-2.0 许可。

为什么值得关注：自动驾驶模型常把感知、语言理解与规划拆成多段管线。这个小体量方案把三者拉进统一骨架，给端侧机器人和车载研究提供了更容易复现实验的起点。

适合谁看：自动驾驶、移动机器人、具身智能、仿真评测与边缘推理团队。

试试看

先复现官方样例，再把同一段行车数据分别交给视觉问答与规划任务，检查对象、车道语义与轨迹是否前后一致。

注意点

架构、权重与许可已核验；官方基准未由本期复测。4B 指主干规模，不应理解为完整训练与部署链只需 4B 资源。

03InclusionAI LLaDA-Image中国 / 全球2026-09-04 发布 / 2026-09-07 观察官方开源发布GitHub Stars 147许可证未声明

LLaDA-Image 用一套 6B 权重兼做生成与编辑

发生了什么：InclusionAI 开放 LLaDA-Image 的推理代码与模型权重：同一个 6B 扩散语言模型兼做文生图和图像编辑，基础版使用 50 步，Turbo 版压到 4 步，并把中英文文字渲染列为重点能力。

为什么值得关注：生成与编辑共享模型，意味着设计工具可以把“先出图、再局部改动”放进连续对话，不必在两套模型之间搬运状态。4 步版本也更适合交互式迭代。

适合谁看：视觉创作工具、广告素材、中文排版图、图像编辑和多模态 Agent 团队。

试试看

注意点

模型页标注 Apache-2.0，权重与推理代码可取；训练代码仍写着即将开放，因此不能称为完整训练配方已经开源。4 步速度与质量尚未独立复测。

04IFM K2-Horizon MoVA美国 / 全球2026-09-01 发布 / 2026-09-07 观察官方模型页

K2-Horizon 用 4B 激活参数承接 512K 上下文

发生了什么：IFM 发布 K2-Horizon-MoVA-36B-A4B 最终权重。模型总参数 36B、每个 token 激活约 4B，并提供 512K 原生上下文；其 MoVA 路由会按 token 在多种注意力机制间选择。

为什么值得关注：长上下文模型的压力不仅来自参数总量，还来自每个 token 真正经过多少计算。按 token 路由注意力与专家，为长文档 Agent 提供了另一种效率取舍。

适合谁看：长文档检索、代码仓库理解、研究 Agent、推理服务和模型架构团队。

试试看

用一组短任务和一组超长资料分别测试首 token 延迟、吞吐、显存占用与答案可追溯性，不只比较上下文标称长度。

注意点

最终权重与 Apache-2.0 许可已核验；训练代码、数据和中间检查点在模型页仍标注将来开放。512K 是官方标称，本期未做压力测试。

05Viggle Animate加拿大 / 全球创作2026-08-31 发布 / 2026-09-07 观察官方模型页

Viggle Animate 只重画一帧就替换整段角色

发生了什么：Viggle Animate 让用户先在视频的一帧里重画人物，再把这个新角色传播到整段视频，同时保留原动作、镜头和节奏。官方说明它不依赖外接姿态估计、分割器、脸部跟踪器或文本编码器。

为什么值得关注：角色替换从“重新生成整段视频”转向“一帧定义身份、整段继承运动”，更接近剪辑师能控制的工作方式，也降低连续修订的成本。

适合谁看：短视频、广告预演、虚拟角色、舞蹈内容和视频编辑工具团队。

试试看

在公开演示中挑一段快速转身并带遮挡的视频，只改首个代表帧，重点检查手部、边缘、被遮挡后重现的身份与镜头一致性。

注意点

26 秒生成 124 帧及 6.1 倍提速均为厂商测试，未独立验证；模型采用 MiniMax H3 社区许可。

06Video DeltaNet VDN-H3全球研究2026-09-02 发布 / 2026-09-07 观察官方开源发布GitHub Stars 303许可证 Apache-2.0

Video DeltaNet 用线性分支压缩视频生成等待

发生了什么：Video DeltaNet 在 MiniMax H3 视频扩散骨架中加入独立线性注意力分支，并用两组 LoRA 适配器对齐原模型。项目开放 8 步与 50 步检查点、训练代码和推理代码。

为什么值得关注：视频加速不一定要重新训练整套大模型。给现有骨架增加可学习的低成本分支，有机会把研究成果更快嵌进已有生成管线。

适合谁看：视频生成基础设施、扩散模型研究、推理优化和创意工具团队。

试试看

用同一提示、分辨率和随机种子比较 8 步与 50 步版本，分别记录稳定段耗时、显存与运动连续性。

注意点

11.23 秒仅指 8 台 B200 的稳定去噪，不含加载、预热、编码和 VAE；权重继承 MiniMax H3 条款。

07CogEvol-4B全球开源2026-08-31 发布 / 2026-09-07 观察官方开源发布GitHub Stars 40许可证 MIT

为什么值得关注：小模型不再只输出讲稿，而是交付能播放、能点击、能离线保存的完整学习材料。对个人设备和内部知识场景，这比云端生成一段文本更接近可用产品。

注意点

模型页标注 Apache-2.0，代码仓库标注 MIT；约 2.4GB 是特定量化文件体积，不代表运行内存。训练样本规模与质量筛选来自项目方说明。
