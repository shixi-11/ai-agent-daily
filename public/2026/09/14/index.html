RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Intern-S2中国2026-09-13 发布 / 2026-09-14 观察官方公告

Intern-S2交付正式BF16权重

发生了什么：上海人工智能实验室在官方模型仓库交付Intern-S2-397B正式BF16权重，共188个分片；FP8文件已于9月11日上传。模型卡列出科学多模态推理、工具调用和长程智能体能力，并提供三种推理框架的部署指引。

为什么值得关注：这次可核验的变化是正式权重交付，而非旧预览版重新命名。研究团队可以据此检查文件、许可证和部署条件，开展自己的评测。

适合谁看：关注科学计算、多模态推理与大模型部署的研究和工程团队。

试试看

先阅读官方模型卡与部署指南，对照BF16和FP8的硬件需求，再用自己的科学问题做小规模验证。

注意点

模型卡标注Apache-2.0；能力成绩来自官方评测，不等于已验证科研结论，也不是普通电脑可轻松运行的模型。

02Meta Muse美国2026-09-08 发布 / 2026-09-14 观察官方公告

Meta Muse把个人助手放进独立虚拟机

发生了什么：Meta发布个人智能体Muse，并在美国逐步推出。它运行在带浏览器的独立Muse Secure VM中，可围绕长期目标持续处理工作；发送邮件、购买等敏感动作仍需用户批准。用户可以通过独立应用或WhatsApp与它交流。

为什么值得关注：助手从一次对话走向持续行动，独立运行环境和明确的审批点因此成为产品核心，而不只是后台实现细节。

适合谁看：关注个人助理、消费级智能体和跨应用工作流的产品团队。

试试看

通过官方介绍核对所在地区的可用状态，重点查看授权范围、操作审批以及任务中途如何交还控制权。

注意点

美国逐步推出不等于全球开放。Shop Pay、1Password及部分隐私增强方案仍属后续计划，不能当作当前能力。

07Pinocchio全球社区2026-09-10 发布 / 2026-09-14 观察官方公告

Pinocchio让表格数字带着计算来路

发生了什么：Pinocchio 0.1研究预览把来源、计算步骤和核验结果一起保留在表格输出中。对支持的数值，系统沿用来源中的操作数并记录推导，使确定性核验器能够回放计算。目前一次处理一个任务，输出为xlsx。

为什么值得关注：它把“相信生成结果”拆成可检查的来源与运算链。报价、预算和对账等数字密集工作，可以据此检查计算过程，而不是只看文字解释。

适合谁看：经常处理报价、预算、运营表格和数字核对的使用者。

试试看

先用不含敏感内容的小型表格体验，逐个查看数字对应的来源单元格、句子及计算步骤。

注意点

需要Google账户；核验范围是受支持的数字，不覆盖整段文字和判断，更不代表已消除所有幻觉。

03DeepSeek DeepSelect中国2026-09-10 发布 / 2026-09-14 观察官方开源发布GitHub Stars 327许可证 MIT

DeepSelect开放特定TopK加速内核

发生了什么：DeepSeek发布DeepSelect v1.0.0及算法解析，面向稀疏注意力索引和采样中的特定TopK计算。官方测试报告相对torch.topk有2至20倍加速，并明确输入类型、词表规模、步长对齐与topk不超过4096等适用条件。

为什么值得关注：它把常见算子拆到具体负载上优化。对推理团队而言，价值在于定位热点并复现收益，而不是把单个内核的倍数直接换算成整机提速。

适合谁看：维护推理引擎、稀疏注意力与GPU算子库的开发者。

试试看

阅读算法解析，使用仓库性能测试复现与自身输入接近的配置，同时检查输出排序、对齐和NaN处理要求。

注意点

2至20倍是官方特定内核测试结果，不代表端到端模型速度；更大的topk和不同负载不能直接套用。

04DeepSeek DeepJIT中国2026-09-08 发布 / 2026-09-14 观察官方开源发布GitHub Stars 300许可证未声明

DeepJIT统一CUDA与昇腾的编译流程

发生了什么：DeepSeek首次公开DeepJIT：一个轻量、仅头文件的C++20即时编译运行时，支持CUDA GPU与昇腾NPU。两种后端共用编译、缓存、加载和启动的接口流程，并提供内存缓存、磁盘缓存、延迟初始化与PyTorch集成。

为什么值得关注：算子库可以共用运行时基础设施，减少重复维护。不过共用接口不等于设备代码自动通用，后端编译器与启动参数仍需分别处理。

适合谁看：维护跨硬件算子扩展、编译缓存和推理基础设施的工程团队。

试试看

从官方示例理解后端依赖与缓存键设计，再检查共享目录是否满足原子重命名和文件同步等要求。

注意点

历史缓存预热与Python直接编译接口仍在开发中；CUDA和昇腾内核源码不能因此自动互换。

05Cohere Megakernel加拿大2026-09-08 发布 / 2026-09-14 观察官方开源发布GitHub Stars 85许可证 Apache-2.0

Cohere用常驻内核串起模型解码

发生了什么：Cohere公开North Mini Code的研究型推理引擎，用一个常驻CUDA内核组织完整解码前向过程，减少算子间启动与同步开销。官方单H100测试覆盖连续批处理和兼容OpenAI的接口，端到端测试报告相对vLLM v0.24提升1.25至1.41倍。

为什么值得关注：与更换模型不同，这条路线重排同一块GPU上的执行细节，展示小批量推理还能从调度和内存利用中获得多少收益。

适合谁看：关注低延迟推理、CUDA调度和模型服务性能的工程师。

试试看

先核对官方构建与测试指南中的模型、GPU、软件版本和批量设置，再比较完整请求而非只看解码指标。

注意点

目前只针对North Mini Code、单H100和特定配置调优；预填充仍使用独立内核，并会暂停解码，不是通用替代引擎。

06Claude Commerce Agents美国2026-09-01 发布 / 2026-09-14 观察官方开源发布GitHub Stars 2,812许可证 Apache-2.0

Claude商业示例分开购物与商家权限

发生了什么：Anthropic公开购物与商家两类智能体参考实现，提供零售、旅行、电信和娱乐四组演示。同一套提示、技能和工具契约可运行于Messages API、Agent SDK及Managed Agents；商家写操作先暂存，再由人批准。

为什么值得关注：购物建议和后台改价的责任不同。把角色、工具契约与审批分开，比给一个聊天助手接上所有接口更便于检查和集成。

适合谁看：搭建电商助手、商家后台和可审批业务流程的产品与开发团队。

试试看

先运行虚构数据演示，比较购物端与商家端的工具边界，再阅读后端映射和部署文档。

注意点

演示不下真实订单、不扣款、不修改线上商品；示例缺少认证，业务授权与合规规则需要部署方自行实现。

08Learnlance全球社区2026-09-13 发布 / 2026-09-14 观察官方开源发布GitHub Stars 4许可证 MIT
