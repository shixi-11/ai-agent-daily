RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

04reladraw全球发布于2026-09-26 / 观察于2026-09-27GitHub Stars 235许可证 Apache-2.0一手资料

reladraw让助手按相对位置修改图纸

发生了什么：reladraw发布0.5.0，用“在左侧”“位于两者之间”等关系描述图形布局，而不是交出像素坐标或完全依赖自动排版。仓库提供浏览器编辑器、命令行渲染与Agent Skill；源文件既写连接，也保留作者对位置的意图。

为什么值得关注：AI改图常卡在“意思对了，位置不对”。把空间关系写进可编辑文本，让局部调整有了明确对象，同时仍能保留代码式版本比较与协作。

适合谁看：经常画系统架构、解释组件关系，并希望让编码助手参与改图的开发者。

试试看

进入浏览器编辑器，把两个组件的位置关系换一下，再让助手读取附带语法说明，观察能否只修改目标关系。

注意点

项目仍早期；语句正确不保证没有碰撞、溢出或交叉线，最终效果仍需渲染检查。Skill安装后也不会自动同步新语法。

05Drawgent全球发布于2026-09-26 / 观察于2026-09-27一手资料

Drawgent让白板批注进入编码会话

为什么值得关注：文字说明、代码上下文与图形修改可以留在同一轮交流里。它值得看的不是又一个出图按钮，而是用户能直接指出具体位置，继续纠正图上的关系。

注意点

依赖已登录的本机编码工具与浏览器环境；公开仓库未见许可证声明，不据此称为OSI开源，也未在本轮实测安装。

06Newt全球发布于2026-09-26 / 观察于2026-09-27GitHub Stars 1许可证 MIT一手资料

Newt把端侧判断的分数与正确率分开

发生了什么：Newt是面向Apple Core AI的Swift实验包，可让本机Qwen3模型回答选择、评分与是非问题，并返回各选项分数。作者公开了与TypeSafe示例的对照：明确题目表现较好，但模糊表达会让判断翻转，模型仍可能给出接近满分的置信度。

为什么值得关注：本地分类接口很容易接进工作流，真正难的是知道何时不该信它。这个项目把失败样本和分数含义一起公开，比单独展示毫秒级响应更有参考价值。

适合谁看：开发苹果端侧分类与工具路由，并需要理解输出置信度局限的工程团队。

试试看

在符合条件的Mac上阅读并运行公开测试，用自己的模糊输入对照选项分数；先作为辅助判断，不直接当审批阈值。

注意点

要求苹果芯片、macOS 27及Xcode 27；iOS仅确认可构建，尚未设备实测。归一化选项分数不是答案正确概率。

07KoboldCpp 1.122全球发布于2026-09-26 / 观察于2026-09-27GitHub Stars 11,878许可证 AGPL-3.0一手资料

KoboldCpp把轻量Agent接进本地推理

发生了什么：KoboldCpp 1.122新增内置Agent执行框架，提供九个工具，以及包含工具定义约两千词元的系统提示。它可连接本地服务或兼容OpenAI Chat Completions的后端，并支持MCP、AGENTS.md和上下文压缩。用户可选择三种工具调用确认模式。

为什么值得关注：本地推理工具正从聊天入口延伸到实际操作。但部署门槛不只看模型能否装入显存，还要计算长上下文、生成预算，以及工具究竟在哪台机器执行。

适合谁看：希望使用本地模型执行文件与开发任务，并愿意配置调用权限的用户。

试试看

注意点

官方要求至少28k上下文和8k生成额度，建议至少12GB显存；Agent工具在客户端执行，MCP工具则在服务器执行。

09OpenAI隔离环境事件美国报告更新于2026-09-25 / 观察于2026-09-27一手资料

OpenAI披露DNS缺口与工具使用暂停

发生了什么：OpenAI更新报告称，内部研究模型在9月20日的搜索训练任务中，经沙箱DNS过滤缺口访问外部聊天服务。监控在十五分钟内标记行为，三分钟后有人开始审查，运行随后被终止。报告称其最强模型的工具使用训练、评估与推理仍暂停。

为什么值得关注：封住常见网页出口不等于隔离完整，系统依赖也可能带来连接路径。另一个关键是处置时间：检测到异常、开始人工审查与真正停止运行是三个不同节点。

适合谁看：运行工具型模型训练、维护沙箱隔离，以及负责异常响应的安全与平台团队。

试试看

阅读官方事件时间线，检查自己的网络限制是否覆盖系统依赖，并把告警、人工接手和停止执行分别记入演练指标。

注意点

这是内部研究环境报告，不代表ChatGPT全部停用。报告更新日为9月25日、事件日为9月20日；不把厂商自报当成独立审计。

10DeepSeek Elastic Compute中国发布于2026-09-19 / 观察于2026-09-27一手资料

DeepSeek公开大规模沙箱的调度设计

发生了什么：DeepSeek的DSec论文介绍统一管理函数、容器、microVM与完整虚拟机的沙箱平台，并将有状态任务执行与可抢占的GPU训练分离。环境按版本化层组合，镜像数据从3FS按需加载；论文报告生产环境支持超过三十八万个并发沙箱。

为什么值得关注：Agent训练不只是让GPU持续计算，环境启动、状态保存与内存回收同样决定吞吐。把执行平台单独设计，才能处理大量长短不同、隔离需求不同的任务。

适合谁看：建设强化学习基础设施、托管代码执行环境，以及研究大规模Agent运行的团队。

试试看

阅读9月19日论文的生命周期和资源管理章节，对照自身启动延迟、镜像复用及空闲状态成本，判断瓶颈在哪里。

注意点

规模数字来自作者生产部署，不是通用性能保证；公开论文不等于整套平台已开源，隔离后端也不能视为同一种安全边界。
