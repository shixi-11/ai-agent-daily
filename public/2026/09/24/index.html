RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01FLUX 3 Action欧洲发布于2026-09-23 / 观察于2026-09-24一手资料

FLUX把视频预测接到机器人动作上

发生了什么：Black Forest Labs于9月23日介绍FLUX 3 Action：70亿参数世界动作模型同时预测未来画面与动作，单次可返回32个动作。官方公开DROID、SO-101权重与训练代码，并接入LeRobot；同一模型还被微调用于射击、赛车及室内无人机仿真实验。

为什么值得关注：图像生成技术开始成为控制策略的底座。比演示更重要的是权重、训练配方与执行接口一起交付，让研究者能对照自己的机器人和任务复现。

适合谁看：研究机器人策略、世界模型及游戏智能体，希望在公开实现上继续实验的团队。

试试看

先阅读SO-101与DROID模型卡，再按LeRobot示例选择对应设备；游戏训练配方也已公开，可先观察动作预测与重新规划的关系。

注意点

代码为Apache-2.0，权重采用FLUX Kommunity自定义许可，不等于OSI开源；官方机器人与游戏结果来自特定任务，不能推广为通用成功率。

02Nemotron 3 Diarization美国发布于2026-09-23 / 观察于2026-09-24一手资料

Nemotron区分八人交谈中的发言时段

发生了什么：NVIDIA于9月23日介绍Nemotron 3 Diarization，开放一亿参数说话人分离模型，支持最多八人、重叠发言及流式处理。它输出匿名说话人活动与时间戳，可接入语音识别；官方还提供含预置对话、实时麦克风与文件上传的在线演示。

为什么值得关注：转写准确仍可能记错谁作了承诺。把说话人归属独立建模，能改善会议摘要和语音Agent记忆，也让语音识别与身份归属错误分别接受检查。

适合谁看：开发会议记录、多人语音助手、访谈检索和实时音频分析系统的团队。

试试看

在官方Space里先听预置多人对话，再对照时间轴中的插话与重叠片段；接入时同时评估转写文字和说话人归属，而非只看一种分数。

注意点

模型不识别真实姓名，也不独自产生转写；最低推荐0.32秒是输入缓冲，不是端到端延迟，网络、推理与语音识别还会增加耗时。

03LensVLM-9B美国权重公开于2026-09-23 / 观察于2026-09-24一手资料

苹果让模型先扫缩略页，再展开证据

发生了什么：苹果在北京时间9月23日公开LensVLM-9B权重，配套代码展示一种长文阅读方式：先把文字渲染成压缩页面图像，再通过学到的工具调用，只展开相关页的原文。实现提供5、10、15倍压缩配置，以及数据准备、演示和评测脚本；论文并非当天首次发布。

为什么值得关注：长上下文不必等于把每页全文都重新读一遍。这条路线把视觉概览与按需取证结合起来，值得观察它节省输入时，是否遗漏小字或跨页关系。

适合谁看：研究长文档问答、视觉文字压缩、检索策略与工具调用模型的开发者。

试试看

从官方仓库的多页问答演示开始，核对模型选择的页面是否包含真实依据，再用自己的文档比较不同压缩率与漏检情况。

注意点

本次是权重交付，不是新论文首发；模型采用Apple研究模型许可，代码另用Apple Sample Code许可，需分别核查使用条款。

04Gemini Connected Apps美国发布于2026-09-23 / 观察于2026-09-24一手资料

Gemini连接更多创作与生活应用

发生了什么：Google于9月23日开始向Gemini推出新一批Connected Apps。生产力类包括Airtable、Linear与Wispr AI，创作类加入Adobe、Picsart、Squarespace和Webflow；生活类覆盖找房、信用信息、健身和票务，可在设置中连接，再通过提及应用发起请求。

为什么值得关注：助手的价值取决于能进入哪些实际工作。此次扩展同时触及项目、设计和生活服务，连接之后的数据范围与可执行动作，比入口数量更值得逐项检查。

适合谁看：已经使用Gemini，希望串联项目管理、设计制作和日常安排的个人及团队。

试试看

先在Gemini设置里查看自己账户可见的应用，选一个常用工具连接；用可复核的小任务确认它能读什么、能改什么，再扩大工作范围。

注意点

公告说开始逐步推出，不保证所有账户同时可见；第三方服务可能另有订阅、地区和权限限制，连接成功也不等于每项操作都受支持。

05Pactto全球本轮产品展示于2026-09-23 / 观察于2026-09-24一手资料

Pactto把审片意见变成现场修改

发生了什么：Pactto在9月23日产品展示中推出面向人与Agent的持续创作房间。团队可把视频、图像、PDF和音频放进共享画布，一边讨论一边标注；助手利用素材与会话上下文提出修改、生成文档和整理任务，房间继续保存决策与版本信息。

为什么值得关注：创作速度提高后，来回解释意见可能成为更大的耗时。把讨论、素材和修改留在同一处，能减少交接损耗，但仍要区分建议、实际改动与最终批准。

适合谁看：经常远程审片、评设计稿或协调多方修改的创作者、广告团队与制作公司。

试试看

从官网免费入口建一个测试房间，放入自有素材并邀请同事；试一句明确的局部修改，检查画布结果、会话记录和审批状态是否一致。

注意点

免费版房间记忆仅限最近一次会话，跨会话记忆属于Pro；本文未实测全部功能，Dropbox与Air仍标注即将推出。

06Alexandria美国本轮产品展示于2026-09-23 / 观察于2026-09-24一手资料

Alexandria让助手先找数据源，再取数据

发生了什么：Firecrawl在9月23日展示Alexandria知识库，把官方API、授权出版商、专门索引和网站连接器放进同一入口。当前页面列出93个提供方、640项能力，支持通过MCP、CLI与API发现合适来源，再取结构化信息，而不只返回普通网页搜索结果。

为什么值得关注：搜索不到的信息可能藏在专用数据接口里。先选择来源再调用工具，有机会减少为每个数据商单独集成的工作，也让来源类别和收费边界更显眼。

适合谁看：建设行业研究、企业信息、政府数据与复杂检索Agent的产品和工程团队。

试试看

先浏览提供方目录，选择一个自己熟悉的数据源，比较直接官方查询与Agent返回的字段、更新时间和出处；再决定是否加入常用工具。

注意点

索引、官方API与授权出版商并非同一种证据；各能力可能单独计费，厂商声称的答案质量提升不应当作对所有任务的保证。

07ToneBird全球发布于2026-09-22 / 观察于2026-09-24一手资料

注意点

官网示例不是实测；自动回忆也可能过期，发送前仍需复核。

13MuJoCo Warp美国发布于2026-09-23 / 观察于2026-09-24一手资料

快讯：机器人仿真教程扩到2048个并行环境

发生了什么：NVIDIA于9月23日发布MJWarp迁移教程，把SO-101从单个MuJoCo场景迁到最多2048个并行GPU环境，逐步验证状态、批量运行与吞吐。

为什么值得关注：并行更多世界，与让单次动作更快不是同一件事。

适合谁看：机器人仿真与强化学习工程团队。

试试看

注意点

这是新教程而非新引擎首发；本篇没有训练机器人策略。

本期观察：把一段话交给正确的人，把一页证据展开在正确时刻，把一次修改留在共同的房间里：真正有用的智能，常体现在这些具体衔接上。
