RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01GPT-6 Sol与Luna美国发布于2026-09-22 / 观察于2026-09-23一手资料

GPT-6新增两档价格与能力选择

发生了什么：OpenAI于9月22日开放GPT-6 Sol与Luna，均支持图文输入和文本输出、105万上下文与12.8万最大输出。标准短提示计价中，Sol每百万输入与输出词元为2和10美元，Luna为0.1和0.5美元；两者支持推理档位与工具调用。

为什么值得关注：同系列提供更低成本的任务分工入口：复杂编程与高频小任务不必使用相同模型。真正该比较的是任务成功后的总成本，而非只看单价。

适合谁看：需要为编码、文档处理及批量Agent任务选择模型的开发者与产品团队。

试试看

用同一组任务比较Sol、Luna的成功率、重试次数与账单；使用工具时优先检查Responses接口，别只替换模型名称。

注意点

超过27.2万输入词元会触发长提示加价，缓存写入另有费率；Chat Completions的函数调用要求关闭推理，不能照搬旧配置。

02Claude Opus 5.5美国发布于2026-09-22 / 观察于2026-09-23一手资料

Opus 5.5把长任务成本继续压低

发生了什么：Anthropic于9月22日发布Opus 5.5，称其多数工作达到Fable 5.1水平。每百万输入、输出词元分别4和20美元，缓存读取0.2美元；公司称默认设置下典型任务总成本较Opus 5下降40%，输出速度提升超过30%，并公布行为审计与外部评估信息。

为什么值得关注：Agent成本同时来自单价、使用词元和反复尝试。价格下降之外，完成长任务所需步骤是否减少，更值得在真实工作负载中检验。

适合谁看：长期使用编程助手、跨仓库修改与知识工作自动化的开发者和企业团队。

试试看

选一项有现成回归测试的迁移工作，对照Opus 5与5.5的耗时、修改范围和总账单，再决定是否更换默认模型。

注意点

40%成本降幅与速度数据来自厂商测试，不保证每个任务相同；Fast模式价格另算，生物与网络安全部分访问仍有验证条件。

03MiMo-V2.6中国权重与模型卡公开于2026-09-22 / 观察于2026-09-23许可证 MIT一手资料

小米开放MiMo全模态强化学习权重

发生了什么：小米在北京时间9月22日公开MiMo-V2.6模型卡与权重。Pro-RL为1.02万亿总参数、420亿激活参数，Flash-RL为3090亿和150亿；两者支持文本、图像、视频、音频及百万上下文。另有基于Qwen3.5-9B的蒸馏SFT检查点，发布页标注MIT许可证。

为什么值得关注：开放的不只是模型调用入口，也包括不同规模的研究起点。统一混合强化学习与组内轨迹评分，让训练方法能被拆开检查，而非只看榜单。

适合谁看：研究多模态Agent、长流程强化学习及开放模型部署的研究者和工程团队。

试试看

先读Pro与Flash模型卡，对照硬件要求、训练配方和评测条件；资源较少可从9B检查点研究任务迁移，而非直接部署万亿模型。

注意点

9B版是监督微调检查点，不是完整强化学习成品；模型自报成绩包含内部测试集，百万上下文与低激活参数也不等于低显存需求。

04Grok 4.7美国发布于2026-09-21 / 观察于2026-09-23一手资料

Grok 4.7开放API与分档推理

发生了什么：xAI于9月21日开放Grok 4.7 API，提供50万上下文、图文输入和文本输出，支持四档推理强度。提示少于20万词元时，每百万输入、缓存输入和输出分别2、0.5和6美元。两倍词元速率的Fast版本目前仅由Cursor与Grok Build提供。

为什么值得关注：模型名称相同，并不代表各入口拥有相同速度与价格。面向Agent的选型应把接口、长上下文费率及推理强度放在同一张比较表里。

适合谁看：比较编程与知识工作模型、维护多供应商路由的产品和基础设施团队。

试试看

先用固定提示与相同推理档位测试公开API，再单独比较合作产品的Fast入口；长文任务同时记录输入长度和实际账单。

注意点

超过20万提示词元会提高费率；Fast不在公开API提供，官方未设文本输出上限也不等于没有上下文、额度或费用约束。

05Hy Image3.5 preview中国发布于2026-09-22 / 观察于2026-09-23一手资料

混元图像预览版支持五图连续编辑

发生了什么：腾讯9月22日发布Hy Image3.5 preview，支持文生图、图生图、最多五张参考图和基于历史上下文的连续编辑，最高输出2K。官方重点展示中英文小字、复杂版式及主体一致性；腾讯云中国区API对2K及以下输出按每张0.15元计费，输入不收费。

为什么值得关注：多参考图和连续编辑适合把一张海报扩成成套物料。成本降低能增加修改空间，但真正的交付标准仍是文字准确、主体稳定和改动范围可控。

适合谁看：制作商品素材、信息图、营销物料与影视人物场景资产的创作者和产品团队。

试试看

从官方AI Studio入口，用自己的五张素材测试组合关系，再连续修改局部文字与材质，检查无需改变的部分是否被保留。

注意点

当前是preview而非正式版，2K不是4K；官方盲测与合作方反馈不能替代自有素材验收，产品入口和云API收费也应分别确认。

10relore全球发布于2026-09-21 / 观察于2026-09-23GitHub Stars 6许可证 Apache-2.0一手资料

relore让编码助手先找到别人做过的工作

发生了什么：Hugging Face于9月21日介绍relore，把GitHub议题、评审与合并请求连到当前代码。它区分维护者决定、贡献者判断和机器人评论，可查询正在进行的修复，也能从代码行追到相关讨论。查询在本地完成，只有摄取和刷新索引时连接GitHub，采用Apache-2.0许可证。

为什么值得关注：仓库记忆不只是更多文本。谁做了决定、是否已有修复、理由对应哪段代码，会直接影响Agent是否重复劳动，以及能否理解维护者的真实要求。

适合谁看：维护历史较长的开源仓库、代码审查助手与团队知识检索工具的开发者。

试试看

先索引一个熟悉的仓库，从已解决议题查询在途修复和原始评审；检查角色与时间是否正确，再让助手依赖检索结果。

注意点

本地查询不等于索引永远最新；作者的单次节省词元案例不能当作普遍收益，仍需检查权限、摄取范围与遗漏讨论。

11Unreal Agent全球发布于2026-09-22 / 观察于2026-09-23GitHub Stars 905许可证 MIT一手资料

Unreal Agent把工具等待移出模型回合

发生了什么：Unreal Labs于9月22日介绍异步Agent执行框架：工具启动后立即记为进行中，完成时再写入结果并唤起模型，用户可在等待期间转向任务。项目提供Go库、命令行运行器与Harbor评测接入。作者在Astra xhigh对照中报告更低成本，并公开运行记录链接。

为什么值得关注：减少等待、轮询和冗余工具返回数据，也可能比换模型更有效。执行框架决定一次模型调用之间能完成多少工作，值得与模型能力分开测量。

适合谁看：建设长流程Agent服务、工具调度层与编码评测环境的基础设施工程团队。

试试看

阅读事件日志与异步工具示例，再用相同模型、任务和推理档位对照现有框架，同时记录成功率、词元与真实耗时。

注意点

节省最高40%是作者特定对照结果，不代表所有任务；部分供应商不接受同一调用的进行中及最终双结果，接入前要验证兼容性。

14混元Batch Size Scaling中国发布于2026-09-22 / 观察于2026-09-23一手资料

快讯：强化学习增大批量，未必更快达标

发生了什么：腾讯9月22日研究将强化学习的样本效率与系统吞吐一起比较。固定硬件实验中，最佳GRPO配置达到同一验证目标的时间缩短29%，但过大批量反而变慢。

为什么值得关注：训练更快要看达到同一质量的时间，而非只看吞吐。

适合谁看：强化学习训练与算力规划团队。

试试看

阅读学习率重新调参方法，对照累计样本数和达标耗时。

注意点

29%来自特定模型与任务，不能推广为任意训练的固定收益。

本期观察：模型价格、执行回合与训练吞吐，都只是成本的一部分。把比较落到同一质量目标，才能知道省下的是浪费，还是必要的工作。
