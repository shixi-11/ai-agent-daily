RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Gemini 3.8 Live Avatar美国发布于2026-09-24 / 观察于2026-09-25一手资料

Gemini让实时助手有了动态形象

发生了什么：Google于9月24日推出Gemini 3.8 Live with Live Avatar，在实时对话中同步生成声音与视频形象。它能边交谈边异步调用工具，并支持97种语言的口型同步；当前已进入Gemini Enterprise，自定义参考图形象仍需企业白名单。

为什么值得关注：虚拟接待不再只是先生成答案、再播放头像。持续对话与后台办事可以并行，值得检验的是等待工具结果时，角色能否准确交代进度而不是只保持热闹。

适合谁看：建设多语言客服、数字接待、交互讲解与企业语音Agent的产品团队。

试试看

先看官方酒店接待演示，再阅读Live API文档；测试工具等待、用户打断和切换语言时，声音、表情与实际业务结果是否一致。

注意点

企业可用不等于个人账户普遍开放；自定义形象需白名单，官方展示不能证明所有网络条件下的延迟与口型质量。

02Gemini 3.8 TTS美国发布于2026-09-23 / 观察于2026-09-25一手资料

Gemini语音生成可逐句导演表演

发生了什么：Google于9月23日推出Gemini 3.8 Flash TTS与Flash-Lite TTS。前者侧重角色声线设计，后者面向高频生成；两者均支持逐句控制节奏与情绪。新能力开始进入Gemini API及AI Studio，支持双人对白，企业API仍标注即将推出。

为什么值得关注：声音从固定预设变成可以保存和反复导演的角色资产。对播客、游戏和有声读物，能否跨段落保持人物一致，比一小段试听是否惊艳更有实际价值。

适合谁看：制作多角色音频、游戏对白、有声读物与规模化配音的创作者及开发者。

试试看

在AI Studio语音工作台写一段双人对话，分别指定语气与停顿；重复生成同一角色的不同场景，比较音色、重音和人物辨识度。

注意点

声线复刻需匹配的口头同意录音，部分地区不可用；声线混调尚未推出，不能把全部宣传能力都视作当前已开放。

03Qwen Decision Model中国发布于2026-09-24 / 观察于2026-09-25一手资料

千问决策模型直接返回判断概率

发生了什么：QwenCloud于9月24日新增decision-model-preview。调用者提交业务状态和多道分类、是否或评分题，模型在一次前向计算中返回结果与概率，分类和评分还带置信度，不生成聊天文字。官方接口采用System One协议，适用于工单分流、Agent路由与结果验证。

为什么值得关注：很多工作只需要一个可执行判断，不需要一段解释。把这类决策单独做成接口，可以减少文字解析环节，但仍需用真实业务数据检验概率是否可靠。

适合谁看：建设高频工单路由、内容分类、质量检查与Agent分工系统的工程团队。

试试看

先用历史工单同时询问部门、是否升级和严重程度，对照人工标签；从少量问题开始，记录错误类型及低置信度时的人工接管策略。

注意点

当前为预览模型，不支持流式、工具调用或联网搜索；示例延迟不是服务保证，置信度也不能直接当作实际正确率。

04WeVisDoc中国论文公开于2026-09-17 / 观察于2026-09-25一手资料

腾讯开放面向复杂页面的文档解析模型

发生了什么：腾讯WeVisDoc提供2B与4B权重，把页面图像转为结构化Markdown，同时保留LaTeX公式和HTML表格。9月17日公开的论文采用两阶段数据训练：先扩展版式与退化场景，再按剩余错误定向补数据。本期补报这套Apache-2.0模型与配套推理代码。

为什么值得关注：解析干净PDF容易掩盖真实扫描件的问题。它把模糊、退化和少见结构纳入训练诊断，让团队能分别检查文字、公式、表格与阅读顺序，而非只看总分。

适合谁看：处理扫描档案、科研文献、企业文档入库与复杂页面抽取的开发团队。

试试看

从官方仓库的单页示例开始，用同一批清晰页和退化页比较2B、4B；逐项核对表格结构与公式，并检查输出截断是否被漏当成成功。

注意点

论文日期为9月17日，并非今日首发；排名限于作者比较的端到端解析器，PDF需先转页面图，整体文档流程仍要自行搭建。

05Scholé Learn Anywhere全球本轮产品展示于2026-09-24 / 观察于2026-09-25一手资料

Scholé在真实网页旁陪你动手学

发生了什么：Scholé在9月24日展示Learn Anywhere浏览器扩展：学习者在真实工具里做项目，侧栏助手读取指定页面，给任务、视觉提示并检查进度。官网提供创建Agent、网站和笔记本的练习入口；用户自己操作，作品保留在自己的账户里，而不是只完成模拟题。

为什么值得关注：让AI代做与让人学会是两件事。把反馈放在真实界面旁，能缩短教程和实践之间的距离；更值得看的是，离开提示后学习者还能否独立完成。

适合谁看：学习新软件、搭建首个Agent或希望把培训变成实际产出的个人与团队。

试试看

从官网选一个自己没用熟的工具，先尝试完成一步再请求提示；结束后关闭侧栏重做关键操作，检查学到的是方法还是跟随指令。

注意点

练习入口可免账户起步，但扩展本身需要Scholé账户；当前支持英法德意四种语言，页面帧不保存不代表进度文字也不留存。

07minimi 2.0美国本轮产品展示于2026-09-24 / 观察于2026-09-25一手资料

08Whiteboard全球本轮公开展示于2026-09-24 / 观察于2026-09-25GitHub Stars 427许可证 MIT一手资料

Whiteboard让Agent在画布上解释代码

发生了什么：Whiteboard在9月24日公开展示面向人与Agent的软件设计画布。这个MIT桌面项目可连接Claude Code、Codex等工具，让助手画图解释设计，点击图中内容可跳到相关代码；它还提供语义差分和决策记录，目前有macOS与Fedora下载入口。

为什么值得关注：生成代码越快，理解改动可能越费时间。把设计、代码位置和决策依据放到同一处，有助于审阅者判断改动是否符合要求，而不只浏览一长串差异。

适合谁看：需要审阅Agent改码、讨论架构方案及追踪实现依据的软件开发团队。

试试看

先拿一组已完成的分支改动做试验，让助手画出接口和数据流；点击节点返回代码，再用决策记录核对它是否遗漏了关键约束。

注意点

当前不能在Whiteboard内编辑文件，跨仓库浏览支持有限；分享后的修改不会自动同步，需要重新分享，不能当作完整协作IDE。

09GitHub Fuzzing Taskflow美国发布于2026-09-24 / 观察于2026-09-25GitHub Stars 2许可证 MIT一手资料

GitHub让Agent沿覆盖率改进模糊测试

发生了什么：GitHub Security Lab于9月24日介绍开源Fuzzing Taskflow。它为C/C++项目识别入口、编写测试驱动、运行AFL++，再按覆盖报告补充输入与驱动。状态存入SQLite，测试语料跨轮次保留，崩溃经过缩减、重放和去重后形成待人工审阅的报告。

为什么值得关注：自动化的重点不是一次找到多少崩溃，而是把覆盖缺口变成下一轮行动，并保留已有进展。模型负责判断、工具负责执行的分工，也让流程更容易逐步检查。

适合谁看：维护C/C++库、希望扩大已有模糊测试覆盖或建立初始测试流程的工程团队。

试试看

按官方指南在一次性Codespace或虚拟机里选小型测试项目，先核对覆盖变化，再人工检查崩溃是否来自真实库缺陷而非测试驱动。

注意点

工具会直接执行模型选择的构建命令，不能放进高权限日常环境；模型报告和补丁仍需复核，崩溃数量不等于漏洞数量。

10Hugging Face Hub 2.0美国与法国发布于2026-09-24 / 观察于2026-09-25一手资料
