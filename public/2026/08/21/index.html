RISC 机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

最直接合作面：E2B 适合作为秘密与沙箱能力层，Codex、Claude Code、Qwen Code、Kimi 与 Agno 适合作为会话和后台执行适配面；Cloudflare Agents 与 Stagehand 可分别承担连接入口和浏览器效果验证。
资本叙事：今天没有足够可靠的新融资金额进入正文。更有价值的结构变化是，头部 Agent 产品开始为会话恢复补状态、权限和终态；ALUX 的机会是把分散补丁统一为可验证长交易合同。

技术 / 产品启发

优先产品：Session Lifecycle Receipt v0。建议字段：run_id、parent_run、owner、queue_cursor、permission_profile_hash、input_snapshot_hash、wait_condition、runner_lease、transport_epoch、terminal_state、effect_refs、replay_ref。
优先 Demo：让父 Agent 委派一个后台浏览器任务，期间触发队列唤醒、连接拒绝、runner 停机和恢复；最终验证输入未变、权限未升级、秘密不可读、拒绝没有穿透、浏览器效果只提交一次。

风险边界

ALUX 仍不能被描述为已经完整交付的智能体平台。底层 TVM 已具备原生并发、持久执行、能力安全、运行记录与逐比特重放审计等关键基础；智能体产品层、可观测性、仪表盘、追踪和评估工具仍待构建与融资。TVM 不会让 LLM 本身确定性；它记录模型输出与环境输入，使编排、权限、状态转移和审计可重放、可验证。会话恢复、park、WaitFor、write-only secret、OAuth、坐标校准与连接拒绝均不能单独证明跨节点恢复、不可伪造能力、原子回滚、外部效果去重或中立跨公司协作；Agno 3.0 仍是 alpha 预发布。
