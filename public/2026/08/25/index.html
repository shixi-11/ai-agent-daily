RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

02DeepSeek-V4-Pro-0813中国 / 全球开放权重2026-08-13 发布 / 2026-08-25 观察官方开放权重权重许可 MIT

DeepSeek-V4-Pro-0813 以 MIT 许可证开放模型权重

发生了什么：DeepSeek 发布 V4-Pro-0813 完整权重、编码脚本、本地推理说明与 DSpark 推测解码配置，支持 low、high、max 三档 reasoning effort；官方示例可在单台四卡 GB300 节点上通过 vLLM 或 SGLang 部署。

为什么值得关注：开放权重与可运行配方同时出现，让团队能独立检查 Agent 编码协议、推理成本和部署取舍。

适合谁看：评估开放权重 Agent 模型、超长输出或本地部署的团队。

试试看

先检查 encoding 测试与显存配方，再用小规模评测比较不同 reasoning effort 的时延、成本和工具表现。

注意点

官方基准含内部测试集，尚需独立复现；推荐配置需要高端多卡硬件，开放权重也不等于低成本部署。

03Tencent UI-Mate中国 / 全球开放权重2026-08-14 发布 / 2026-08-25 观察官方开放权重权重许可 Apache-2.0

腾讯开放 UI-Mate 27B 电脑操作 Agent 权重与运行代码

发生了什么：腾讯 HY Frontier 发布 UI-Mate-27B 的 Apache-2.0 权重、解析器与交互 Harness；模型仅凭任务指令、实时截图和历史记录生成鼠标键盘动作，并提供 vLLM 服务方式、完整轨迹回放及 9B 配套检查点。

为什么值得关注：电脑操作 Agent 终于出现可本地部署、可回放轨迹、可替换外部运行时的官方开放基线。

适合谁看：研究桌面自动化、GUI Agent、安全评测与人机确认流程的团队。

试试看

只在一次性虚拟机回放官方轨迹，逐步核对截图、结构化动作与应用终态，再决定是否接入真实桌面。

注意点

官方明确提示界面变化和提示注入会影响行为；基准成绩不保证任意环境可靠，敏感动作必须人工确认。

06Claude Code美国 / 全球开发者2026-08-24 发布 / 2026-08-25 观察官方发布

Claude Code 把循环、子 Agent 与合同价纳入运营面板

发生了什么：Claude Code 2.1.243 在 /usage 中拆出每个 loop 的运行次数与 token，在 /tasks 标明子 Agent 使用的模型和 effort，并允许企业把合同折扣写入成本面板；远程 MCP 断线后也会自动重连或明确失败。

为什么值得关注：长驻循环和子 Agent 一旦规模化，团队需要先看清谁在运行、用了什么模型、花了多少钱。

适合谁看：运营 Claude Code、远程 MCP、云模型合同价或后台循环的团队。

试试看

开一个短 loop 与两个不同模型的子 Agent，核对 /usage、/tasks 和合同价成本，再模拟 MCP 断线。

注意点

这些是可见性与恢复改进，不代表循环自动具备预算上限，也不证明所有 MCP 操作可以安全重放。

DeepSeek 把完整 Agent Harness 以 MIT 许可证开放

发生了什么：DeepSeek 首次公开 DeepSeek Harness：这是一个“万物皆插件”的 Agent 工作台，提供本地 Web UI、源码运行入口、插件发现与完整架构文档；项目仍处开发者预览阶段，并明确提醒后续会有破坏兼容性的变化。

为什么值得关注：大模型厂商不再只开放权重，也开始开放承载工具、界面与插件生态的完整 Agent 外壳。

适合谁看：想研究 Agent 工作台、插件架构或自建开发环境的团队。

试试看

先用 npx 在隔离目录启动 Web UI，再读架构文档，确认插件能接触哪些文件、网络与模型接口。

注意点

MIT 代码可本地运行，但仍是开发者预览；高关注度不代表接口稳定、安全边界完备或适合直接上生产。

04Meta MoE-ViE美国 / 全球研究2026-08-12 发布 / 2026-08-25 观察官方开放权重权重许可 CC BY-NC 4.0（非商业）

Meta 开放 MoE-ViE 视觉编码器，但只限非商业研究

发生了什么：Meta 发布 MoE-ViE-H14-448 权重与代码：35 亿总参数中每个 token 只激活约 11 亿参数，用共享专家加路由专家处理图像、视频分类与检索；模型需要 CUDA，并在运行时编译 Triton MoE 内核。

为什么值得关注：视觉编码器开始借稀疏专家降低每次计算量，但开放程度必须和许可证限制一起看。

适合谁看：研究多模态检索、视频理解、稀疏视觉模型和算力效率的团队。

试试看

用官方 demo 复测一组图像与视频检索任务，同时记录总参数、激活参数、显存和 Triton 编译开销。

注意点

权重采用 CC BY-NC 4.0，仅限非商业研究，并非 OSI 开源；表中成绩来自官方零样本评测。

Black Forest Labs 为 FLUX 3 补齐八个视频 Skills

07AI with Authority美国 / 全球研究2026-08-21 发布 / 2026-08-25 观察一手研究

一个人用 AI Agent 和机器证明把 RISC-V 芯片送去流片

发生了什么：论文报告一名研究者在五周内指挥一组 AI Agent，从应用代码一路生成经验证的编译器、执行器和 RISC-V 处理器，并送入社区硅片流片；数学论断交给 Lean 4 与 SAT 校验，错误账本累计记录 256 次拦截。

为什么值得关注：当 Agent 产出速度超过人工复核能力，机器可验证产物可能从昂贵附加项变成扩张前提。

适合谁看：研究形式化验证、硬件设计、多 Agent 协作和高风险自动化的团队。

试试看

先读论文的证明链和错误账本，挑一个小模块复现“Agent 生成、证明内核裁决、人工只审目标”的流程。

注意点

这是单个研究案例，作者自报没有人工审证明；芯片完成流片不等于规模制造、系统性能或方法已独立复现。

研究观察：这一期最值得记住的不是某个分数，而是开放与验证正在同时扩张：能拿到权重、代码和 Skill 只是起点，许可边界、运行权限、错误账本与机器证明决定它能否进入真实生产。
