RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

AI Agent雷达

结构化输出

决策模型减少长回答

Decisions和Decido把分类与评分从长回答中拆出，Craft先规划视觉结构。输出更贴近任务，不代表概率、文字或布局已经自动正确。

权限分层

授权开始独立于模型

1Password把凭据留在密码库，Model Vault验证推理环境，Skills转向中立治理。三者分别处理登录、计算和规范，不能互相替代。

可检查结果

工作入口保留人工检查

World展示代码差异，MarketMee提供发布前复核，ForTy输出分类概率。交互越直接，越需要让读者找到结果背后的限制和证据。

01OpenAI美国2026-10-22 发布2026-10-23 观察官方一手来源

决策接口正式开放，一次可问四百个问题

发生了什么：OpenAI将基于GPT-6 Luna的Decisions API转为正式可用，单次问题上限从200增至400。新版支持直接传入结构化数据、在单个问题中加入图片，并对重复共享输入提供提示缓存；返回的是类型化答案与概率，不需要先生成一段解释。

为什么值得关注：高频分类、分流和评分可以从长回答中拆出来单独处理。价值不只是少输出文字，还在于问题是否独立、选项是否清晰，以及低置信结果能否交回人工。

适合谁看：搭建客服路由、内容分类、图片检查与Agent动作选择的开发团队。

试试看

用一份已有标注的数据比较旧版与正式版，记录准确率、缓存命中和总成本；相互依赖的问题应分成多次请求。

注意点

共享缓存前缀至少1024个token，问题里的内容不计入；置信分数不是正确率保证，输入与缓存写入仍有费用。

02Canva澳大利亚2026-10-22 发布2026-10-23 观察可信媒体报道

Canva新模型先规划版式，再生成图片

发生了什么：据TechCrunch与The Verge的10月22日报道，Canva推出自研图像模型Craft：先规划元素位置、比例、层级与文字，再生成最高2K图片，支持30种画幅。报道确认用户可从Dream Lab进入，API与MCP等扩展入口仍需区分后续安排。

为什么值得关注：设计任务常同时要求文字可读和元素关系准确，两阶段生成试图先解决这层结构问题。它与把图片转换为可编辑图层的工具配合，但生成图片本身不等于已得到完整设计源文件。

适合谁看：制作海报、社交配图和信息图，希望减少版式返工的创作者与设计团队。

试试看

从Canva的Dream Lab选择Craft，用同一段含标题、数字和相对位置的需求比较结果，再检查文字与局部修改。

注意点

上述能力来自两家媒体对发布的报道，不是本刊实测；最高2K不能称原生4K，API与更快版本不应当作已经全面开放。

031Password加拿大2026-10-22 发布2026-10-23 观察官方一手来源

密码管理器替Agent完成获准登录

发生了什么：1Password发布面向个人Agent的登录协作平台。Agent先证明身份，用户在自己的设备上看到所需凭据与用途并决定是否批准，再由1Password直接填入登录表单。公告列出多家合作方，但Claude Duet的对应集成仍使用“即将”的表述。

为什么值得关注：把批准登录与交出密码分开，能减少凭据进入模型上下文的机会。不过登录完成之后，Agent仍可能看到账户内容；登录保护不能代替站内动作权限和审批。

适合谁看：希望让个人助手使用既有账号，又不愿把密码交给模型的用户和产品团队。

试试看

先核对自己所用Agent的集成开放情况，再用低风险账号检查身份提示、批准入口与退出方式，不按合作名单推断全部可用。

注意点

厂商描述的是凭据不暴露给模型，并非账户内容不可见；各集成进度不同，授权后的操作范围仍须在产品中确认。

04NVIDIA美国2026-10-22 发布2026-10-23 观察官方一手来源

GR00T开放苹果取放任务专用权重

发生了什么：英伟达模型卡将GR00T N1.7的一个苹果取放检查点标为10月22日发布。它面向宇树G1，使用402次演示训练，提供三个Safetensors权重分片、配置与归一化统计；名称中的15000是保存步数，40000是余弦学习率计划长度。

为什么值得关注：专用检查点让机器人研究更容易对照具体任务、数据和训练设置，而不只看通用演示。它的价值是可复现的适配起点，不能外推为任意机器人都能稳定抓取。

适合谁看：研究具身模型微调、机器人动作表示与任务复现的开发者和实验团队。

试试看

从模型卡核对G1输入、动作维度与兼容运行实现，先检查数据和归一化设置，再安排隔离环境中的受控验证。

注意点

这是约30亿参数的任务微调模型，不是新一代通用基座；权重适用NVIDIA Open Model Agreement，不能笼统称为OSI开源。

05Decido全球2026-10-22 公开展示2026-10-23 观察作者一手来源GitHub Stars 0许可证 Apache-2.0

Decido把结构化判断放到笔记本CPU

发生了什么：独立项目Decido公开展示本地决策模型与兼容Jev格式的接口。它基于Gemma 4的26B-A4B模型微调，以八位GGUF运行，回答是非、分类和分级问题；作者给出的安装路径面向macOS与Linux，建议约30GB内存，单次输入约16K token。

为什么值得关注：把文档留在本机处理提供了一种不同于托管接口的选择。代价是内存与等待时间；决策模型仍要用自己的样本校准，而不是因为输出了概率就直接用于自动批准。

适合谁看：需要离线文档分类、愿意核对复现实验与本地部署成本的开发者。

试试看

先用少量已知答案测试分类和边界样本，再检查选项顺序变化；按模型卡使用配套运行时，不能只加载GGUF就假定校准生效。

注意点

优势依赖同领域训练数据，排除这些训练集后不再成立；部分评测使用GPU，Jev取自外部成绩，非全程CPU公平对照。

06AgentIntersect World全球2026-10-22 公开展示2026-10-23 观察作者一手来源GitHub Stars 1许可证 MIT

代码仓库变成可游览的三维城市

发生了什么：AgentIntersect World公开预览把本地仓库呈现为三维城市，可连接自己已安装的Claude Code、Codex、Hermes或OpenClaw，最多带入四个Agent。工作流保留分支、差异与验证结果，也能用描述调整环境外观；当前提供Windows和Linux版本。

为什么值得关注：空间界面给多个工作对象提供了位置感，但是否有用仍取决于代码变化能否清楚检查。它把探索、讨论和执行放在同处，并没有替代底层Agent或增加模型能力。

适合谁看：喜欢可视化工作空间、经常在多个编码Agent之间切换的个人开发者。

试试看

在备份过的测试仓库中安装公开预览，先连接一个已有Agent，确认差异和验证结果能读清，再增加其他角色。

注意点

这是单人本地工作空间，不是多人在线服务；本地优先不等于模型离线，账户另备，Windows安装包尚未签名。

09WhatYouSay全球2026-10-22 公开展示2026-10-23 观察作者一手来源GitHub Stars 0许可证 MIT
