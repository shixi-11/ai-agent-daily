RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Kimi中国2026-10-24 发布2026-10-24 观察官方一手来源

Kimi新版扩展三维创作与长程工作

发生了什么：月之暗面发布Kimi K3.1 Pro及Highspeed版本，提供百万token上下文，已接入网页、应用、Work、Code与API。公告展示代码、参数化建模和财务研究能力，3D Make可在线预览编辑；完整模型权重计划11月4日前发布。

为什么值得关注：模型改进开始与具体制作入口一起交付：从草图到三维资产，再到可继续修改的工作结果。API可用与权重开放是两件事，团队现在能试服务，但还不能据此安排本地部署。

适合谁看：需要长程编码、三维原型与跨文档财务分析的开发者和专业用户。

试试看

在Kimi中用一个小型参数模型测试修改与导出，或在API选择Pro与Highspeed对照完成时间、成本和结果质量。

注意点

提速与基准成绩来自厂商测试，不代表所有任务；企业管理员须开启访问，权重仍待发布，生成的财务数字需逐项核对。

02MiniMax中国2026-10-23 发布2026-10-24 观察官方一手来源

MiniMax新模型从API走向权重开放

发生了什么：MiniMax M3.1 Flash的官方模型仓库已出现48个主权重分片、DSpark草稿头和本地部署说明。10月23日提交确认了权重开放这一新变化；它不同于10月19日的API上线，也不是把模型页更新时间当作首次发布日。

为什么值得关注：可下载权重让团队能够自行研究推理部署与基础设施适配，不再只比较托管接口。不过下载入口不等于低门槛运行，模型规模、精度格式与配套引擎仍决定实际成本。

适合谁看：评估开放权重模型、自托管推理和多模态Agent基础设施的团队。

试试看

先阅读官方模型卡与本地部署命令，核对硬件、运行时和权重格式，再选择小规模验证任务；不要直接套用旧版配置。

注意点

权重采用MiniMax Community自定义许可，不能称为OSI开源；本期确认文件与说明已公开，没有实测吞吐或部署成本。

03Tencent Youtu-LLM-A7B-Base中国2026-10-21 发布2026-10-24 观察官方一手来源

腾讯开放七十亿激活参数的视觉语言底座

发生了什么：腾讯公开Youtu-LLM-A7B-Base权重与定制推理代码。这个视觉语言MoE模型约有1200亿总参数，每token激活约70亿，支持262144-token上下文；模型仓库列出24个权重分片及MTP权重。

为什么值得关注：它为图文理解研究提供了可自行部署的预训练底座，而非只能调用的服务。较少激活参数不等于只需装载一个70亿参数模型，部署仍须容纳完整权重。

适合谁看：研究多模态预训练、长上下文和稀疏模型推理的团队。

试试看

先阅读模型卡，再按Transformers或仓库专用SGLang适配器运行小规模文本续写和图像输入测试。

注意点

这是Base模型，不是即用型聊天助手；采用Youtu自定义许可。加载需要信任远程代码，模型卡提醒高并发图像请求不要开启重叠调度。

04Block Dessa加拿大2026-10-23 公开展示2026-10-24 观察作者一手来源

Dessa只听人类谈话，学会边听边说

发生了什么：Block的小型研究团队展示Dessa全双工语音模型：官方称其从人类谈话音频直接训练，不使用文本或预训练模型。演示包括插话、笑声和音量调整，也展示与GPT-Live对话；网页目前提供录音与候补名单，并邀请少量安全研究者提前访问。

为什么值得关注：语音不只是文字的另一种包装。停顿、重音和接话时机可以成为模型直接学习的对象，这条路线值得观察，但自然的声音表现不能直接证明知识准确性或情绪理解。

适合谁看：研究实时对话、语音交互与声音表达的开发者、设计师和音频创作者。

试试看

先听官方双轨对话片段，比较打断和回应时机，再查看候补入口；把录制演示与自己能实际使用的功能分开判断。

注意点

纯音频训练和本地Mac运行能力均为团队陈述，尚无公开权重可供复现；候补登记不等于立即开放，也不是已上线通用助手。

05Anthropic美国2026-10-23 发布2026-10-24 观察官方一手来源

企业Claude把聊天与云端执行合在一起

发生了什么：Anthropic将统一的聊天与Cowork体验正式扩展到Enterprise。用户可在同一对话中提问或交付项目，代码与文件工作在云端独立虚拟机继续执行，关闭电脑后仍可推进；管理员新增Efficient模式，将模型使用限制在Sonnet与Haiku。

为什么值得关注：入口统一减少了用户先选工具的负担，也把成本与权限管理推给组织设置。真正需要评估的是长任务用了多少资源、跨设备如何接续，以及既有企业控制能否完整保留。

适合谁看：准备把聊天助手推广为团队文档、分析和交付工具的企业管理者。

试试看

由管理员检查组织设置，用一项可中断的文件任务验证云端接续，并比较Efficient模式与其它模型的交付质量和用量。

注意点

采用特定零数据保留、HIPAA配置或客户自管密钥的组织仍保持原配置；按用量计费，长任务可能消耗更多token。

06CleanYourTV全球2026-10-17 公开展示2026-10-24 观察作者一手来源GitHub Stars 27,904许可证未声明

编码Agent替电视整理主屏与预装软件

发生了什么：CleanYourTV把作者10月17日公开的电视改造整理成提示、工具与设备清单。编码Agent通过同一网络上的Android调试桥备份设置、停用不需要的软件，再安装简洁启动器；主要面向Android TV和Google TV，保留恢复路径。

为什么值得关注：它把编码助手带进家里的既有硬件，不需要另买一台AI设备。值得借鉴的是先调查机型、备份与逐步核验，而不是把一份停用清单不加检查地复制到所有电视上。

适合谁看：熟悉设备调试、希望减少电视主屏广告与预装干扰的动手用户。

试试看

先读对应机型清单与恢复说明，再在自己的设备上核对要保留的投屏、语音和更新功能；完成后关闭不再需要的调试入口。

注意点

不是所有电视都支持：Tizen与webOS不同，Fire TV功能受限；停用系统组件可能影响功能，作者的兼容清单不等于逐台保证。

07Photoshop MCP全球2026-10-23 公开展示2026-10-24 观察作者一手来源GitHub Stars 0许可证 MIT

让Agent在Photoshop里逐层修改图片

发生了什么：独立项目Photoshop MCP公开展示通过AppleScript控制Mac上的Photoshop，可读取图层、调色、选主体、加蒙版与导出。每次编辑合成一个撤销步骤，首次修改前建立检查点，并把修改前后的预览与直方图交回Agent。

为什么值得关注：比起只交付一张合成图，这类桥接保留了熟悉的图层与历史记录。价值在于让自然语言操作留下可检查的过程，但仍需人确认画面意图，自动撤销也不能代替独立备份。

适合谁看：已有Photoshop授权，希望试验语言驱动修图与批处理的Mac用户。

试试看

用一次性照片按源码方式安装，先做曝光调整、查看结果再撤销，验证图层是否保留；当前只明确测试过Photoshop 27.11.0。

注意点

不支持生成式填充、画笔或三维；预览可能发送给模型服务商。本地执行不等于图片不外传，现有DMG尚未公证。
