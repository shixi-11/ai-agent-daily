RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Gemini Agent美国2026-10-08 发布 / 2026-10-09 观察官方一手来源

Gemini把企业任务接成持续工作

发生了什么：Google宣布面向企业的Gemini Agent，把知识工作、内容制作和编码放进统一入口。云端执行可跨设备保留记忆，并调度临时子智能体；同事型Agent拥有独立身份。系统还能组合Gemini与Claude模型，在项目花费触及上限时暂停工作。

为什么值得关注：企业助手的竞争正在转向持续工作的组织方式。记忆、身份、模型选择与预算若能一起管理，团队才可能把一项跨天任务真正交出去，而不只是多开几个聊天窗口。

适合谁看：评估企业助手、跨工具工作流和部门级AI治理的技术与业务负责人。

试试看

从官方公告梳理一个真实任务需要的数据、技能和授权，再核对现有Workspace环境能否接入；优先测试暂停、恢复与成本归属。

注意点

金融和法律专门能力仍属预览，政府、医疗和零售版本尚待推出。公告描述不等于所有租户已同步开放，具体资格与价格需另行核实。

02Anthropic OSS Scanner美国2026-10-08 发布 / 2026-10-09 观察官方一手来源

Anthropic免费为开源项目定期查漏洞

发生了什么：Anthropic启动Cyber Mission，并推出自愿加入的OSS Scanner。获接纳的开源项目可免费获得前沿模型的定期扫描，报告包含漏洞利用示例、解释及可提供的修补建议。报告不经过人工复核，面向有能力持续核查发现的维护团队。

为什么值得关注：发现漏洞的成本下降后，稀缺环节会转向复核、排序和修复。免费扫描能扩大覆盖，但维护者真正需要衡量的是有效修补速度，而不是收到多少条机器报告。

适合谁看：维护开源软件、管理依赖安全或承接漏洞响应的工程团队。

试试看

从官方服务入口查看加入条件，先确定谁负责分流和验证报告，再选择能持续维护的项目申请；保留修补前后的回归测试。

注意点

官方预期真阳性率超过90%，并非独立实测保证。模型可能判断错严重程度；无法承接原始报告的项目仍可走人工核验的披露流程。

04Motion Graphics Benchmark全球2026-10-08 发布 / 2026-10-09 观察作者一手来源

十个模型交同一份动效作业

发生了什么：Cliphouse发布动效对照页面，让十个模型完成相同的三份Remotion任务，每项提供两次独立运行。读者可以并排看成片、读取提示和调用费用，也能区分首次成功与自动修复。任务涵盖产品发布、动态文字和数据故事。

为什么值得关注：选择创作模型时，实际成片比抽象分数更容易判断。把失败、修复和费用放在同一页面，也能看出便宜的一次调用是否真的意味着便宜的一次交付。

适合谁看：使用代码生成视频、制作动效或评估创作模型的设计与开发者。

试试看

先选一份任务，在不看模型名称的情况下比较信息层级、节奏和结尾可读性，再展开运行详情核对修复次数与实际调用费用。

注意点

这是作者设置的小规模对照，不代表全部视频任务。模型耗时只统计成功尝试的接口时间；修复运行和渲染耗时需要分别阅读。

06AdvancedMathBench AutoVerifier中国2026-09-29 发布 / 2026-10-09 观察官方一手来源

数学验证模型定位证明中的首个错误

发生了什么：上海AI实验室相关团队在9月29日公开AdvancedMathBench AutoVerifier权重。模型判断自然语言证明是否正确，解释问题并定位首个错误步骤；配套评测协议对每份证明检查八次，只有八次有效判断均通过才接受。

为什么值得关注：能写出解答，不代表能准确检查解答。明确错误位置和接受规则，让验证环节更容易研究；但多次同意仍然只是模型判断，不能替代形式化证明或专家复核。

适合谁看：研究数学推理、证明评测与自动验证流程的模型和学术团队。

试试看

从模型卡检查输入格式、错误索引和无效输出处理，再阅读配套评测说明；先估算约68GiB权重的加载成本，使用小样本检查误判。

注意点

文件保留Apache-2.0文本，但NOTICE要求权利方确认上游谱系与发布授权；不能据此推定所有材料可商用。模型不是形式化证明检查器。

03Rembrandt全球2026-10-08 发布 / 2026-10-09 观察作者一手来源GitHub Stars 49许可证 GPL-3.0

Rembrandt把本地AI放进照片暗房

发生了什么：独立照片编辑器Rembrandt更新到0.3.9，提供桌面下载和自托管浏览器入口。工具把AI主体与深度蒙版、降噪、放大等功能放在本地处理，支持非破坏性编辑。用户也能输入调色文字，但这部分采用词汇规则，不是大语言模型。

为什么值得关注：照片工具的吸引力不只在生成新画面，也在整理和修好已有素材。把推理留在设备上、让修改跟随可见滑杆，有助于用户理解每一步到底改变了什么。

适合谁看：希望本地处理照片、愿意试用新软件的摄影爱好者与创作者。

试试看

先用照片副本体验蒙版、降噪和前后对比，再检查自己的RAW格式与显卡表现；自托管时确认访问范围和旁车文件保存方式。

注意点

代码采用GPL-3.0或更新版本，模型和其他依赖另有条款。当前安装包尚未代码签名；官方列出的相机覆盖和效果未在本期逐项实测。

05Video Reasoning Best-of-N美国2026-10-07 发布 / 2026-10-09 观察官方一手来源GitHub Stars 0许可证未声明（GitHub识别结果）；README声明CC BY-NC 4.0

Meta公开视频答案筛选研究代码

发生了什么：Meta研究仓库公开视频推理的实验代码，比较多次生成答案后，如何用自洽投票、跨模型评审和其他验证器选出结果。发行快照包含生成、评分、筛选及图表脚本，覆盖五个评测集，帮助研究者复现部分实验。

为什么值得关注：多想几次并不自动带来更可靠的答案，选择器本身也可能出错。把生成能力与筛选能力分开测量，才能判断增加推理预算究竟买到了什么。

适合谁看：研究视频理解、测试时计算扩展和模型评审机制的团队。

试试看

先阅读数据表与计分约定，再选择一个评测集复跑生成和筛选；固定候选答案池，比较不同验证器，避免把额外采样混进选择收益。

注意点

源码采用CC BY-NC 4.0，禁止商业使用，不是OSI开源许可。数据和权重另有条款；Muse实验依赖Meta内部接口，外部无法复现。这是研究快照，非持续维护的通用库。
