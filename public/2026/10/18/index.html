RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

MOSS把位置写进输入，Kiteva让用户先选短预览。能在成品之前检查和调整，比一次生成更多内容更有用。

splatting-rs在浏览器重建三维，SpeakoFlow在桌面处理语音。无需上传并不等于没有门槛，设备与模型下载成为新的体验条件。

任务成本

模型选型回到实际任务

DeepSeek关注执行耗时与输出量，HoldemBench比较同桌决策成本。价格、速度和表现需要在同一任务里一起衡量。

01DeepSeek中国2026-10-17 发布2026-10-18 观察官方一手来源

DeepSeek新版缩短执行与输出

发生了什么：DeepSeek发布V4.1-Flash-1017，更新网页、应用及deepseek-flash接口，价格不变。官方称新版提升推理、代码、视觉与Agent能力，同时减少任务耗时和输出长度；代码与权重采用MIT许可，支持百万词元上下文。

为什么值得关注：更快完成任务和更少输出可能一起降低实际使用成本。比起只看单价，这次更新更值得用同一组工作任务比较总耗时、用量与完成率。

适合谁看：使用DeepSeek接口的开发者，以及评估本地部署和模型替换的团队。

试试看

先在现有接口复跑一组固定任务，再对照官方模型卡中的评测设置；本地部署按仓库提供的编码方案处理输入。

注意点

性能提升来自官方评测，不同测试采用不同Agent框架；百万上下文是容量上限，不代表长文任务始终同样可靠。

03DeepSeek Search中国2026-10-17 发布2026-10-18 观察官方一手来源

DeepSeek单独开放搜索与网页提取

发生了什么：DeepSeek新增独立搜索接口与网页提取接口，使用现有密钥即可调用。搜索返回结构化结果，可指定站点、语言和日期，并选择附带正文；提取接口把单个网页转换为Markdown。这两种工具不要求先发起模型对话。

为什么值得关注：把检索和生成分开，应用可以自己决定查什么、保留哪些证据，再交给任意后续模型。搜索不再只能藏在聊天回答里，链路也更容易检查。

适合谁看：构建资料助手、新闻追踪、网页阅读和需要保留引用证据的Agent团队。

试试看

按官方文档先查询一个已知主题，再提取其中一页；比较搜索摘要和原文，记录链接及抓取时间供回答引用。

注意点

相关性与权威性分数只是搜索引擎的排序信号，不是事实认证；正文可能缺失，网页提取也不保证每个站点都可读取。

02OpenMOSS中国2026-10-16 发布2026-10-18 观察官方一手来源GitHub Stars 438许可证 Apache-2.0

MOSS图像模型让布局成为输入

发生了什么：OpenMOSS于10月16日开放MOSS-Image的Base与SFT版本及推理代码。模型采用50亿参数主干，支持长提示词、文字绘制和布局控制；示例可用JSON指定文字位置。权重和独立推理代码采用Apache-2.0许可。

为什么值得关注：文字、位置和构图能够一起描述，图像模型就更接近版面创作工具。Base与SFT分别提供继续训练和直接体验的入口，选择更清楚。

适合谁看：关注海报、信息图、图文排版的创作者，以及希望微调图像模型的团队。

试试看

从仓库进入官方演示，比较自然语言与JSON布局输入；本地运行可按显存条件选择常驻、组件卸载或顺序卸载模式。

注意点

布局示例不是严格排版保证，中文文字仍需逐字检查；已有ComfyUI插件不等于官方原生集成已经完成。

04splatting-rs全球2026-10-17 公开展示2026-10-18 观察作者一手来源GitHub Stars 0许可证 Apache-2.0

照片在浏览器内变成可旋转三维

发生了什么：splatting-rs展示了一条完全在浏览器内运行的照片转三维流程：下载137MB的DA3 Small模型估计深度，再用WebGPU优化高斯点。用户可导入多张照片，旋转查看结果并导出PLY；另有原生版本采用不同模型。

为什么值得关注：把重建放进浏览器，尝试三维素材不必先搭服务器或把照片上传到远端。它提供的是能直接操作的小入口，而非只有效果视频。

适合谁看：想记录物件或空间的创作者，以及研究浏览器端机器学习与三维工具的开发者。

试试看

从仓库打开网页演示，准备六至十二张视角有重叠的照片，在支持WebGPU的浏览器中观察重建并尝试导出。

注意点

137MB是模型下载量，不是运行内存需求；效果取决于照片与设备，不能当作精密测量。本期未执行照片重建。

05SpeakoFlow全球2026-10-17 公开展示2026-10-18 观察作者一手来源GitHub Stars 321许可证 MIT

SpeakoFlow把离线口述放进日常应用

发生了什么：SpeakoFlow把按键口述、文字整理和助手放进桌面输入流程，支持Windows、macOS与Linux。默认采用本地模型，云端能力需自行启用并提供密钥；项目以MIT许可开放，也提供会议转写及麦克风、系统音频的分轨处理。

为什么值得关注：语音输入不必只存在于聊天窗口。能在正在使用的应用里完成转写与整理，才更容易进入写邮件、做笔记和整理想法的日常动作。

适合谁看：希望本地处理语音的写作者、会议记录者，以及需要跨应用输入的桌面用户。

试试看

从项目主页选择系统安装包，先下载所需模型，再用几段普通笔记比较纯转写与整理结果；离线体验应关闭云端选项。

注意点

语言覆盖取决于所选模型，首次使用仍需下载资源；macOS录制会议另一方可能需要虚拟音频设备。本期未安装实测。

06HardwareOS全球2026-10-17 公开展示2026-10-18 观察作者一手来源

HardwareOS从一句想法整理搭建计划

发生了什么：HardwareOS把硬件项目的自然语言需求整理成器件、连线、固件与取舍建议，提供登录后的工作台入口。官网以ESP32与传感器为例展示搭建过程，让用户从希望实现的功能出发，而不是先在零件清单里摸索。

为什么值得关注：硬件入门的难处往往在多个环节接不上。把部件选择、连线和程序放在一个计划中，有机会减少来回查资料的成本，也便于暴露遗漏条件。

适合谁看：准备尝试传感器、开发板和小型自动化项目的学生、创客及硬件初学者。

试试看

先看官网示例，再登录工作台描述一个小项目，把电源、器件型号和预期功能写清楚，核对生成的连线与器件数据表。

注意点

已核验的是官网说明与工作台入口，不是实物搭建结果；接线、供电和电流限制仍需独立确认，不能照建议直接通电。

07HoldemBench全球2026-10-17 发布2026-10-18 观察官方一手来源

扑克实验让模型价格接受同桌检验

发生了什么：HoldemBench作者报告了17个AI在7700手单挑无限注德州扑克中的表现。实验通过重复牌局、交换座位及全下权益修正减少运气干扰；部分低价推理模型表现接近或超过昂贵模型，也有模型输给简单的脚本策略。

为什么值得关注：价格与任务表现不是同一张排行榜。统一牌局和决策接口之后，成本差异才有比较意义，也提醒选型应围绕具体任务，而非直接照搬通用榜单。

适合谁看：研究模型决策、游戏Agent、成本评估，以及希望理解评测设计的读者。

试试看

阅读作者的方法说明和牌局回放，重点看座位交换、样本量与置信区间，再思考自己的任务能否设计类似的对照实验。

注意点

这是个人研究中的特定游戏实验，不代表通用智能排名；有限样本和动作接口会影响结论，也不构成真实资金博弈建议。

本期观察：一个工具是否值得留下，往往取决于它能否让原本模糊的一步变得可见：布局在哪里、资料从哪来、哪项输入影响结果。能检查这些细节，才有条件判断自动化带来的收益。
