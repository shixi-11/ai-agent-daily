RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01GPT-6.1 Sol美国2026-09-29 发布 / 2026-10-04 观察官方一手来源

Sol 6.1为复杂工作新增较低价选择

发生了什么：OpenAI发布GPT-6.1 Sol，面向复杂编码与专业工作。标准档在输入不超过272K token时，每百万输入与输出分别为2美元和10美元；Responses API同时提供测试中的多智能体委派能力，工具调用应走该接口。

为什么值得关注：价格只是选择模型的一半。委派能力让单次请求可以拆分工作，但总成本还取决于子任务数量、上下文与失败重试。

适合谁看：需要处理复杂工程任务、研究分析和多步骤工具调用的开发团队。

试试看

用同一组真实任务比较Sol与既有模型，记录结果正确率、总token、工具调用和完整交付耗时。

注意点

多智能体仍为测试能力；上述价格有输入长度与处理档位条件，不应直接套到所有请求。

02Gemini 4 Argon美国2026-09-30 发布 / 2026-10-04 观察官方一手来源

Argon把长程推理推向百万输出

发生了什么：Google发布Gemini 4 Argon，将输出上限提高到100万token，主攻长程软件工程、专业知识工作和网络防御。首批通过Fairwind计划向可信防御者开放；面向开发者、企业和普通用户的更广泛开放仍在后续安排中。

为什么值得关注：更长输出容纳更多连续推理，但也放大等待、成本和验证负担。真正值得看的是复杂任务能否少中断、少丢失约束地完成。

适合谁看：处理大型代码迁移、金融法律研究，以及防御性安全工作的团队。

试试看

先阅读官方使用案例和评测设置，为自己的长任务建立验收集；获得资格后再验证端到端表现。

注意点

100万是输出token上限，不要误写成上下文长度。Google内部成果与厂商评测尚不能替代本地复现。

03Cohere Embed 5加拿大2026-09-30 发布 / 2026-10-04 观察官方一手来源

Embed 5让索引与查询各选一档

发生了什么：Cohere推出Embed 5 Pro与Fast，两档共享向量空间，可用Pro建立索引、用Fast处理查询，无需因此重建索引。两者支持图文输入、超过100种语言和128K上下文；文本每百万token分别为0.12美元与0.08美元。

为什么值得关注：检索系统不必把离线建库与每次在线查询绑在同一成本档位。共享空间提供了可独立优化吞吐、延迟和质量的工程选择。

适合谁看：维护多模态知识库、企业搜索和频繁检索型Agent的团队。

试试看

取一组真实查询，对比Pro建库搭配两档查询的召回率、尾延迟和费用，重点检查表格与扫描文档。

注意点

图像计价不同于上述文本价格；跨模型兼容指Embed 5两档，不表示任意旧模型向量都可混用。

04Qwen-Image-2.1-Pro中国2026-10-02 发布 / 2026-10-04 观察官方一手来源

千问透明图层生成新增Pro接口

发生了什么：QwenCloud在10月2日新增Qwen-Image-2.1-Pro，统一文生图与编辑，支持原生透明通道及最多10张参考图。视觉生成部分为7B参数；这是10月2日的API可用性更新。

为什么值得关注：透明图层与多图合成更贴近贴纸、商品素材和版式制作。接口上线后，团队可先测试服务，再决定是否承担本地部署成本。

适合谁看：制作电商素材、角色贴纸和可叠加视觉资产的设计师与应用开发者。

试试看

用同一主体测试透明背景、多图组合和局部编辑，检查边缘残留、身份一致性及导出结果是否真含透明通道。

注意点

请求参数沿用3.0系列，但用量字段沿用2.0系列；接入时需分别核对，不能只更换模型名。

05AstaBrief 8B美国2026-10-02 发布 / 2026-10-04 观察官方一手来源

AstaBrief把科学报告压成一次生成

发生了什么：Ai2开放AstaBrief 8B及训练数据，模型把研究问题与检索到的文献片段写成带引用的报告，并已用于Asta的Fast模式。官方完整流程平均耗时51.1秒，Thinking模式为178.5秒；另提供从自有PDF生成报告的示例。

为什么值得关注：专门训练的小模型配合简化流程，可以减少逐节生成与中间归纳的开销。引用是否真正支持结论，仍需独立于文笔评价。

适合谁看：需要快速整理文献、构建机构内研究助手或处理未发表研究问题的团队。

试试看

先在Asta试一组熟悉的问题，再逐条打开引用核对研究对象、时间范围与结论强度，必要时评估本地部署。

注意点

主要训练与比较实验完成于2025年，不能据此宣称胜过当下前沿模型；51.1秒是完整流程平均值。

11Open TTS Leaderboard美国 / 法国2026-09-30 发布 / 2026-10-04 观察官方一手来源

快讯：语音榜单可以切换语言亲耳对比

发生了什么：Hugging Face推出Open TTS Leaderboard，分开比较转写错误率、速度与说话人相似度，并可按语言筛选，在Listen页试听对应生成结果。

为什么值得关注：选配音模型不必只看一个总分，耳朵能补上指标看不到的表现力。

适合谁看：选择多语言配音与语音Agent模型的创作者。

试试看

挑常用语言试听，再比较首段音频延迟。

注意点

识别错误率不直接衡量自然度，声线相似也不等于更好听。

GitHub开源发现与代码发布

Stars为成稿时的关注度快照，不代表质量排名。模型权重可能另有许可条件。

06Olmo-core 3美国2026-10-01 发布 / 2026-10-04 观察官方一手来源GitHub Stars 1,663许可证 Apache-2.0

快讯：Olmo-core重排稀疏训练通信

发生了什么：Olmo-core 3调整MoE分布式训练，让专家参数常驻设备并减少通信。Apache-2.0代码开放，万亿参数结果属系统基准，非完整训练。

为什么值得关注：把通信、路由和低精度计算一起优化，比只看活跃参数更接近训练成本。

适合谁看：研究MoE训练与分布式系统的团队。

试试看

阅读代码与交互演示，对照自己的通信瓶颈。

注意点

超大配置包含随机路由及短容量测试，不是已训练模型的质量成绩。

07NVIDIA Kumo Tabular美国2026-09-29 发布 / 2026-10-04 观察官方一手来源GitHub Stars 283代码 Apache-2.0 / 权重许可 OpenMDW-1.1

快讯：Kumo从有标签表格直接做预测

发生了什么：NVIDIA开放Kumo Tabular，提供28M至215M三档模型，用有标签的表格行作上下文，直接完成分类或回归，无需为当前任务另行训练。

为什么值得关注：让小型表格任务多一个可与梯度提升树对照的起点。

适合谁看：处理业务表格与预测任务的数据团队。

试试看

使用留出测试集，与现有树模型比较误差及推理成本。

注意点

代码为Apache-2.0，权重为OpenMDW-1.1，须分别核对。

08SemanTok英国 / 德国2026-09-30 发布 / 2026-10-04 观察官方一手来源GitHub Stars 0代码及权重许可 Stability AI Community License

快讯：SemanTok让少量token先讲清画面

为什么值得关注：可以直观看到视频生成如何在语义与细节之间分配预算。

适合谁看：研究视频压缩、生成效率与视觉表示的开发者。

不含训练代码；代码与权重受社区许可约束，商用须核对条件。

09Microsoft ThinkingBox美国2026-10-03 发布 / 2026-10-04 观察官方一手来源

ThinkingBox不听完成宣言，只查数据库

发生了什么：微软介绍ThinkingBox，用507项有状态业务任务检验Agent留下的终态与副作用，每项重复20次。评测同时区分单次成功率、20次中至少成功一次，以及记录中20次全部成功，避免将偶然完成当成可靠交付。

为什么值得关注：合法工具调用和流畅回复都可能掩盖错误写入。把验收放在业务状态，再观察重复运行表现，才能看见看似完成的失败。

适合谁看：准备把Agent接入客服、保险、出行与企业业务系统的团队。

试试看

选一个有明确终态的内部流程，重置测试数据后多次运行，分别记录漏改、错改和不该发生的额外操作。

注意点

20次全过是观测结果，不保证未来每次成功；不同领域、框架与工具配置会影响模型排名。

10ServiceNow AutoSynthData美国2026-10-02 发布 / 2026-10-04 观察官方一手来源

快讯：AutoSynthData围绕失败生成练习

发生了什么：ServiceNow介绍AutoSynthData，从目标模型失败与较强教师成功的差异提炼能力缺口，再生成可执行任务及验证器，逐轮调整训练课程。

为什么值得关注：合成数据的价值从数量转向是否针对真实薄弱环节。

适合谁看：构建企业Agent训练数据与评测环境的团队。

试试看

先定义状态、工具和成功条件，再参考任务验证流程。

注意点

这是方法与实验介绍，不代表任意企业环境均能自动生成可靠训练集。

12Google SynthID Bio英国 / 美国2026-09-30 发布 / 2026-10-04 观察官方一手来源

快讯：SynthID把水印带入蛋白质设计

发生了什么：Google介绍SynthID Bio，在生成的蛋白质序列与预测结构中加入可检测标记，并报告部分实验中保留生物功能，计划推动来源验证。

为什么值得关注：生成内容的溯源不再只涉及图片，也进入科学数据与实体实验。

适合谁看：关注科研数据完整性与AI生成物溯源的读者。

试试看

阅读方法论文，区分数字检测与实验验证范围。

注意点

这是概念验证；抗蓄意篡改能力和更复杂对象仍待研究。

本期观察：可靠流程不能只靠模型能力。保留证据原本的适用范围，检查执行留下的真实状态，再通过重复测试判断结果是否值得信任。
