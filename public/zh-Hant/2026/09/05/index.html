01Claude Code美國 / 全球開發者2026-09-04 釋出 / 2026-09-05 觀察官方釋出

Claude Code 開始盤點 Skills 的上下文成本

發生了什麼：Claude Code 2.1.261 新增 /skill-doctor，可列出已載入卻未使用的 Skills 及其上下文成本；命令和後臺任務的內聯輸出上限可調至 12.8 萬字元，子 Agent 提示也能從檔案追加。版本還修復恢復會話時丟失並行工具附近的 hook 輸出。

為什麼值得關注：Skills、工具返回和恢復上下文開始具備可見預算，團隊可以找到隱性 token 消耗，也更容易判斷會話恢復是否保持原意。

適合誰看：維護大型 Skill 集、遠端會話、子 Agent 和企業策略的開發團隊。

試試看

執行 /skill-doctor 清理一個長期未呼叫的 Skill，再恢復一段含並行工具的會話，核對 hook 輸出、許可權模式和請求語義是否完整。

注意點

上下文成本來自當前載入與使用情況，不等於 Skill 質量；提高內聯輸出上限也會擴大提示佔用，離線訊息仍要等終端重連後才真正投遞。

02Kimi Code中國 / 全球開發者2026-09-04 釋出 / 2026-09-05 觀察官方釋出

Kimi Code 0.41 把壓縮後追溯寫回事件日誌

發生了什麼：Kimi Code 0.41.0 會在自動壓縮前提醒剩餘上下文，壓縮後引導模型回查會話事件日誌；逐輪檔案歷史改為常開，子 Agent 也能在新程序中按原身份恢復。Web 端擴充套件實驗性 Tower 多 Agent 協作，同時調整自動許可權模式，不再攔截危險或無法靜態分析的命令。

為什麼值得關注：壓縮、重啟與多人協作不再只能依賴摘要續接，事件日誌和穩定 Agent 身份開始承擔精確恢復；代價是自動許可權的風險邊界更需要人工理解。

適合誰看：使用 Kimi Code 做長會話、多 Agent 編碼和自動許可權配置的團隊。

試試看

在測試倉庫觸發一次自動壓縮並重啟程序，檢查逐輪檔案歷史和子 Agent 歸屬能否續上；隨後分別迴歸三種許可權模式。

注意點

Tower 仍是實驗能力；Never Ask 等模式可能執行危險或無法靜態分析的命令，不能在含真實憑據、生產資源或寬許可權環境裡直接試跑。

Mistral Vibe 2.25 把 Skills 與聯結器納入會話邊界

發生了什麼：Mistral Vibe 2.25 新增按作用域分組的 /skills 瀏覽器，並在會話啟動時同步共享 Skills；ACP 接入 Slack、GitHub、Gmail 等七類聯結器。外掛 MCP 服務可獨立登入並按會話隔離憑據，檔案操作則用解析後的路徑阻止符號連結逃逸。

為什麼值得關注：技能目錄、業務聯結器、MCP 身份和檔案路徑被放進同一會話控制面，減少多會話之間誤繼承憑據或許可權的機會。

適合誰看：需要在 Mistral Vibe 中組合 Skills、SaaS 聯結器與 MCP 服務的開發者。

試試看

開啟實驗性 /skills，檢查使用者、會話和專案作用域；再讓兩個會話連線同名 MCP 服務，確認狀態、工具與登入憑據沒有串用。

注意點

Skills 瀏覽器預設關閉；聯結器可見不代表每個租戶都已授權。自動批准配置與專案外寫入仍需結合組織策略單獨檢查。

04DeepSeek Harness中國 / 全球開發者2026-09-04 釋出 / 2026-09-05 觀察官方開源釋出GitHub Stars 212,246許可證 MIT

DeepSeek Harness 為每個 Session 加上唯一持有鎖

發生了什麼：DeepSeek Harness 0.1.3 alpha 用 SessionHandle 管理持久化，並用會話鎖保證一個 Session 至多由一個程序佔用；舊日誌不可變遷移至 v2，Assistant 流按 attempt 匯入 settlement；團隊訊息在冷恢復中保留髮送者與順序。

為什麼值得關注：會話所有權、格式遷移和多 Agent 訊息順序都進入明確協議，能減少雙寫、舊日誌漂移和恢復後訊息來源不清。

適合誰看：研究多程序 Agent、長會話持久化、團隊訊息與冷恢復的框架開發者。

試試看

用兩個程序爭用同一測試 Session，確認第二個被鎖拒絕；再遷移一份 v1 日誌並中斷一次流，檢查 settlement 與訊息順序。

注意點

這是 alpha 版本且含破壞性 API 變化；官方已披露部分歷史會話載入存在效能回退，升級前應複製測試資料並做回滾演練。

05Agno AgentOS美國 / 全球基礎設施2026-09-04 釋出 / 2026-09-05 觀察官方開源釋出GitHub Stars 42,053許可證 Apache-2.0

Agno 3.0.6 讓 MCP 服務擺脫會話黏連

發生了什麼：Agno 3.0.6 增加可選的無狀態 MCP 服務：/mcp 不再追蹤會話，任意副本都能響應請求，多例項部署無需會話黏連。MCPTools 可選擇 legacy 或 auto 協議協商，並新增列出工具、名稱、版本與說明的 Server Card；公開路由也能單獨排除在鑑權之外。

為什麼值得關注：MCP 服務首次把橫向擴充套件便利與會話能力損失擺在顯式開關上，部署者可以按通知、續流和負載均衡需求選擇協議形態。

適合誰看：運營多副本 MCP、AgentOS 閘道器或跨版本客戶端的基礎設施團隊。

試試看

用兩個副本和無會話親和的負載均衡器壓測 stateless 模式，再切回 legacy，對比通知、SSE 續流、故障切換與工具發現。

注意點

無狀態模式預設關閉，並會失去服務端通知和 SSE 可恢復性；excluded_route_paths 只應開放確實無需身份的路徑，不能當成全域性繞過。

06HyperPod InstantStart美國 / 全球雲基礎設施2026-09-04 釋出 / 2026-09-05 觀察官方公告

HyperPod InstantStart 把叢集運維封進可重試控制面

發生了什麼：AWS 介紹開源 HyperPod InstantStart：Web、REST 與 MCP 工具進入同一後端 API，共享驗證和持久操作狀態。它把 EKS、依賴、容量、儲存、訓練與推理拆成分階段、冪等、可重試操作；Agent 輪詢非同步步驟到終態，只把可用區、例項和容量型別留給使用者決定。

為什麼值得關注：Agent 不再直接拼接原始 CLI，而是呼叫帶約束、狀態與恢復路徑的控制面；這比“讓模型記住正確命令”更接近可靠基礎設施自動化。

適合誰看：管理 SageMaker HyperPod、EKS、GPU 訓練和推理叢集的平臺團隊。

試試看

在隔離賬號只建立最小測試叢集，故意讓一個後置階段失敗，確認已完成階段不會回滾，重試能從持久狀態繼續並返回終態。

注意點

專案由 AWS 官方部落格釋出並提供程式碼，但 GitHub 倉庫未宣告許可證；管理容器需要 AWS 與 Kubernetes 許可權，模板的公網安全組也應在實用前收緊。

07Amazon Bedrock AgentCore Memory美國 / 全球企業2026-09-04 釋出 / 2026-09-05 觀察官方公告

AWS 把 Agent 記憶清理做成夜間生命週期

發生了什麼：AWS 釋出 AgentCore 記憶生命週期架構：EventBridge 每晚觸發 Step Functions，執行 TTL 清理、相關性評分、LLM 合併、指標寫入和結果歸檔。評分結合建立時間、最近訪問與頻次，資料來自 CloudTrail 和 S3 累計賬本；低分記憶可先合併，再刪除原記錄。

為什麼值得關注：長期 Agent 的“忘記”被拆成可配置、可觀測、帶明確失敗處理的運營流程，避免舊爭議、過期操作手冊和無限積累繼續汙染回答。

適合誰看：運營客服、銷售、IT 幫助臺等高頻長期記憶 Agent 的團隊。

試試看

先在副本資料上分別測試情景、語義和程式記憶的保留期，做一個只出報告的實現，列出待刪、待合併清單與命中依據；審查透過前不要啟用刪除。

注意點

AgentCore 目前沒有內建自動刪除 TTL，這套方案依賴額外 AWS 元件；LLM 合併具有損失性，高風險領域應保留冷存檔並做人審與忠實性校驗。

08Google Genomic Prediction美國、英國與日本 / 全球科研2026-09-03 釋出 / 2026-09-05 觀察官方公告

Google 發現跨人群遷移學習並非資料越多越好

發生了什麼：Google Research 用 UK Biobank 歐洲人群與近 20 萬日本 Biobank 樣本，在八項臨床性狀上比較多基因風險預測。目標人群樣本少於約 1.5 萬時，歐洲資料能提供統計增益；樣本繼續增加後，混入外部人群資料反而可能降低準確率，轉折點還會隨性狀的群體特異性變化。

為什麼值得關注：“更多資料必然更好”在跨人群醫學模型裡失效，訓練策略必須同時看目標樣本規模、遺傳結構和分佈差異，而不能只追求大庫遷移。

適合誰看：醫學 AI、基因組學、公共健康、風險建模與資料治理團隊。

試試看

複查一個跨地區模型的學習曲線，按目標人群樣本量逐步減少外部資料權重，並把效能轉折點按具體任務而非統一閾值記錄。

注意點

研究覆蓋八項性狀與兩個人群，不能直接推廣到所有疾病或族群；多祖源方法 PRS-CSx 也需要較大的目標樣本後才顯出優勢。

本期觀察：今天的共同變化是把 Agent 從會話型助手推向可持續運營：技能要能盤點，會話要能鎖定，基礎設施與記憶也要具備可重試、可清理的生命週期。
