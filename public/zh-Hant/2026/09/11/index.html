01DeepSeekChina2026-09-10 釋出 / 2026-09-11 觀察官方頁面

DeepSeek V4.1 Flash 換上原生視覺架構

發生了什麼：DeepSeek 釋出 V4.1 Flash：採用因果編碼器—解碼器與 MoE，552B 總引數，輸入和輸出分別啟用 8B、16B。新模型原生支援視覺，API 使用 deepseek-flash，舊 Flash 與視覺實驗版名稱暫時轉接到新模型。

為什麼值得關注：變化不僅是回答能力：輸入與輸出拆開計算，會改變長材料處理的成本結構；原生視覺則讓截圖、圖表與文字可以進入同一套工作流程。

適合誰看：正在做文件理解、視覺智慧體，或維護 DeepSeek API 接入的團隊。

試試看

用同一份帶圖表的材料比較舊流程與新模型，核對數字提取、推理結論和呼叫記錄，再決定是否調整預設模型。

注意點

官方計劃於北京時間 9 月 14 日中午將 V4 Pro 別名轉接至 V4.1 Flash；依賴模型名稱固定能力的應用應提前檢查。

為什麼值得關注：語音產品不必再把每輪交流切成嚴格的先聽後說。前臺交談與後臺辦事分開，也給客服、口語練習和電話助理更靈活的設計空間。

先聽官方示例，再用自己的語音流程測試中途改口、短暫停頓和背景噪聲，記錄誤打斷與恢復對話的表現。

注意點

這是 API 開放，不是模型首次亮相。語音前端標價每分鐘 0.05 美元；後臺模型的呼叫成本仍需另外核算。
