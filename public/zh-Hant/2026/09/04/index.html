RISC機器說明

RISC = 生產級 Agent / 機器人身體的四個系統

一個真正能上生產的 Agent，不能只有大腦。它還要持續行動、扛住故障、抵禦越權，並進入真實組織協作。

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體持久執行、容錯、恢復與水平擴充套件。身體站不住，一次故障就會把工作清空。
I｜智慧 / 大腦模型迴圈、記憶、工具與編排。它決定 Agent 如何思考、呼叫和完成複雜工作。
S｜安全 / 免疫能力物件、策略審批、回滾與審計。沒有免疫，恢復與連線會擴大失控半徑。
C｜連線 / 社會跨公司授權、中立基底、會話型別與生態連線。沒有社會介面，Agent 只能停在單一產品裡。

01Claude Code美國 / 全球開發者2026-09-03 釋出 / 2026-09-04 觀察官方釋出

Claude Code 讓改動與恢復狀態可直接核對

發生了什麼：Claude Code 2.1.260 新增並排 diff 面板，並在 /cost 與狀態列提示提示詞快取未命中的可能原因。版本還修復路徑含括號時許可權規則失效、zsh 變數藏入命令替換被自動放行，以及 /rewind 在備份缺失時誤報成功等問題。

為什麼值得關注：程式碼改了什麼、快取為何失效、檔案是否真的恢復，開始從後臺細節變成操作者可以當場核對的執行狀態。

適合誰看：使用 Claude Code、遠端控制、企業策略和多 Agent 會話的開發團隊。

試試看

開啟 /diff 連續編輯兩處檔案，再故意製造一次快取失效與缺失檢查點，確認介面給出的原因和恢復結果都與磁碟一致。

注意點

這是客戶端可見性與可靠性升級，不等於生成程式碼已經正確；許可權規則、回退結果和企業證書鏈仍要在真實環境迴歸。

02Qwen Code中國 / 全球開發者2026-09-03 釋出 / 2026-09-04 觀察官方開源釋出GitHub Stars 27,628許可證 Apache-2.0

Qwen Code 0.23 把記憶與並行審查納入邊界

發生了什麼：Qwen Code 0.23.0 新增專案級與使用者級記憶任務，並在 remember 與 forget 時隔離兩類檔案儲存；review emit-workflow 可生成確定性的並行審查指令碼。版本還讓定時任務每次建立獨立子會話，並開放暫停、恢復、重試和刪除工作流。

為什麼值得關注：記憶作用域、審查並行度和後臺會話生命週期被寫成顯式控制，減少多個 Agent 共用狀態時的串線與不可複核操作。

適合誰看：維護開源編碼 Agent、團隊記憶、程式碼審查和後臺工作流的工程團隊。

試試看

分別寫入同名的專案記憶與使用者記憶，再執行 emit-workflow 生成的審查指令碼，檢查儲存隔離、並行順序和會話歸屬。

注意點

嚴格作用域只覆蓋該版本實現的儲存邊界；私有 Git 主機擴充套件、無令牌迴環介面和超高 token 預算仍需單獨評估。

03Anthropic CLI美國 / 企業平臺2026-09-03 釋出 / 2026-09-04 觀察官方開源釋出GitHub Stars 629許可證 MIT

Anthropic CLI 用 ant apply 管理整套 Agent 資源

發生了什麼：Anthropic CLI 1.30.0 新增 ant apply，可把 Agent、Skills、環境、記憶庫和部署作為程式碼統一管理；同時為使用報告加入 Claude Tag 分類與使用者拆分，並讓更多 API 端點接受 workspace ID。

為什麼值得關注：Agent 的提示、技能、記憶與部署不再只能散落在控制檯，團隊開始獲得可版本化、可審查的資源宣告入口。

適合誰看：管理 Claude API 工作區、Agent 資源和多環境部署的平臺工程團隊。

試試看

在測試工作區宣告一個 Agent、一個 Skill 和一套記憶庫，先檢視差異再執行 apply，並將結果與人工控制檯配置比對。

注意點

釋出說明確認了管理入口，但未證明所有資源都具備完整回滾或漂移檢測；生產使用前應驗證刪除、重新命名和許可權繼承。

04OpenAI Codex Security美國 / 全球安全工程2026-09-02 釋出 / 2026-09-04 觀察官方開源釋出GitHub Stars 10,358許可證 Apache-2.0

Codex Security 0.1.25 保留跨掃描漏洞身份

發生了什麼：Codex Security 0.1.25 可在多次掃描和比較中保留已確認漏洞的身份，並說明相關項為何相似、不同項為何分開；大規模比較改用有界批次，放不下的輸入會明確標為匹配未完成。版本還加入無模型呼叫的 mock 掃描與執行中預算上調。

為什麼值得關注：安全 Agent 不再只輸出一批易漂移的文字結果，而是開始維護可比較的漏洞物件、失敗邊界和可重複測試資料。

適合誰看：建設程式碼安全掃描、漏洞去重、迴歸驗證和 CI 安全門禁的團隊。

試試看

先用 mock 模式跑通報告、匯出和歷史比較，再對同一倉庫做兩次真實掃描，核對漏洞 ID、distinct 決策和未完成標記。

注意點

mock 只生成明確標記的合成結果，不會審計倉庫；互動式加預算也不適用於 CI、JSON、無頭或 verbose 模式。

05Hugging Face Funes法國 / 全球開發者2026-09-03 釋出 / 2026-09-04 觀察官方開源釋出GitHub Stars 29許可證 Apache-2.0

Funes 把多款編碼 Agent 的舊會話變成本地記憶

發生了什麼：Hugging Face 釋出 Funes：單個二進位制可解析 Claude Code、Codex、pi 與 Hermes 的既有會話，在本地 Lance 資料集上結合向量檢索、BM25、重排和鄰近片段，返回原始文字及會話、時間和輪次出處；也可同步到使用者自有的私有 Hub 資料集。

為什麼值得關注：跨工具記憶被還原成使用者可持有、可遷移、可追溯的資料集，而不是繫結某個 Agent 服務的不可見摘要。

適合誰看：頻繁切換編碼 Agent、多臺電腦協作或希望本地掌握會話記憶的開發者。

試試看

只匯入一組脫敏測試會話，追問一次舊架構決策，並沿 recall 返回的 session 與 turn 開啟原文，檢查是否能復現當時理由。

注意點

本地預設不等於絕對無洩漏；繫結 Hub 後資料會離開單機，雙重脫敏也不能替代敏感目錄排除、訪問控制和人工抽查。

NVIDIA 以 129.3 億美元收購 Hugging Face

發生了什麼：NVIDIA 宣佈已同意以 129.303 億美元收購 Hugging Face。公告稱平臺擁有逾 1800 萬開發者、300 萬模型、50 萬資料集和 100 萬應用，並承諾保留模型、框架、雲、推理服務商和計算平臺的選擇，不要求開發者使用 NVIDIA 算力。

為什麼值得關注：開放模型最大的分發入口與主導 AI 算力供應商進入同一家公司，模型發現、評測、託管和推理的中立性將成為行業核心議題。

適合誰看：使用 Hugging Face 分發模型、資料集、Spaces 或多雲推理的開發者與企業。

試試看

列出團隊依賴的模型託管、推理供應商和下載映象，做一次可遷移性演練，確認不依賴單一賬戶、雲或加速器。

注意點

當前是收購協議而非完成交割；開放與多雲承諾來自 NVIDIA 公告，後續仍要觀察監管、治理、定價和產品整合。

07NVIDIA Local AI at IFA德國 / 全球本地 AI2026-09-03 釋出 / 2026-09-04 觀察官方公告

NVIDIA PAIR 開始排程家中多臺 RTX 電腦

發生了什麼：NVIDIA 在 IFA 釋出 PAIR，支援區域網內分配推理；Hermes Agent、OpenClaw 與 Perplexity Portable Computer 將簡化本地模型安裝。llama.cpp、vLLM 宣稱最高提速 1.9 倍，聯想、宏碁 RTX Spark 預計 10 月上市。

為什麼值得關注：本地 Agent 從單機視訊記憶體問題走向家庭或小團隊算力池，隱私、成本與雲端升級路徑可以在路由層共同決定。

適合誰看：執行本地模型、桌面 Agent、創作工具和多機推理的個人與小團隊。

試試看

先在兩臺區域網裝置上記錄同一模型的視訊記憶體、吞吐與斷線恢復，再決定哪些步驟留本地、哪些經明確批准升到雲端。

注意點

PAIR 和部分簡化安裝仍是即將提供的能力；1.9 倍是特定最佳化口徑，RTX Spark 的價格、供貨與實際噪聲功耗仍待驗證。

08OpenAI Daybreak美國 / 關鍵基礎設施2026-09-03 釋出 / 2026-09-04 觀察官方公告

OpenAI 為關鍵服務防禦投入 10 億美元

發生了什麼：OpenAI 宣佈 Daybreak for Frontline Defenders，承諾投入 10 億美元，為關鍵服務的一線防禦者擴大前沿網路安全 AI、培訓和支援的可獲得性。官方 RSS 將其歸入 Security，並把專案定位在保護 essential services。

為什麼值得關注：頭部模型公司開始用長期資金、培訓和部署支援爭奪網路安全現場，而不只釋出更強的漏洞模型或排行榜成績。

適合誰看：關鍵基礎設施、安全運營中心、政府採購和網路安全產品團隊。

試試看

先盤點一類關鍵服務的告警、處置與升級鏈路，標出 AI 可以輔助但不能繞過的人類批准點，再關注專案申請細則。

注意點

10 億美元是承諾規模，不代表資金已經支出或產生效果；公開摘要尚未給出完整受益物件、分配節奏與成效指標。

09Google Fruit Fly Connectome美國 / 全球科研2026-09-03 釋出 / 2026-09-04 觀察官方公告

AI 協助完成最大規模果蠅全腦連線圖

發生了什麼：Google Research、HHMI Janelia 與合作者釋出雄性果蠅完整大腦和中樞神經系統連線圖，包含逾 16.6 萬個神經元和 1.25 億個突觸連線，按神經元數量為目前最大腦圖。AI 把電鏡切片重建為 3D 神經形態，再由人類專家校對，成果發表於 Cell。

為什麼值得關注：AI 在這裡不是替代科學解釋，而是把超大規模影象重建壓到可研究的資料層，讓性別差異、感知與運動迴路獲得共同底圖。

適合誰看：計算神經科學、醫學影像、科學 AI、三維重建和開放資料團隊。

試試看

開啟 Neuroglancer 資料集，挑一條從感官輸入到運動輸出的迴路，核對自動重建、人工校對與論文結論分別承擔什麼證據。

注意點

果蠅連線圖不能直接外推到人腦；AI 重建仍需多年人工校驗，連線結構本身也不等於神經活動或因果機制。

本期觀察：Agent 的競爭正在離開單一模型分數，轉向誰能掌握可遷移的配置、證據、分發入口和實際執行位置。
