RISC機器說明

RISC = 生產級 Agent / 機器人身體的四個系統

一個真正能上生產的 Agent，不能只有大腦。它還要持續行動、扛住故障、抵禦越權，並進入真實組織協作。

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體持久執行、容錯、恢復與水平擴充套件。身體站不住，一次故障就會把工作清空。
I｜智慧 / 大腦模型迴圈、記憶、工具與編排。它決定 Agent 如何思考、呼叫和完成複雜工作。
S｜安全 / 免疫能力物件、策略審批、回滾與審計。沒有免疫，恢復與連線會擴大失控半徑。
C｜連線 / 社會跨公司授權、中立基底、會話型別與生態連線。沒有社會介面，Agent 只能停在單一產品裡。

01Qwen Code中國 / 全球開源2026-08-22 釋出 / 2026-08-23 觀察官方釋出

Qwen Code 0.22 把會話、評審與記憶體邊界放進同一次更新

發生了什麼：Qwen Code 0.22 為 Web Shell 限制轉錄保留量並裁掉過大的回放，避免渲染器記憶體溢位；同時把新建 GitHub PR 繫結到來源會話，指出評審迴圈反覆卡住的具體檔案，並允許 11 個斜槓命令在流式輸出時立即執行。

為什麼值得關注：程式設計 Agent 的可靠性開始同時取決於會話可追蹤、評審能解釋和前端記憶體有上限，而不只是模型能否寫出程式碼。

適合誰看：使用 Qwen Code、Web Shell、自動評審或多會話開發的團隊。

試試看

升級後建立一個 PR，確認側欄能回到原會話；再跑長轉錄與反覆評審，觀察記憶體和卡點說明。

注意點

版本控制的是會話與介面可靠性，不代表長任務已經具備跨程序檢查點或外部動作回滾。

AWS 用四級路徑拆解企業 Agent 工具治理

發生了什麼：AWS 將 Bedrock AgentCore Gateway 的企業落地拆成 Connect、Control、Catalog、Harden 四級：從統一認證與審計，推進到 Cedar 許可權和隱私清洗、工具目錄與成本歸屬，再補私網接入、治理看板及多區域故障切換。

為什麼值得關注：企業不必第一天建完所有控制面；按真實治理痛點逐級升級，能減少 10 個助手對 5 個 API 維護 50 套憑據的漂移。

適合誰看：管理 MCP、企業 API、Agent 身份、合規審計與平臺成本的團隊。

試試看

先只做 Connect：集中憑據、SSO 和 CloudTrail；一週後再按審計缺口決定是否進入 Control。

注意點

這是參考架構與實施指南，不代表服務預設完成四級治理；文中自託管替代方案也需自行整合。

Microsoft Agent Framework 1.19 讓路由與會話跨程序儲存

發生了什麼：Microsoft Agent Framework .NET 1.19 新增持久化聊天客戶端路由、Azure Blob Storage 會話儲存與 Foundry 託管 Agent 狀態；並把 agent-hooks 攔截合同列為實驗功能，遷移到 2026-07-28 MCP Tasks 擴充套件。

為什麼值得關注：恢復會話時，狀態、路由和攔截規則必須一起回來，否則同一對話可能被送往不同模型或丟失治理上下文。

適合誰看：構建 .NET 企業 Agent、持久會話、MCP 長任務與雲端路由的團隊。

試試看

用 Blob 儲存儲存會話並重啟服務，核對聊天客戶端路由、託管狀態和 MCP task ID 是否保持一致。

注意點

持久化元件不自動保證外部副作用冪等；agent-hooks 仍是實驗功能，升級前需單獨迴歸。

04Google Gemini CLI美國 / 全球開源2026-08-22 釋出 / 2026-08-23 觀察官方預釋出

Gemini CLI nightly 把容器套接字隔離進 macOS Seatbelt

發生了什麼：Gemini CLI 8 月 22 日 nightly 修復 macOS Seatbelt 沙箱：隔離 Docker 及其他容器執行時的套接字和二進位制檔案，避免受限會話仍可觸達宿主容器控制面。這是單項安全補丁，變化集中但邊界清楚。

為什麼值得關注：Agent 即使被檔案沙箱包住，只要還能控制宿主容器執行時，就可能借更高許可權的執行面繞出原有邊界。

適合誰看：在 macOS 上用 Gemini CLI、Docker 或本地容器沙箱的開發者。

試試看

在測試機安裝該 nightly，對照檢查沙箱內的 Docker socket、容器二進位制與普通專案檔案可見性。

注意點

這是 nightly 且只說明 macOS Seatbelt 路徑；Linux、其他沙箱和既有容器許可權仍需分別驗證。

05Strands Agents SDK美國 / 全球開源2026-08-21 釋出 / 2026-08-23 觀察官方釋出

Strands Agents 1.53 把委派、取消與 MCP 授權一起推進

發生了什麼：Strands Agents Python 1.53 新增 agent-as-tool 委派、FileMemoryStore、MCP Streamable HTTP OAuth 與工具註解；同時加入執行範圍取消、上下文解除安裝策略、快取分數過濾，並補齊音訊內容塊。

為什麼值得關注：子 Agent 作為工具被呼叫後，委派身份、取消範圍、記憶位置和 MCP 授權會共同決定一次呼叫能否安全結束。

適合誰看：開發多 Agent 工具鏈、MCP 連線、長會話記憶或多模態應用的團隊。

試試看

把一個子 Agent 註冊為工具，接入 OAuth MCP 服務，並在執行中取消，檢查記憶、令牌和工具結果的收口。

注意點

釋出說明由提交自動彙總；不同模型與儲存提供方的取消、快取和授權語義仍需應用側驗收。

NVIDIA 把 Agent 安全邊界下沉到可強制執行的執行時

發生了什麼：NVIDIA 將 Agent 棧拆為產品分發、元編排、harness、安全執行時與推理基礎設施，並主張關鍵控制應落在 Agent 無法自行修改的執行時和基礎設施層，以最小許可權、隔離、即時授權與審計約束真實動作。

為什麼值得關注：提示詞和 harness 都會被替換；只有位於效果路徑下方的控制層，才能在模型變聰明後仍保持不可繞過。

適合誰看：設計 Agent 平臺、安全執行時、沙箱、身份與審計系統的架構師。

試試看

畫出自家 Agent 的五層棧，逐個標記誰能改策略、誰保管憑據、每次外部動作在哪一層被最終裁決。

注意點

這是 NVIDIA 的架構觀點，不是跨產品安全評測；執行時策略仍可能寫錯，外部結果也可能不確定。

07Google Biomarker Discovery Framework美國 / 全球研究2026-08-21 釋出 / 2026-08-23 觀察一手研究

Google 多 Agent 生物標誌物框架把生成推理與確定性統計分開

發生了什麼：Google Research 釋出 Biomarker Discovery Framework：多 Agent 在人工監督下迴圈完成假設生成、並行統計、模型訓練、對抗驗證和文獻推理。三組佇列共 9279 個參與者觀測中，系統提出 41 個心理健康和 25 個代謝候選指標。

為什麼值得關注：把生成式解釋與確定性計算分開，並讓 Critic 與 Defender 爭辯證據，比讓一個模型包辦科研結論更可核驗。

適合誰看：做可穿戴健康、科研 Agent、統計管線與臨床資料產品的團隊。

試試看

閱讀其六階段流程，把團隊現有分析任務拆成假設、統計、洩漏檢查、文獻核對和專家複審五個門。

注意點

這些結果用於生成假設，不構成因果證據或直接跨佇列復現；論文也明確報告了不穩定候選。

08Micron Research Labs美國 / 全球硬體2026-08-21 釋出 / 2026-08-23 觀察官方公告

Micron 計劃十年投入 100 億美元做 AI 記憶體長線研究

發生了什麼：Micron 宣佈成立美國長期創新中心 Micron Research Labs，計劃未來十年投入 100 億美元，把學術界與企業研究連線起來，面向記憶體與 AI 開展不受短期產品週期約束的長期探索。

為什麼值得關注：這是一筆圍繞記憶體瓶頸的十年押注：AI 基礎設施競爭正從算力晶片繼續延伸到資料搬運、容量與系統協同。

適合誰看：關注 AI 硬體、記憶體供應鏈、科研合作、人才與資本開支的團隊。

試試看

跟蹤實驗室首批研究方向、學術夥伴和招聘崗位，區分基礎研究投入與可量產產品路線。

注意點

100 億美元是未來十年的計劃投入，不是已經支出的金額，也不能直接推導具體產品、產能或收入。

市場觀察：今天最清楚的變化不是又多了幾個功能，而是行業正在為模型下方的層重新定價：會話儲存、安全執行時、工具治理、科研驗證和記憶體研究，都會成為 Agent 的長期成本與競爭力。
