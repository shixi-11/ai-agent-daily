RISC：S 主 · 安全 / 免疫R 輔 · 強韌 / 機體

風險邊界

護欄結果和 tracing 仍是框架證據，不等於防篡改日誌、能力衰減、外部效果回滾或跨公司責任鏈。

今天的新變化

這條訊息主要動到機器人的安全 / 免疫：嚴格沙箱決定程式碼執行邊界；強韌 / 機體為輔，因為並行停止與會話遊標必須在恢復時保持一致。

隔離邊界部分ContainerCodeExecutor 增加嚴格沙箱，但需要顯式開啟。
能力物件否版本沒有物件能力授予或衰減證據。
合作 / 學習視窗

Google ADK Java 可作為 ALUX 併發工具呼叫、程式碼沙箱和會話遊標的適配測試面。 學習嚴格沙箱的顯式開關、並行停止合併與會話過濾組合語義。

風險邊界

strict sandbox 仍為 opt-in；並行呼叫保留和會話過濾也不等於持久恢復、防篡改審計或能力衰減。

今天的新變化

本期的新變化是 Google ADK Java 在一個補丁裡同時修正沙箱邊界、並行停止合併和會話視窗，三者開始被視為同一執行路徑。

融資 / 合作視窗

最直接合作面：LangGraph 與 Microsoft Agent Framework 可驗證持久工作流和恢復裁決；OpenAI、Google ADK 與 E2B 覆蓋護欄、沙箱和連線生命週期；AgentScope 提供中國渠道與技能市場入口。
資本敘事：今天沒有足夠可靠的新融資金額進入正文。更強的融資訊號是，主流框架正在逐一修補失敗路徑，而 ALUX 有機會把這些分散補丁組織成完整的生產級執行時。

技術 / 產品啟發

優先產品：Failure-Path Runtime Receipt v0。欄位建議：run_id、termination_cause、policy_verdict、checkpoint_ref、pending_set、authority_epoch、effect_cursor、replay_ref。
優先 Demo：讓 CrewAI 修復前後對比 provider 與 cache token 計量，OpenAI Agents SDK 同時觸發護欄與兄弟任務失敗，E2B 連線經歷 GOAWAY。ALUX 只有在終止原因、許可權、檢查點和效果遊標一致時才允許恢復。

風險邊界

ALUX 仍不能被描述為已經完整交付的智慧體平臺。底層 TVM 已具備原生併發、持久執行、能力安全、執行記錄與逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤和評估工具仍待構建與融資。TVM 不會讓 LLM 本身確定性；它記錄模型輸出與環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。框架級 checkpoint、護欄、strict sandbox、後臺 run 與 permission hook 都不能單獨證明不可偽造能力、跨節點恢復、外部效果去重、原子回滾或中立跨公司協作。
