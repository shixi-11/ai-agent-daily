技術 / 產品啟發

優先 Demo：讓一個 Agent 在受控沙箱中呼叫 MCP 工具，觸發一次護欄拒絕、一次網路重定向和一次斷線恢復；最終驗證敏感載荷按策略遮罩、許可權沒有升級、記憶只提交一次、每個外部效果都有同一 run_id。

風險邊界

ALUX 仍不能被描述為已經完整交付的智慧體平臺。底層 TVM 已具備原生併發、持久執行、能力安全、執行記錄與逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤和評估工具仍待構建與融資。TVM 不會讓 LLM 本身確定性；它記錄模型輸出與環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。日誌、trace、session registry、沙箱、OAuth 與 SSRF 檢查均不能單獨證明不可偽造能力、跨節點恢復、外部效果去重、原子回滾或中立跨公司協作。
