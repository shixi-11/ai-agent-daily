C · 社會中強

並行會話與派生會話進入產品，但中立跨公司委派仍空缺。

RISC 機器說明

RISC = 生產級 Agent / 機器人身體的四個系統

一個真正能上生產的 Agent，不能只有大腦。它還要持續行動、扛住故障、抵禦越權，並進入真實組織協作。

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體持久執行、容錯、恢復與水平擴充套件。
I｜智慧 / 大腦模型迴圈、記憶、工具與編排。
S｜安全 / 免疫能力物件、策略審批、回滾與審計。
C｜連線 / 社會跨公司授權、中立基底、會話型別與生態連線。

風險邊界

ALUX 仍不能被描述為已經完整交付的智慧體平臺。底層 TVM 已具備原生併發、持久執行、能力安全、執行記錄與逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤和評估工具仍待構建。TVM 不會讓 LLM 本身確定性；它記錄模型輸出與環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。沙箱隔離、workload identity、session persistence、測試 replay、trace 和失敗摘要均不能單獨證明不可偽造能力、原子回滾或中立跨公司協作。
