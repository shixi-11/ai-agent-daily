對 ALUX 的關係：沙箱客戶端的依賴裝載和網路介面卡也屬於 Agent 身體。一次初始化失敗若被永久快取，會把臨時故障變成會話級失能；ALUX 應記錄介面卡 epoch、失敗類別與可重試性。

容錯能力是失敗的 fetcher 構建不再永久快取，後續請求會重新嘗試構建。

重新構建 fetcher 提高恢復性，但沒有證明工具呼叫效果冪等；晚繫結全域性 fetch 也可能被執行環境替換。

今天的新變化

09LangChain Deep Agents美國 / 全球開源2026-07-28 釋出 / 2026-07-28 觀察官方釋出

Deep Agents 0.1.49 為 YOLO 模式增加顯式退出與模式切換入口

發生了什麼：0.1.49 增加 LangSmith Gateway 憑據識別、模式切換斜槓命令，以及從 YOLO 提示返回 manual 模式的顯式出口；同版還加入 install 子命令並修復安裝後重啟互動。

對 ALUX 的關係：審批旁路一旦進入 Agent 迴圈，退出與撤銷必須和進入同樣明確。ALUX 可以把 manual、auto、YOLO 等模式建模為有範圍、有期限、可撤銷的許可權狀態，而非 UI 偏好。

可行動建議與產出物：建議形成 Guarded Autonomy Lease v0，繫結 mode、tool_scope、effect_budget、issued_by、expiry、revocation_ref 與 executed_effect_cursor。 可沉澱為：Guarded Autonomy Lease v0。

RISC：S 主 · 安全 / 免疫I 輔 · 智慧 / 大腦

這條訊息主要動到機器人的安全 / 免疫：高自主模式能否清晰退出和撤銷決定失控半徑；智慧 / 大腦為次維度，因為模式改變 Agent 自主迴圈的停頓頻率。

策略審批部分版本增加模式命令和從 YOLO 提示返回 manual 的顯式出口，但未公開逐工具審批策略。
回滾審計否退出 YOLO 只改變後續模式，釋出沒有說明既有外部效果可回滾或完整審計。
合作 / 學習視窗

可用 Deep Agents 模式迴圈對照 Guarded Autonomy Lease 的進入、衰減與撤銷。

風險邊界

顯式退出降低操作摩擦，但不能恢復 YOLO 期間已經產生的外部效果，也沒有公開每工具範圍與自動過期。

今天的新變化

昨天的新訊號是 YOLO 模式進入審批迴圈；今天新增的是顯式退回 manual 的出口與命令化模式切換。

融資 / 合作視窗

最直接合作面：OpenAI Agents SDK 提供程式化工具呼叫入口，MCP Python SDK 提供聯結器與認證語義，Qwen Code、Browser Use、E2B 提供長程執行與環境恢復樣本；Agno、Langfuse、Mem0 和 Deep Agents 可作為運營、觀測、記憶與審批出口。
