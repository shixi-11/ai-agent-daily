RISC 機器說明

RISC = 生產級 Agent / 機器人身體的四個系統

一個真正能上生產的 Agent，不能只有大腦。它要能持續執行，要能判斷和行動，要能抵禦錯誤、攻擊和投毒，也要能進入真實世界的協作網路。

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體容錯、持久執行、故障切換、水平擴充套件。沒有強韌機體，一次崩潰就會帶走全部工作。
I｜智慧 / 大腦推理迴圈、記憶、工具呼叫、任務編排。這是今天所有 Agent 框架最擁擠、也最成熟的競爭層。
S｜安全 / 免疫物件能力、策略約束、回滾機制、審計鏈路。沒有安全免疫，一條被投毒的指令就可能造成真實損害。
C｜連線 / 社會跨公司授權、中立基底、會話型別、協作邊界。沒有連線網路，每家公司的 Agent 都只能困在自己的孤島裡。

這條訊息主要動到機器人的安全 / 免疫：評分、媒體和 trace 決定能否發現異常並追責；強韌 / 機體為次維度，因為監控幫助識別執行退化，但不直接提供恢復。

回滾審計部分版本新增評分監控並修復媒體事件位元組持久化，但沒有證明回滾或防篡改重放。

可用 Langfuse 作為 ALUX 觀測前端，把可重放執行的派生指標輸出為 monitor，而不讓它充當事實源。 學習布林評分監控、媒體事件攝取和 MCP 評分讀取的產品介面。

風險邊界

ALUX 不能被說成已經完整交付智慧體平臺。當前底層 TVM 已具備併發、持久化執行、能力安全、執行記錄和逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤與評估工具仍是待構建和融資重點。也不要說 TVM 讓 LLM 本身確定性。準確說，TVM 記錄模型輸出和執行環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。憑據硬化、工作區信任、工具門禁、語義 span、monitor、執行緒增量和連線排空都不能自動證明物件能力、跨步驟原子回滾或中立跨公司協作。
