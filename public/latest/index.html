RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

Google搜索接入只读消费上下文

发生了什么：Google开始向AI Mode的Personal Intelligence推出Wallet连接，让用户主动授权后按消费记录和卡片权益获得建议。Drive文档与Gemini聊天上下文将在未来数周接入，不能视为今天已全部开放；用户可逐项开启或关闭连接，并管理搜索个性化。

为什么值得关注：搜索的输入不再只有提问和网页，还包括用户选择连接的账户资料。关键差别是读取上下文与执行动作分开：消费建议并不意味着搜索可以转账、投资或管理资金。

适合谁看：开发个人助手、跨应用检索与账户授权体验的产品工程团队。

试试看

注意点

Wallet从公告日开始逐步推出；Drive与Gemini连接仍待后续数周。Google明确该连接只读，不能移动或投资资金，本期未登录测试。

09Qwen-Audio-3.1-Live中国2026-11-23 发布 / 2026-11-24 观察官方发布

Qwen实时语音边交谈边等后台结果

发生了什么：QwenCloud发布qwen-audio-3.1-live，支持实时语音对话。应用或后台模型执行任务时，前台可继续接收音频、回应用户，结果就绪后再播报；文档分别给出平台Responses和应用自行接任务两种模式，并要求按委派标识关联结果。

为什么值得关注：语音助手不用在查库存或复杂计算时整段沉默。前后台分工能改善对话连续性，但自然接话不等于后台已成功；应用仍需验证返回事实并避免重复执行工具。

适合谁看：开发语音客服、实时助手与后台工具委派的产品工程团队。

试试看

从官方语音样例开始，先检查音频收发，再用固定库存回执验证任务委派；接真实服务前测试超时、重复事件和播报对应关系。

注意点

这是托管语音模型，不是开放权重。文档部分示例型号不一致，应核对调用名与服务权限；本期未连接API测试延迟或任务成功率。

10Claude EFS美国2026-11-23 发布 / 2026-11-24 观察官方发布

Claude企业防护把安全数据放进客户云桶

发生了什么：Anthropic推出Enterprise Frontier Safeguards测试版，覆盖Claude平台及其托管云渠道。符合资格组织可获零留存，提示与回答的加密副本进入客户云桶；平台新增存储每日检查失败与恢复通知。

为什么值得关注：敏感工作流的关键不只是“是否存储”，还包括谁持有副本、何时可访问与配置失效如何被发现。客户控制存储位置，与Vercel的独立审计路线提供不同层次的保证。

适合谁看：评估前沿Claude模型数据边界、企业存储与合规监控的平台团队。

试试看

检查组织资格和客户自有桶设置，梳理加密副本的访问与删除流程；在测试工作区验证存储失效和恢复通知，再决定是否接业务。

注意点

功能仍为测试版，且并非所有组织自动适用；使用Anthropic托管存储的工作区不属于EFS。零留存不代表客户云桶中没有加密副本。

13AudioVisual Flamingo美国2026-11-15 发布 / 2026-11-24 观察官方发布

AVF把既有声画权重转成Transformers格式

发生了什么：NVIDIA的AudioVisual Flamingo在11月15日转换为Transformers布局，权重数值不变，配置、处理器与聊天模板重新生成；次日更新推理接口示例。模型把同步音频和视频片段按时间交错输入，针对同时依赖声音与画面的问答生成文本，不包含语音合成。

为什么值得关注：开放模型能否运行，除了权重还取决于处理器、模板和后端是否配套。格式转换降低集成摩擦，但既不表示模型能力重新训练，也不等于上游稳定版本已完整支持。

适合谁看：研究长视频理解、声音画面对齐与本地多模态部署的开发者。

试试看

按模型卡使用指定Transformers分支与torchcodec，固定提交版本；选择答案同时依赖声音和画面的公开片段，核对时间对齐及资源占用。

注意点

仅限非商业研究，采用NVIDIA OneWay非商业许可，不能称OSI开源。需要指定分支及FFmpeg依赖；这是旧权重的新格式，不是模型今天首发。

01Shirudo美国2026-11-23 发布 / 2026-11-24 观察官方发布GitHub Stars 287许可证 BSD-2-Clause

Shirudo为运行中的Linux加临时防护

发生了什么：OpenAI与Cisco推出Shirudo，用eBPF把临时防护附加到运行中的Linux系统。团队可先观察影响，再由操作员批准执行；防护需签名验证，并通过TPM记录加载与移除。受控测试中，Codex生成的输入检查阻断了Java4Shell利用尝试，Elasticsearch无需重启。

为什么值得关注：发现漏洞到部署补丁之间仍有空窗。可测试、可批准的临时防护，把AI生成方案接到实际运行控制上；但阻断一次攻击，不等于已经修好漏洞或验证所有正常业务。

适合谁看：维护Linux服务、研究eBPF防护与安全Agent的基础设施团队。

试试看

按官方VM快速入门，在隔离环境体验签名、加载和验证防护；同时检查正常请求是否受影响，再研究故障回退流程。

注意点

项目仍为预发布，生产目标需内核补丁和TPM 2.0。运行时BSD-2-Clause，BPF另有BSD/GPL双许可；本期未部署，临时防护不能替代正式补丁。

03Formal Quantum Computation美国2026-11-23 发布 / 2026-11-24 观察官方发布GitHub Stars 32许可证 Apache-2.0

Gemini团队先证明，再共享量子算法改进

发生了什么：DeepMind披露Gemini 4多团队研究量子算法的流程：各组独立搜索，改进经Lean证明后进入共享笔记，每四小时交流。团队开放Lean库、问题规格与已验证解；在聚变相关计算中，官方报告综合计算成本降低11.8倍，纠错量子比特需求由5650降至4338。

为什么值得关注：多Agent交流的价值不只在集思广益，还在共享前先过滤错误。形式证明能约束数学正确性，但论文中的资源估算不能当成现有量子硬件上的运行提速。

适合谁看：研究科学Agent、多团队搜索、形式验证与量子算法的科研开发者。

试试看

先阅读论文成本定义，再检查Lean规格与discoveries分支的已验证解；按固定工具链构建小例子，区分数学资源模型与实际硬件成本。

注意点

这些算法仍超过首批纠错量子计算机预期资源。倍数来自作者研究，不是本期实测；数学证明也不等于已经完成硬件实验。

04Audited ZDR美国2026-11-23 发布 / 2026-11-24 观察官方发布

Vercel为零留存声明引入独立审计

发生了什么：Vercel宣布Audited ZDR层级：推理供应商须接受独立安全机构对代码、基础设施和实时流量的检查，并公开报告后才能进入。Baseten、Modal和Wafer已启动审计，报告预计12月8日前发布；平台另用含唯一网址的金丝雀提示，发现请求内容被额外读取的迹象。

为什么值得关注：零留存从合同承诺走向可公开检查的证据，路由和故障转移也须受同一边界约束。独立审计与持续探测互补，却都不能被写成永远不会发生泄露的保证。

适合谁看：处理专有代码、客户记录与受监管数据的模型平台和采购团队。

试试看

阅读审计范围及例外披露要求，待报告发布后再检查覆盖模型、工具与端点；区分现有ZDR声明和已通过审计的供应商。

注意点

启动合作方尚在审计中，不代表全部已获标签。金丝雀只能发现特定读取行为，不能检测写盘后从未读取的数据；本期未做独立安全测试。
