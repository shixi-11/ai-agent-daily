RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

AI Agent雷达

语音分工

语音模型分出不同工种

Qwen音频控制实时轮次，Nemotron处理长录音，Homi返回选项概率。输入同样是声音，延迟、上下文与输出形式却决定了三种不同工具。

运行条件

推理优化回到具体硬件

DeepInfer列明支持的加速器与缺失的服务组件，Andromeda区分生产吞吐和单项测量。性能数字只有连同系统边界一起读，才足以支持部署判断。

体验边界

互动项目让限制可见

花园把Agent活动放到公共空间，Harness把模型下载到浏览器。共享并不意味着私密，本地运行也不意味着所有设备都能玩。

Carbon先向网络防御伙伴开放

发生了什么：Google DeepMind于10月28日公布Gemini 4 Carbon，强化网络安全与长程工程任务。本周起先向部分网络防御者开放，再通过Fairwind计划逐步扩展至可信伙伴；开发者、企业和消费者的广泛开放仍待后续安排。

为什么值得关注：新模型的重点不只是单题得分，而是跨越多步骤、持续修复复杂问题。与此同时，能力发布与使用权限分开推进，读者需要把评测成绩和实际入口分别判断。

适合谁看：关注长程编码、安全防御以及企业模型采购与接入的技术团队。

试试看

注意点

官方网络安全基准在不启用护栏的条件下测量，不等于线上同等表现。公布价格为引入期每百万输入2美元、输出10美元，并非永久定价。

02QwenCloud中国2026-10-27 发布2026-10-29 观察官方一手来源

千问实时语音新增Flash模型

发生了什么：QwenCloud在10月27日上线qwen-audio-3.1-realtime-flash，提供双向流式语音、文字输入输出、函数调用和声音克隆。配套文档提供语义轮次判断及目标说话人增强，让对话系统更好地区分停顿、插话和背景人声。

为什么值得关注：语音助手的体验取决于什么时候开口、听谁说话，而不只是转写准确率。把轮次与说话人控制纳入接口，给客服和陪伴产品提供了更具体的调试抓手。

适合谁看：开发实时语音客服、交互设备与多语言陪伴应用的产品和工程团队。

试试看

用官方实时语音示例测试停顿和多人背景声，再选择WebSocket、WebRTC或AOQ接入；记录延迟与误打断，而不只检查回答文字。

注意点

联网搜索与函数调用不能同时启用。发布日志列26.2万词元窗口，但语音历史另限50轮、累计300秒，不能理解为无限保留整场录音。

03NVIDIA美国2026-10-28 发布2026-10-29 观察官方一手来源

Nemotron把长录音变成可指挥的转写

发生了什么：英伟达在10月28日开放Nemotron 3.5 Transcribe权重，用同一模型处理转写、翻译、说话人标记和音频问答。它支持40种语言的转写及最长一小时录音，可按提示保留口头语、调整书面格式或补充领域词汇，并提供微调材料。

为什么值得关注：录音变文字不再只有一种结果。让使用者明确要逐字稿、可读笔记还是带说话人的记录，有助于把模型输出接进采访、会议和媒体检索流程。

试试看

从模型卡的提示表选择两种输出风格，用同一小段录音比较遗漏、专名和时间戳；部署前检查显存与NeMo Speech版本要求。

注意点

这是离线录音模型，不是实时流式识别服务；权重采用OpenMDW-1.1许可。最快吞吐来自NIM专用优化，官方说明这些优化尚未全部进入开放代码。

07Vercel美国2026-10-28 发布2026-10-29 观察官方一手来源

虚拟模型让团队统一更换底座

发生了什么：Vercel在10月28日推出AI Gateway虚拟模型。团队用固定ID调用任务背后的模型，在控制台修改模型、回退顺序和零数据保留等设置，应用无需改代码或重新部署。配置可覆盖请求中的同名参数，调用方不能随意取消集中约束。

为什么值得关注：模型选择从散落在各应用的字符串，变成可集中管理的任务配置。团队更容易统一迁移与回退，但一个配置变化也可能同时影响许多业务入口。

适合谁看：维护多应用模型接入、成本归属与数据处理规则的平台工程团队。

试试看

为一个低风险任务创建虚拟ID，再建立候选ID比较新旧模型；迁移前核对供应商参数，切换后检查成功率和任务费用。

注意点

配置通常几分钟内传播，并非瞬时生效。供应商专属选项不会自动转译到另一家模型；集中路由也不能替代任务质量评测。

04egma.ai Homi全球2026-10-28 公开展示2026-10-29 观察作者一手来源GitHub Stars 3许可证 Apache-2.0

Homi用选项概率回答声音问题

发生了什么：Homi作者在10月28日展示音频决策模型：以冻结的Qwen3-Omni为底座，加入决策头和LoRA，直接返回每个选项的概率，不生成文字。仓库开放推理、评测、训练及数据重建代码，支持判断语速、音高变化和说话情绪等问题。

为什么值得关注：有些声音信息不会出现在转写稿里。把问题写成明确选项，可以直接接到分类与监测流程，也更容易检查模型的自信程度是否与实际正确率相符。

适合谁看：研究音频质检、语音交互评价及低成本批量声音分析的开发者。

试试看

从仓库给出的选择题示例开始，用已知答案的录音检查概率和误判；结合校准表读成绩，不把单一准确率当成全部表现。

注意点

作者明确列出多人长对话、说话人数及停顿推理的弱项。BF16运行约需70GB可用显存；自报成本使用H200批处理，不能当普通电脑的费用承诺。

05Tellers全球2026-10-28 公开展示2026-10-29 观察作者一手来源GitHub Stars 2许可证 MIT

Agent剪视频时也能随时预览

发生了什么：Tellers作者在10月28日展示视频编辑Skills，让编码助手用OTIO时间线组织切片、叠层、标题、特效和音乐。本地播放器可在浏览器预览，并把MP4导出到项目目录；另一个MCP插件用于编辑云端项目和调用生成服务。

为什么值得关注：让剪辑过程留下可编辑时间线，人就能看见Agent改了哪里，而不是只等一个最终视频。预览与导出在本机进行，也让本地素材工作流更容易接入。

适合谁看：希望用编码助手剪辑录屏、短片和产品演示的创作者及小型团队。

试试看

从几段非敏感本地素材开始，让助手创建时间线、调整一个剪点并预览；导出前检查字幕、音乐和素材路径是否正确。

注意点

本地播放器无需Tellers账号，但云端MCP需要登录。播放器加载Tellers发布的脚本，不能把本地预览直接称为完全离线；本期未实际导出视频。

06DeepSeek中国2026-10-20 发布2026-10-29 观察官方一手来源GitHub Stars 23,916许可证 Apache-2.0

DeepInfer开放离线推理核心

发生了什么：DeepSeek于10月20日公开DeepInfer推理框架代码，支持DeepSeek-V4.1-Flash，包含优化内核、异步调度、结构化输出和多种并行方式。仓库给出源码构建与离线推理示例，支持英伟达SM100及华为昇腾950，采用Apache-2.0许可。

为什么值得关注：这次开放把模型背后的执行方式变成可检查的代码：从批次调度到确定性采样，团队可以研究输出稳定性与吞吐如何共同优化，而不只比较模型权重。

试试看

注意点

仓库不包含完整KV缓存系统、服务拆分和数据并行负载均衡；批次不变推理与确定性采样目前仅支持英伟达平台。

08Meta美国2026-10-28 发布2026-10-29 观察官方一手来源

Meta把广告检索压进同一GPU流程

发生了什么：Meta在10月28日披露新一代Andromeda架构，把索引匹配、混合专家评分和候选筛选放到同一GPU服务器，减少中间数据搬运。官方称生产流水线每秒处理超过十亿条广告候选；单独评分内核更高的吞吐则属于另一测量口径。

为什么值得关注：当计算越来越快，网络与显存之间的搬运反而可能成为瓶颈。这个案例的价值在于模型、内核和服务结构共同设计，而不是把某个局部倍数直接套给整个系统。

适合谁看：研究大规模推荐、检索服务和GPU系统优化的架构师与工程团队。

试试看

对照原文的评分内核、索引匹配和端到端三种口径，画出自己服务中的数据搬运路径；先测量等待，再决定改模型还是改部署。

注意点

这是Meta生产架构披露，不是可直接下载的通用检索产品。超过百亿条每秒是单独评分内核指标，不能和生产端到端十亿级吞吐混用。
