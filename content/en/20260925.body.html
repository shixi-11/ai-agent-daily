RISC Machine Guide

RISC = four systems for a production-grade agent or robot

A production-grade agent needs more than a brain. It must keep working, withstand failures, prevent overreach, and collaborate across real organizations.

The industry has delivered a capable brain. Production agents also need a body, an immune system, and a social interface.ALUX is building that complete machine.
R | Resilience / BodyDurable execution, fault tolerance, recovery, and horizontal scaling. One failure should not erase the work.
I | Intelligence / BrainModel loops, memory, tools, and orchestration determine how an agent reasons and completes complex work.
S | Security / ImmunityObject capabilities, policy approvals, rollback, and audit limit the reach of failures and unauthorized actions.
C | Connectivity / SocietyCross-company authorization, a neutral substrate, session types, and ecosystem connections let agents work beyond one product.

New Features Worth Watching

01Gemini 3.8 Live AvatarUnited StatesPublished 2026-09-24 / Observed 2026-09-25Primary sources

Gemini adds expressive avatars to live agents

What changed: Google introduced Gemini 3.8 Live with Live Avatar on September 24. It generates a visual persona alongside speech, keeps talking while tools run asynchronously, and supports lip synchronization across 97 languages. It is available in Gemini Enterprise; custom avatars made from reference images require enterprise allowlisting.

Why it matters: Virtual receptionists can move beyond generating an answer and then animating an avatar. Conversation and background work can proceed together. The useful test is whether the agent accurately explains progress while waiting for tools.

Who should care: Product teams building multilingual service agents, virtual receptionists, and interactive enterprise walkthroughs.

Try it

Watch the hotel check-in demo, then read the Live API documentation. Test interruptions, tool delays, and language changes against the actual business outcome.

Watch for

Enterprise availability does not mean general consumer access. Custom avatars require allowlisting, and demonstrations do not establish latency or lip-sync quality under every network condition.

02Gemini 3.8 TTSUnited StatesPublished 2026-09-23 / Observed 2026-09-25Primary sources

Gemini speech models let creators direct each line

What changed: Google launched Gemini 3.8 Flash TTS and Flash-Lite TTS on September 23. Flash emphasizes character voice design; Flash-Lite targets high-volume generation. Both offer line-by-line pacing and emotional direction, including two-speaker dialogue. Rollout has begun in the Gemini API and AI Studio; enterprise API access is still coming soon.

Why it matters: Voices become reusable character assets rather than fixed presets. For podcasts, games, and audiobooks, consistency across passages matters more than one impressive sample.

Who should care: Creators and developers producing character audio, game dialogue, audiobooks, or large-scale dubbing.

Try it

Write a two-speaker scene in AI Studio and specify delivery and pauses. Generate several scenes for the same character, comparing timbre, emphasis, and recognizability.

Watch for

Voice replication requires a matching verbal consent recording and is unavailable in some regions. Voice remixing is still forthcoming; not every advertised capability is available now.

03Qwen Decision ModelChinaPublished 2026-09-24 / Observed 2026-09-25Primary sources

Qwen returns decision probabilities without generating prose

What changed: QwenCloud added decision-model-preview on September 24. A request carries business context and multiple classification, yes/no, or scoring questions. One forward pass returns decisions and probabilities, with confidence for classification and scoring, rather than chat text. Its System One endpoint targets ticket routing, agent routing, and result validation.

Why it matters: Many workflows need a decision, not an explanation. A dedicated endpoint removes a text-parsing step, but teams still need to establish how well its probabilities match real outcomes.

Who should care: Engineers building high-volume routing, classification, quality checks, and agent assignment systems.

Try it

Test department, escalation, and severity questions on historical tickets with human labels. Start with a few questions and define human handoff rules for uncertain results.

Watch for

The preview does not support streaming, tool calls, or web search. Example latency is not a service guarantee, and confidence is not automatically an observed accuracy rate.

04WeVisDocChinaPaper published 2026-09-17 / Observed 2026-09-25Primary sources

Tencent releases document parsers for complex page images

What changed: Tencent’s WeVisDoc offers 2B and 4B weights that convert page images into structured Markdown, including LaTeX formulas and HTML tables. Its September 17 paper describes two-stage training: first broadening coverage of layouts and degraded images, then adding data to address remaining errors. This issue covers the previously released Apache-2.0 models and accompanying inference code.

Why it matters: Clean PDFs can hide the difficulties of real scans. Separate checks for text, formulas, tables, and reading order reveal more than an aggregate score, especially on degraded pages.

Who should care: Teams parsing scanned archives, scientific papers, enterprise documents, and complex layouts.

Try it

Start with the repository’s single-page example. Compare both sizes on clean and degraded versions of the same pages, checking tables, formulas, and truncated outputs.

Watch for

The paper was published September 17, not today. Rankings cover the end-to-end parsers compared by the authors. PDFs must first be rendered to images; a complete document workflow requires additional work.

05Scholé Learn AnywhereGlobalProduct showcase 2026-09-24 / Observed 2026-09-25Primary sources

Scholé guides hands-on learning alongside real webpages

What changed: Scholé showcased its Learn Anywhere browser extension on September 24. Learners build projects in real tools while a sidebar reads the selected page, provides tasks and visual hints, and checks progress. Exercises cover agents, websites, and notebooks. Users perform the work themselves and keep the resulting artifacts in their own accounts.

Why it matters: Having AI do the work is different from learning to do it. Guidance beside the actual interface closes the gap between tutorials and practice. The stronger test comes after the hints disappear.

Who should care: Individuals and teams learning unfamiliar software, building a first agent, or turning training into tangible work.

Try it

Choose an unfamiliar tool and attempt each step before asking for help. Close the sidebar afterward and repeat a key operation without guidance.

Watch for

Exercise entry points allow an account-free start, but the extension requires a Scholé account. It supports English, French, German, and Italian. Screen frames are not stored; text progress and guidance are retained.

06StorytailorUnited StatesProduct showcase 2026-09-24 / Observed 2026-09-25Primary sources

Brief: Turn a child’s drawing into a recurring story character

What changed: Storytailor showcased its rebuilt product on September 24. Children’s drawings become recurring characters in illustrated stories with reading, audio, word explanations, and offline activities. New accounts receive two free stories.

Why it matters: A single creation can grow into a personal cast and story world.

Who should care: Families reading together, educators, and children’s content creators.

Try it

Read a sample, then test character consistency across stories using an original drawing.

Watch for

Adults manage accounts and review stories together with children. Translating a story also uses a credit.

07minimi 2.0United StatesProduct showcase 2026-09-24 / Observed 2026-09-25Primary sources

Brief: A desktop cat tracks unfinished commitments

What changed: minimi 2.0 showcased commitment tracking on September 24. According to its website, it reads personal context on a Mac, identifies unfinished commitments, and looks for later activity that indicates completion. Memory is stored locally and can be shared with assistants through MCP.

Why it matters: A task may begin in a conversation rather than a manually maintained list.

Who should care: Mac users who switch apps frequently and miss follow-ups.

Try it

Test one simple commitment against detection, reminders, and completion judgments.

Watch for

These claims have not been independently tested. Local storage does not guarantee that connected assistants keep data on-device.

08WhiteboardGlobalPublic showcase 2026-09-24 / Observed 2026-09-25GitHub Stars 427License MITPrimary sources

Whiteboard lets agents explain code on a shared canvas

What changed: Whiteboard’s September 24 public showcase presents a software-design canvas for people and agents. The MIT-licensed desktop app connects to tools such as Claude Code and Codex. Agents draw explanations that link back to code, alongside semantic diffs and decision logs. Downloads are available for macOS and Fedora.

Why it matters: Faster code generation can make review the bottleneck. Connecting design, implementation, and decision context helps reviewers assess requirements rather than simply scroll through changes.

Who should care: Software teams reviewing agent-written changes, discussing architecture, and tracing implementation decisions.

Try it

Try a completed branch. Ask the agent to diagram interfaces and data flow, follow the links into code, and compare its decision log with the original constraints.

Watch for

Whiteboard cannot currently edit files, and cross-repository browsing is limited. Changes made after sharing are not synchronized automatically; reviews must be shared again.

09GitHub Fuzzing TaskflowUnited StatesPublished 2026-09-24 / Observed 2026-09-25GitHub Stars 2License MITPrimary sources

GitHub agents improve fuzzing through coverage feedback

What changed: GitHub Security Lab introduced its open-source Fuzzing Taskflow on September 24. For C/C++ projects, it identifies entry points, writes harnesses, runs AFL++, and uses coverage reports to improve inputs and harnesses. SQLite retains state and corpora persist across runs. Crashes are minimized, replayed, and deduplicated before reports go to human review.

Why it matters: The useful automation is not just finding crashes. It turns coverage gaps into subsequent actions without discarding earlier progress. Separating model decisions from tool execution also makes the workflow easier to inspect.

Who should care: C/C++ maintainers expanding existing fuzzing coverage or establishing an initial testing workflow.

Try it

Use a small test project in a disposable Codespace or virtual machine. Inspect coverage changes, then distinguish library defects from errors in generated harnesses.

Watch for

The pipeline executes model-selected build commands directly on its host. Avoid privileged everyday environments. Reports and patches need review; crash counts are not vulnerability counts.

10Hugging Face Hub 2.0US / FrancePublished 2026-09-24 / Observed 2026-09-25Primary sources

Brief: Hugging Face Hub 2.0 changes its HTTP stack

What changed: Hugging Face released Hub 2.0 on September 24, moving clients and transport exceptions to httpx2 and removing APIs deprecated in 1.x. Custom clients, exception handling, and legacy CLI calls need review.

Why it matters: Network handling can break even when model-download code appears unchanged.

Who should care: Developers maintaining model downloads, uploads, and deployment scripts.

Try it

Check client factories, exception types, and retired commands against the migration guide.

Watch for

This is a breaking release. Validate certificates and proxy behavior in a test environment.

11LuxRemixUnited StatesReproduction update 2026-09-24 / Observed 2026-09-25Primary sources

Brief: LuxRemix adds parameters for reproducing paper results

What changed: Meta updated LuxRemix on September 24 with camera parameters for 48 curated test scenes, paper evaluation cases, and a color-management submodule fix. Researchers can reconstruct the corresponding perspective test sets from existing panorama data.

Why it matters: Reproducing results requires the original camera parameters and evaluation settings, not just the data.

Who should care: Teams researching indoor relighting, inverse rendering, and reproducibility.

Try it

Reconstruct one test scene and compare it with the published evaluation cases.

Watch for

The dataset predates this update. Its custom license restricts use to noncommercial research.

12Private AI ComputeUnited StatesPublished 2026-09-23 / Observed 2026-09-25Primary sources

Brief: Google outlines protected persistent cloud memory

What changed: Google updated its Private AI Compute architecture on September 23. Devices hold decryption keys; isolated cloud environments process requests and encrypt new context for storage. Published materials include server-software records and audit information.

Why it matters: Cross-device memory raises a key question: who can decrypt it?

Who should care: Teams studying personal-agent memory, cloud isolation, and privacy architecture.

Try it

Compare device keys, server verification, and persistent storage in the technical brief.

Watch for

This is an architecture disclosure, not confirmation that cross-device memory is available to every user.

13Project SuncatcherUnited StatesPublished 2026-09-24 / Observed 2026-09-25Primary sources

Brief: Google prepares an orbital test for TPUs

What changed: Google outlined plans for Suncatcher’s first orbital test on September 24. A prototype satellite developed with Planet will test how TPUs withstand the stresses of launch and space, including vibration, radiation, and cooling challenges in a vacuum. A two-satellite interconnect test is planned for 2027.

Why it matters: Orbital compute must demonstrate hardware survival before scaling into clusters.

Who should care: Readers following AI hardware, energy, and long-term compute infrastructure.

Try it

Watch the technical videos and track chip resilience, cooling, and laser links separately.

Watch for

These are plans and ground-test findings, not an operational orbital data center.
