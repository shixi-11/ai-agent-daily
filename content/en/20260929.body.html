RISC Machine Guide

RISC = four systems for a production-grade agent or robot

A production-grade agent needs more than a brain. It must keep working, withstand failures, prevent overreach, and collaborate across real organizations.

The industry has delivered a capable brain. Production agents also need a body, an immune system, and a social interface.ALUX is building that complete machine.
R | Resilience / BodyDurable execution, fault tolerance, recovery, and horizontal scaling. One failure should not erase the work.
I | Intelligence / BrainModel loops, memory, tools, and orchestration determine how an agent reasons and completes complex work.
S | Security / ImmunityObject capabilities, policy approvals, rollback, and auditing. Without these safeguards, recovery and connectivity can amplify the impact of failures and unauthorized actions.
C | Connectivity / SocietyCross-company authorization, a neutral substrate, session types, and ecosystem connections let agents work beyond one product.

01Claude Sonnet 5.5United StatesPublished 2026-09-28 / Observed 2026-09-29Primary sources

Sonnet 5.5 Targets Task Efficiency

What changed: Anthropic has released Sonnet 5.5 in Claude, through its API, and on major cloud platforms. The company reports faster coding, visual work, and knowledge tasks, with lower output usage reducing some task costs. Token prices remain $2 per million input tokens and $10 per million output tokens. The claimed savings come from usage, not a price cut.

Why it matters: Completed work per dollar is more useful than an isolated leaderboard result. Teams with existing Sonnet workflows can compare success rates, latency, and total bills to see whether the upgrade pays off.

Who should care: Claude Code users, office-assistant developers, and teams responsible for model selection and spending.

Try it

Compare a fixed set of coding or document tasks against the previous version. Use claude-sonnet-5-5 through the API and check that reasoning settings are comparable.

Watch for

Speed and savings figures come from Anthropic’s tests, not guarantees for every task. API clients that previously disabled thinking need to follow the new migration requirements.

02Holo4FrancePublished 2026-09-28 / Observed 2026-09-29Weight license 27B: CC-BY-NC-4.0; 35B-A3B: Apache-2.0Primary sources

Holo4 Connects Desktop Actions and Code

What changed: H Company has released Holo4 in dense 27B and mixture-of-experts 35B-A3B versions, with API access and downloadable weights. The models combine desktop, web, and Android interaction with code, MCP, and APIs. Published task trajectories let readers inspect how the agents carry out multistep operations.

Why it matters: Computer-use models need more than accurate clicks. Switching between interfaces and code, and making failures inspectable, matters when bringing them into real software workflows.

Who should care: Teams building computer-use assistants, test automation, and desktop agents, plus researchers studying execution traces.

Try it

Start with the official trajectory viewer to inspect tool switching in FreeCAD or Godot tasks. Then choose API access or a checkpoint that fits your hardware.

Watch for

The 27B model uses CC-BY-NC-4.0; 35B-A3B uses Apache-2.0. Their commercial-use terms differ. Benchmark results also depend on the task set and execution harness.

03Shopify Checkout WebMCPCanadaAnnouncement reported 2026-09-28 / Observed 2026-09-29Primary sources

Shopify Adds Checkout Tools for Browser Agents

What changed: Shopify’s Checkout WebMCP lets browser agents read, update, and complete eligible checkouts while sharing the buyer’s browser-session state. The documented tools are get_checkout, update_checkout, and complete_checkout. Placing an order requires the buyer’s explicit confirmation; login and payment verification remain with the buyer.

Why it matters: Shopping agents gain structured tools instead of relying only on visual button recognition. That does not grant unrestricted payment authority. Shared state, tool contracts, and buyer approval together define the transaction boundary.

Who should care: Shopping-assistant developers, Shopify merchants, and product and engineering teams designing browser-based payment flows.

Try it

Check browser support, agent registration, and signing requirements in the checkout documentation. Test order changes, human verification, and final confirmation in a test store.

Watch for

This is not a universal interface for every browser or store. Checkout eligibility, browser capabilities, and agent authentication requirements apply; buyer confirmation cannot be skipped.

04MicroLLM LabGlobalCreator showcase 2026-09-28 / Observed 2026-09-29Primary sources

Brief: A Browser Lab for Small Models

What changed: MicroLLM Lab offers browser-based small-model chat, speed comparisons, and custom evaluations. It prioritizes WebGPU, lists WASM and JavaScript fallbacks, and caches models locally in the browser.

Why it matters: Seeing differences on your own device is more useful than borrowing cloud speed rankings.

Who should care: Local-AI enthusiasts and frontend developers.

Try it

Open the lab and start with one small model and a question with a checkable answer.

Watch for

We inspected the page but did not load a model. Speed, caching, and compatibility still need testing.

05Nibia FabricGlobalPublished 2026-09-27 / Observed 2026-09-29GitHub Stars 1License Apache-2.0Primary sources

Nibia Links Spare Computers for Inference

What changed: Nibia Fabric v0.7.0-alpha is Apache-2.0-licensed experimental software. It aims to connect Macs, Linux machines, and Windows PCs on a trusted local network for distributed GGUF inference. A coordinator exposes a web interface and an OpenAI-compatible API while workers contribute compute. The project also offers a local Metal path on Apple silicon.

Why it matters: Several modest computers may become a useful experimental resource, but network overhead can erase the gains. This is a cross-device inference design to investigate, not a way to turn scattered RAM into one pool of fast GPU memory.

Who should care: Developers with spare computers, local-model researchers, and anyone comparing distributed inference with a single machine.

Try it

Choose the appropriate release for each operating system. Connect a few nodes on a trusted LAN, then compare latency, stability, and memory use against the same GGUF model on one machine.

Watch for

This is an experimental alpha. Communication overhead and the hardware mix affect results. Combined memory capacity is not a speed guarantee; start with nonsensitive samples.

06JeffGlobalPublished 2026-09-28 / Observed 2026-09-29GitHub Stars 238License MITPrimary sources

Brief: Small Models Pick Moves in Games

What changed: Jeff offers Qwen and Gemma decision-model fine-tunes with Doom, Frogger, and Pac-Man examples. Code describes the state and action consequences in text; each forward pass produces probabilities for the available options.

Why it matters: Reducing game decisions to classification reveals how much the task description matters.

Who should care: Developers building game AI and local classifiers.

Try it

Run a game script from the repository and compare it with the rule-based bot.

Watch for

It reads English text, not screens. Base-model terms apply separately from the code license.

07SemloopGlobalPublished 2026-09-27 / Observed 2026-09-29GitHub Stars 0License MITPrimary sources

Brief: Detecting Loops Beyond Repeated Words

What changed: Semloop looks for semantic stagnation in agent traces, even when the wording keeps changing. Its MIT-licensed repository provides semantic-judge interfaces, a mock judge, and synthetic trace tests.

Why it matters: The question is whether the task advanced, not simply whether the text repeated.

Who should care: Agent orchestration and observability developers.

Try it

Check for false positives on your own failure traces before using it to stop runs.

Watch for

Current experiments rely mainly on synthetic traces and do not establish detection rates in production.

Global Technology and Market Watch

08NVIDIA Open Agent SafetyUnited StatesPublished 2026-09-28 / Observed 2026-09-29Primary sources

NVIDIA Moves Agent Monitoring Outside the Runtime

What changed: NVIDIA has announced Open Agent Safety, connecting its OpenShell security runtime with continuous monitoring. The Sentry reference design uses a BlueField-4 DPU to monitor and isolate agents from outside their compute environment. OpenShell is broadly available; the hardware reference design does not mean every component is a turnkey product.

Why it matters: Asking the system doing the work to police itself can leave blind spots. An independent monitoring path extends safety beyond prompts and into infrastructure, but policy effectiveness and isolation still need deployment-level validation.

Who should care: Teams running long-lived agent workloads, managing enterprise compute, or responsible for infrastructure isolation and auditing.

Try it

Read the architecture overview and separate deployable OpenShell software from the Sentry hardware reference design. Then validate policies and audit records with controlled tool calls.

Watch for

Millisecond isolation is a vendor claim, not our measurement. BlueField hardware, the software runtime, and support for third-party processors have different deployment requirements.

09AMD and World LabsUnited StatesPublished 2026-09-28 / Observed 2026-09-29Primary sources

AMD Plans to Acquire World Labs

What changed: World Labs has signed a definitive acquisition agreement with AMD. The deal is expected to close by the end of 2026, subject to regulatory approval and other conditions. After closing, Fei-Fei Li would become AMD’s executive vice president and chief scientist. The team would continue spatial-intelligence research, bringing world-model research into closer alignment with AMD’s chips and computing platforms.

Why it matters: Chip competition is extending into model and application research. If the deal closes, AMD could help define spatial intelligence’s computing requirements rather than just supply the compute. The benefits of integration remain unproven.

Who should care: Researchers and investors following world models, robotics, graphics computing, and competition among chipmakers.

Try it

Read World Labs’ announcement and distinguish the closing timeline, team arrangements, and future product commitments. Watch for changes in public models, tools, and hardware support.

Watch for

An agreement has been signed; the acquisition has not closed. We do not treat a reported media valuation as company-confirmed or future integration goals as delivered capabilities.

10PHNTM OneGlobalCreator showcase 2026-09-28 / Observed 2026-09-29Primary sources

Brief: A Raspberry Pi Assistant Opens Reservations

What changed: PHNTM One packages local voice, document, and memory features in a Raspberry Pi desktop device, with a bounded set of self-repair actions. Reservations are free, with a target product price of $549. The first batch will ship only after the final version is certified.

Why it matters: Assistant hardware is drawing attention to upkeep and sustained operation, not just its shape.

Who should care: Local-assistant enthusiasts and hardware product designers.

Try it

Review the product page’s local mode, repair limits, and reservation terms.

Watch for

It is not in stock. Privacy and stability remain product claims, not independently tested results.

11AWS vLLM-OmniUnited StatesPublished 2026-09-28 / Observed 2026-09-29Primary sources

Brief: One Runtime for Voice and Video

What changed: AWS has published two vLLM-Omni deployment guides covering real-time voice and image-to-video generation. The media example uses a real-time endpoint for images and an asynchronous queue for slower video generation.

Why it matters: A shared runtime does not mean every request should wait synchronously.

Who should care: Teams building multimodal apps and inference services.

Try it

Check endpoints, quotas, and cleanup steps in the official examples before deploying.

Watch for

Cloud GPU endpoints keep incurring charges. Single-run timings are not benchmarks.
