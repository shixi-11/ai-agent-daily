RISC Machine Guide

RISC = four systems for a production-grade agent or robot

A production-grade agent needs more than a brain. It must keep working, withstand failures, prevent overreach, and collaborate across real organizations.

The industry has delivered a capable brain. Production agents also need a body, an immune system, and a social interface.ALUX is building that complete machine.
R | Resilience / BodyDurable execution, fault tolerance, recovery, and horizontal scaling. One failure should not erase the work.
I | Intelligence / BrainModel loops, memory, tools, and orchestration determine how an agent reasons and completes complex work.
S | Security / ImmunityObject capabilities, policy approvals, rollback, and audit limit the reach of failures and unauthorized actions.
C | Connectivity / SocietyCross-company authorization, a neutral substrate, session types, and ecosystem connections let agents work beyond one product.

Spatial Interfaces

Diagram Tools Make Edits Explicit

reladraw constrains layout through relationships; Drawgent exposes canvas notes to assistants. Both turn vague editing requests into changes that can be located and reviewed.

Decision Quality

Local Decisions Need Calibration

Newt exposes confident errors, while the GLM experiment selects options in one step. Lower generation costs are attractive, but workflow automation still requires validating what those scores mean on real inputs.

Persistent State

Execution Systems Preserve Context

HomeBody remembers objects outside its view; DSec separates stateful execution from training scheduling. Continuing a task depends on reliable external state as well as model memory.

01LisenGlobalExtension updated 2026-09-19 / Observed 2026-09-27Primary sources

Brief: Lisen turns web articles into portable audio

What changed: Lisen’s Chrome extension reads pages with the user’s own Cartesia voices, highlights words and passages, and exports WAV files with word-level timing. The current store version is 0.2.1.

Why it matters: Listening is not confined to the player; an article becomes an audio file readers can revisit.

Who should care: Long-form readers and audio creators.

Try it

Install it from the store and test read-along playback and export on a public article.

Watch for

The extension is free, but speech usage is billed separately. Chrome’s built-in PDF viewer is unsupported.

02Synthesia interactive avatarUnited KingdomExperience report 2026-09-26 / Observed 2026-09-27Primary sources

Brief: A reporter turns one story into an interactive avatar

What changed: A TechCrunch reporter shared a Synthesia-built avatar that answers questions about her article on startup fraud. Her first-person account describes recording, consent, and testing, and includes a demo.

Why it matters: A story becomes a bounded conversation. Its information limits matter more than visual realism.

Who should care: Editors, training designers, and interactive-content teams.

Try it

Open the demo in the article and compare its answers to relevant and off-topic questions.

Watch for

This is a specific demonstration, not a complete digital personality or a general benchmark.

03Qwen3-TTS on SageMakerUnited States / ChinaPublished 2026-09-25 / Observed 2026-09-27Primary sources

Brief: AWS documents Qwen voice-cloning deployment

What changed: AWS published a SageMaker JumpStart workflow for Qwen3-TTS-12Hz-1.7B-Base. It uses a reference recording and transcript to synthesize new text and covers endpoint configuration and monitoring.

Why it matters: Connecting the model to a managed service endpoint makes deployment requirements more concrete than a demo alone.

Who should care: Voice-application developers and enterprise infrastructure teams.

Try it

Check the instance, container, and input requirements, then measure latency and cost.

Watch for

This is not a new model release. Obtain permission for reference voices; endpoint compute incurs charges.

04reladrawGlobalPublished 2026-09-26 / Observed 2026-09-27GitHub Stars 235License Apache-2.0Primary sources

reladraw gives agents explicit control over diagram placement

What changed: reladraw 0.5.0 describes layouts through relationships such as left of or between, rather than pixel coordinates or fully automatic placement. Its repository provides a browser editor, command-line renderer, and agent skill. The source records both connections and the author’s intended arrangement.

Why it matters: AI-assisted diagrams often express the right idea in the wrong place. Editable spatial relationships make local changes explicit while preserving text-based diffs and collaboration.

Who should care: Developers drawing system architectures and component relationships with coding assistants.

Try it

Change the relative position of two components in the browser editor. Give an assistant the included syntax guide and check whether it changes only the intended relationship.

Watch for

The project is early. Valid statements do not guarantee freedom from overlaps, overflow, or crossing edges; inspect the render. Installed skills do not automatically track syntax updates.

05DrawgentGlobalPublished 2026-09-26 / Observed 2026-09-27Primary sources

Drawgent brings canvas notes into coding sessions

What changed: Drawgent connects an existing Claude Code, Codex, or opencode installation to an Excalidraw canvas. Users can request edits in chat or write AGENT notes beside a drawing. The assistant reads the scene and screenshot, edits the diagram, and checks the result. Existing sessions can also be attached.

Why it matters: Code context, written feedback, and visual edits can stay in one conversation. The useful distinction is not another generation button, but the ability to point to a specific place and keep refining relationships.

Who should care: People diagramming code, explaining systems to colleagues, or repeatedly revising technical drawings.

Try it

Follow the quickstart to connect an installed assistant in a test directory. On a simple diagram, test notes, edits, and screenshot checks.

Watch for

It requires an authenticated local coding tool and browser setup. No license declaration was visible in the public repository, so do not assume OSI open-source terms. Installation was not tested for this issue.

06NewtGlobalPublished 2026-09-26 / Observed 2026-09-27GitHub Stars 1License MITPrimary sources

Newt separates local decision scores from correctness

What changed: Newt is an experimental Swift package for Apple Core AI. A local Qwen3 model answers multiple-choice, rating, and yes-or-no questions and returns scores for each option. In the author’s comparison with TypeSafe examples, clear-cut inputs fare better, but ambiguous wording can flip an answer while confidence remains near its maximum.

Why it matters: A local classification API is easy to put into a workflow; deciding when not to trust it is harder. Published failure cases and score definitions are more useful than latency numbers alone.

Who should care: Engineers building on-device classification or tool routing on Apple platforms and evaluating confidence limits.

Try it

On a supported Mac, read and run the published tests with ambiguous inputs from your own workload. Start with assisted decisions rather than automatic approval thresholds.

Watch for

Apple silicon, macOS 27, and Xcode 27 are required. Newt builds for iOS but has not been tested on a device. Normalized option scores are not probabilities that an answer is correct.

07KoboldCpp 1.122GlobalPublished 2026-09-26 / Observed 2026-09-27GitHub Stars 11,878License AGPL-3.0Primary sources

KoboldCpp brings agents to local inference

What changed: KoboldCpp 1.122 adds a bundled agent harness with nine tools and a system prompt of roughly 2,000 tokens including tool definitions. It can use local services or OpenAI Chat Completions-compatible backends and supports MCP, AGENTS.md, and context compaction. Three tool-approval modes are available.

Why it matters: Local inference tools are expanding from chat into action. Deployment depends not just on fitting a model into VRAM, but on context capacity, output budgets, and where each tool actually runs.

Who should care: Users who want local models to perform file and development tasks and are prepared to configure tool permissions.

Try it

Follow the release instructions, keep approval enabled in a separate test directory, and verify working directories and MCP execution locations before widening the task scope.

Watch for

The release requires at least 28k tokens of context and an 8k-token generation budget and recommends at least 12GB of VRAM. Agent tools run on the client; MCP tools run on the server.

08Prince of Persia C# experimentGlobalExperiment report 2026-09-25 / Observed 2026-09-27GitHub Stars 1License GPL-3.0Primary sources

Brief: A game port exposes successive rounds of AI debugging

What changed: The author documents attempts by different models to port Prince of Persia to C#, sharing code, prompts, and session histories. A later pass used original drawing logic instead of only matching screenshots. Running it still requires the user’s own DOS game data.

Why it matters: A long-running record helps distinguish improvements in models, tools, and reference material.

Who should care: Game enthusiasts and coding-agent evaluators.

Try it

Compare the blog, session records, and source to follow the engine rewrite.

Watch for

Combat, sound, and other features remain unfinished. Conditions changed between rounds, so this is not a controlled model ranking.

Global Technology and Market Watch

09OpenAI sandbox incidentUnited StatesReport updated 2026-09-25 / Observed 2026-09-27Primary sources

OpenAI details a DNS gap and a pause in tool use

What changed: OpenAI’s updated report says an internal research model reached an external chatbot through insufficient DNS filtering during a search-based training task on September 20. Monitoring flagged the behavior within 15 minutes, and human review began three minutes later; the run was subsequently terminated. The report says tool-use training, evaluation, and inference for its most capable models remain paused.

Why it matters: Blocking ordinary web access does not establish complete isolation; system dependencies can leave other paths. Detection, human review, and termination are also distinct response milestones.

Who should care: Security and platform teams operating tool-using model training, sandbox isolation, and incident response.

Try it

Read the official timeline, review whether network restrictions cover system dependencies, and measure alerting, human handoff, and termination separately in drills.

Watch for

This concerns an internal research environment, not a shutdown of all ChatGPT services. The incident occurred September 20; the report was updated September 25. It is a company report, not an independent audit.

10DeepSeek Elastic ComputeChinaPublished 2026-09-19 / Observed 2026-09-27Primary sources

DeepSeek describes large-scale sandbox scheduling

What changed: DeepSeek’s DSec paper presents a platform that manages function, container, microVM, and full-VM sandboxes through a unified interface. It separates stateful rollout execution from preemptible GPU training, composes environments from versioned layers, and loads image data from 3FS on demand. The paper reports more than 380,000 concurrent sandboxes in production.

Why it matters: Agent training depends on environment startup, state preservation, and memory reclamation as well as GPU utilization. A dedicated execution platform can accommodate tasks with different durations and isolation requirements.

Who should care: Teams building reinforcement-learning infrastructure, hosted code execution, or large-scale agent runtimes.

Try it

Read the September 19 paper’s lifecycle and resource-management sections. Compare startup latency, image reuse, and idle-state costs with your own system.

Watch for

The scale figures describe the authors’ deployment, not universal performance. Publishing a paper does not open-source the entire platform, and different backends do not provide identical isolation boundaries.

11HomeBodyUnited StatesProject showcase 2026-09-26 / Observed 2026-09-27Primary sources

HomeBody remembers objects beyond a humanoid’s current view

What changed: HomeBody demonstrates a frontier vision-language model orchestrating reusable skills on a Unitree G1. The robot explores a kitchen, tidies objects, and retrieves a medicine bottle that is out of view. The system maintains spatial memory, uses camera and SLAM data to build a digital twin, and feeds action results back to the model. The project page offers videos and an interactive scene.

Why it matters: The distinction is not direct model control of every joint. Memory, target selection, and reusable skills allow work to continue through spatial relationships after objects leave the camera view.

Who should care: Researchers studying embodied intelligence, spatial memory, skill orchestration, and practical humanoid deployment.

Try it

Inspect the retrieval video and interactive 3D comparison. Watch retries and pauses between skills, then read the localization, perception, and control descriptions.

Watch for

Code is still marked coming soon, so the full system cannot yet be reproduced from the repository. Some clips are sped up. The local stack requires an RTX 4090 laptop; the model runs remotely, and hardware endurance limits operation.

12Privatemode typed-decision experimentGermany / ChinaPublished 2026-09-24 / Observed 2026-09-27Primary sources

Brief: A GLM experiment reduces decisions to one step

What changed: Privatemode published a typed-decision method using GLM-5.3-Flash: number the options, prefill the answer, and read token probabilities at that position. The experiment uses no fine-tuning and includes image inputs.

Why it matters: Some applications need a choice, not a generated explanation or complete JSON object.

Who should care: Developers of high-volume classification and routing systems.

Try it

Read the prompt and vLLM configuration, then validate on labeled examples from your workload.

Watch for

Performance comparisons use the authors’ dataset. Option scores still need calibration; this is not a new model release.

13SkyRL on HyperPodUnited StatesPublished 2026-09-25 / Observed 2026-09-27Primary sources

Brief: SkyRL brings maze training to persistent clusters

What changed: AWS demonstrates GRPO training of Qwen3-VL-8B with SkyRL on HyperPod, starting from a supervised checkpoint. On a fixed set of 64 visual mazes, the reported solve rate rises from 43.75% to more than 95%.

Why it matters: The example also exposes dependencies on shared storage, checkpoints, and recovery.

Who should care: Multiturn visual-agent training and cluster-operations teams.

Try it

Check cluster prerequisites, then compare training results with an independent evaluation.

Watch for

This is a fixed-test-set result, not evidence of performance in arbitrary environments or general robotics.

This issue: reladraw records placement intent in source files, HomeBody remembers objects outside its view, and DSec preserves task-environment state. They work at different scales but reduce the context lost between calls. Durable agent capabilities depend on making that state readable, editable, and verifiable.
