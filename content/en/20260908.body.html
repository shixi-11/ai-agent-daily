RISC Machine Primer

RISC = the four systems that make an agent production-ready

A production-grade agent needs more than a brain. It must keep operating, survive failure, resist overreach, and participate in real organizational workflows.

The industry has delivered an excellent brain, but a production-grade agent also needs a body, an immune system, and a social layer.ALUX is building that complete machine.
R | Robust — BodyDurable execution, fault tolerance, recovery, and horizontal scale. Without a resilient body, one failure can erase progress.
I | Intelligent — BrainModel loops, memory, tools, and orchestration. This system determines how an agent reasons, uses tools, and completes complex work.
S | Secure — Immune SystemObject-capability security, policy controls, rollback, and audit. Without an immune system, recovery and connectivity expand the blast radius.
C | Connected — SocialCross-company authorization, neutral substrate, session types, and ecosystem connectors. Without a social interface, an agent remains confined to one product.

01Anthropic Fermat FormalizationUnited States / Global researchPublished 2026-09-07 / Observed 2026-09-08Official research

An Anthropic Team Formalizes Fermat in Lean

What changed: Anthropic reports that its researchers and Claude completed a Lean formalization of Fermat’s Last Theorem in 11 days, producing roughly 13 million lines of computer-checkable proof code. Nature covered the work the same day.

Why it matters: AI-assisted mathematics is moving from plausible prose toward verifiable proof objects. That changes how research agents can be evaluated: an answer must survive replay inside a proof system, not merely sound convincing.

Who should care: Formal-verification and theorem-prover builders.

Try it

Read the official methods first, then sample three pivotal lemmas and compare the natural-language goal, Lean definitions, and dependency chain.

Keep in mind

The 11-day timeline and roughly 13 million lines come from Anthropic and Nature. This issue did not rerun the full proof, and the result should not be generalized to every open mathematical problem.

02Nous Research Hermes KanbanUnited States / Global open sourcePublished 2026-09-07 / Observed 2026-09-08Official open-source releaseGitHub Stars 243,053License MIT

Hermes Gives Multiple Agents a Durable Shared Task Board

What changed: Hermes Agent v0.21.1 adds a SQLite-backed Kanban board. Multiple Hermes profiles can share tasks, dependencies, owners, and status, then resume from the same board after a restart.

Why it matters: Once an agent system spans processes and sessions, task state and ownership often fail before model capability does. Persisting coordination in a queryable store is more robust than repeatedly reconstructing context in prompts.

Who should care: Teams building multi-agent orchestration, research pipelines, development automation, or long-running assistants.

Try it

Create a shared board with three dependent tasks. Let two profiles claim and update work, restart them, and verify that state, dependencies, and history survive.

Keep in mind

The feature and version are documented in the official release and guide. This issue did not test high-contention writes, merge conflicts, or recovery from database corruption.

03QuireGlobal open sourcePublished 2026-09-07 / Observed 2026-09-08Official open-source releaseGitHub Stars 0License AGPL-3.0

Quire Lets Humans and Agents Co-edit the Same Local Markdown File

What changed: Quire keeps a local Markdown file as the source of truth while people and AI agents edit it together in real time. Agent changes remain visible and reversible, without moving the document into a closed cloud editor.

Why it matters: Knowledge workflows break when people and agents operate on different versions of the truth. A shared filesystem object brings collaboration, version control, and downstream automation back to the same artifact.

Who should care: Writers, researchers, documentation engineers, knowledge-base teams, and builders of local-first tools.

Try it

Track a test document with Git. Let an agent revise one section while a person edits another, then inspect conflict handling, undo behavior, and the final diff.

Keep in mind

The project is in public beta and uses AGPL-3.0. Local-first storage does not mean every connected model runs offline, so production users must inspect how data is routed to the model.

04KeyclaspGlobal open sourcePublished 2026-09-07 / Observed 2026-09-08Official open-source releaseGitHub Stars 2License not declared

Keyclasp Keeps Secret Values Out of Agent Prompts

What changed: Keyclasp v0.2.0 beta provides a local encrypted vault. Agents reference secret names, and the tool injects selected values when launching a child process, reducing the chance that credentials appear in prompts or command text.

Why it matters: Agents need access to real services without turning credentials into copyable context. Name-based references and execution-time injection reduce exposure and create a clearer authorization checkpoint.

Who should care: Teams building coding agents, automation platforms, internal tools, or credential-governance systems.

Try it

Use a disposable test secret with one child command. Inspect shell history, process arguments, errors, and logs for plaintext, then revoke it and verify the failure path.

Keep in mind

The project explicitly warns that the child process still receives the real secret and can exfiltrate it. Keyclasp is not a sandbox and does not provide operating-system user isolation. The release remains beta.

05Principia BenchmarkGlobal researchPublished 2026-09-04 / Observed 2026-09-08Official research

Principia Compares Physics Across Paired Objects

What changed: Principia evaluates generated video by comparing paired objects across mass, velocity, and post-collision relationships. Instead of asking only whether one clip looks plausible, it checks whether a model preserves consistent Newtonian behavior.

Why it matters: Photorealistic pixels can hide broken dynamics. Relational evaluation shifts attention from visual polish to stable world rules, which matters for world models and robotic simulators.

Who should care: Teams working on video models, world models, robotics simulation, game physics, or multimodal evaluation.

Try it

Generate several light-versus-heavy collision clips from one prompt. Blind-rate visual quality first, then use the benchmark to compare momentum and relative changes.

Keep in mind

The site and paper publish the method and reported results, but this issue did not reproduce them. The benchmark covers selected Newtonian relationships and does not establish complete physical understanding.

OpenAI Brings AI Tools Into Independent Ukrainian Newsrooms

What changed: OpenAI announced a program supporting independent Ukrainian news organizations with AI-assisted source-material processing, translation, and editorial workflows, while stating that editorial judgment remains with the newsroom.

Why it matters: When agents enter a high-risk knowledge profession, efficiency is only part of the product question. Provenance, accountability, and final decision rights matter more. Newsrooms offer a stricter governance test than ordinary office automation.

Who should care: Teams building media products, translation tools, research assistants, fact-checking systems, or high-risk content governance.

Try it

Break the described workflow into collection, translation, verification, and publication. Mark the human approval point, source record, and reversible action in each stage.

Keep in mind

This issue relies on OpenAI’s announcement and RSS feed. It did not independently interview participating newsrooms or evaluate long-term editorial quality, cost, or effects on journalistic independence.

08Microsoft SecurityUnited States / Global securityPublished 2026-09-03 / Observed 2026-09-08Official research

ASCII Smuggling Expands Into Phishing Evasion

What changed: Microsoft Security reports that ASCII smuggling, which uses invisible Unicode control characters to conceal instructions, has expanded from AI prompt injection into phishing evasion.

Why it matters: The same text-normalization gap can mislead both people and agents. Email should be normalized consistently before it enters automated summarization or action pipelines.

Who should care: Email-security and enterprise-agent builders.

Try it

Use harmless test text to compare raw characters, normalized output, and the agent-visible string. Verify that detection occurs before any action.

Keep in mind

This item relies on Microsoft’s published research. Do not reproduce attack payloads in production mailboxes.

09Relaxed Memory Model ZooEurope / Global systemsPublished 2026-09-07 / Observed 2026-09-08Official demo

A Memory Model Zoo Makes Concurrency Counterexamples Runnable

What changed: The Relaxed Memory Model Zoo turns classic weak-memory litmus tests into interactive examples that show which concurrent outcomes different architectures permit.

Why it matters: Sequential intuition often hides concurrency bugs. Runnable counterexamples give engineers and agents a concrete execution boundary to reason about.

Who should care: Teams working on systems programming, compilers, concurrent runtimes, formal verification, or infrastructure agents.

Try it

Open the store-buffering example, switch between two memory models, and record which outcomes are allowed and which barriers change them.

Keep in mind

The site is designed for teaching and exploration. It does not replace validation against the target hardware, compiler version, and formal specification.

11Qwen MM Plugins Omni MemoryChina / Global open sourcePublished 2026-09-03 / Observed 2026-09-08Official open-source releaseGitHub Stars 2,805License Apache-2.0

Qwen Omni Memory Retains Audio Cues Across Long Video

What changed: Qwen MM Plugins released Omni Memory 1.0.0, adding joint audiovisual memory for long video to an agent harness while preserving people, speech content, tone, and acoustic information.

Why it matters: A video memory that stores only transcripts loses who spoke, how it sounded, and what appeared on screen. Joint indexing preserves more of the original context for later questions.

Who should care: Teams building video research, meeting analysis, media retrieval, or multimodal agents.

Try it

Use one long video with several scenes, then ask separately about people, exact speech, tone, and environmental sound while checking cited positions.

Keep in mind

This issue relies on the official initial capability release. It did not independently measure recall or storage cost on very long video.
