RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Gemini Decision多模态决策模型美国与英国2026-11-11 发布2026-11-12 观察官方一手来源

Gemini Decision把判断与生成分开

发生了什么：Google在11月11日发布Gemini Decision及Decisions API，对文本、图片、音视频和PDF直接返回概率，而不生成答案文本。单次请求最多评估1000个独立问题，共享输入与全部问题合计受262144 token上下文窗口限制，支持是非、单选及分档评分。

为什么值得关注：路由、规则检查和候选排序不必都经过长篇生成；专用接口让团队分别衡量判断延迟、概率校准与业务阈值。

适合谁看：需要多模态分类、客服分流、规则筛查与Agent工具选择的开发团队。

试试看

从官方Decisions Playground或v1beta示例开始，用有标签的小样本比较是非概率和分档评分。

注意点

零输出token不等于免费；模型不支持文本生成、函数调用、Batch或缓存。概率与校准表现需要用自己的分布验证，本期未实测。

Qwen4预览只向订阅计划开放

发生了什么：QwenCloud在11月11日上线Qwen4-Max-Preview，整合文本、图像和视频理解，支持工具调用与结构化输出。官方给出1M上下文及393216 token的思考与答案共用输出额度；本次只通过Token Plan提供，不支持按量付费。

为什么值得关注：预览更适合验证多模态与工程迁移，不适合当作稳定生产版本：官方已明确结束时间与到期退役安排。

适合谁看：已使用Token Plan、计划测试长上下文编码或视觉Agent的开发者与团队。

试试看

按官网Token Plan专用端点设置qwen4-max-preview；迁移时为思考和答案共同预留输出预算。

注意点

预览从北京时间11月11日10:00至11月25日24:00，结束后退役；不是GA或开放权重。max_tokens会限制思考加答案总量，本期未实测。

04AWS AgentCore美国2026-11-11T15:13:16-08:00 发布2026-11-12 观察官方一手来源

AgentCore把网页搜索开放为独立API

发生了什么：AWS为AgentCore新增独立网页搜索API，不必先创建Gateway或MCP目标即可从SDK调用。它查询Amazon自营索引，返回排序结果与文本摘录，支持域名和发布日期过滤；调用沿用IAM与SigV4，也可通过PrivateLink接入私有网络。

为什么值得关注：搜索不再要求先采用一整套Agent网关。已有编排和数据管道可以单独接入，而统一工具策略与多工具授权仍可留给Gateway，两种入口承担不同集成需求。

适合谁看：已有AWS应用、自建Agent循环或需要为事实核查管道增加搜索能力的开发团队。

试试看

沿官方示例从小范围域名查询开始，核对返回摘录与原文；需要统一管理多个工具时，再比较Gateway路线，不必一次迁移现有编排。

注意点

网页标题、链接和日期仅在索引具备时返回，不能假定每条齐全。CloudTrail数据事件需要另行启用，日志不记录查询文本与过滤条件；本期未调用测试。

03AlphaGenome 2细胞类型条件基因模型美国与英国2026-11-11 发布2026-11-12 观察官方一手来源

AlphaGenome 2按细胞状态预测变异影响

发生了什么：DeepMind在11月11日公布AlphaGenome 2，把百万碱基DNA序列与指定细胞类型或状态共同作为输入，预测变异对基因调控的影响。模型训练覆盖超过一亿个细胞谱；现通过AlphaGenome API供非商业研究使用，商业研究处于私有预览。

为什么值得关注：把组织平均值细化到具体细胞，有助于研究者寻找只在特定免疫状态或病变细胞中起作用的调控变化。

适合谁看：研究遗传变异、单细胞组学与疾病机制的科研团队。

试试看

先读论文与官方API说明，核对研究许可、目标细胞及所需输入，再用已知实验结果测试预测。

注意点

官方TenK10K结果是特定数据集上的评估，不代表临床诊断准确率；模型预测仍需实验验证。API开放不等于权重开放，商业使用另有资格。
