RISC 机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

ALUX 今日雷达

机会

执行准入可成为统一运行时入口

把工具来源、路径、会话、授权和恢复状态收进一份收据，能让 ALUX 的安全与强韧共享同一条状态链。

风险

便利性正在扩大授权半径

工具发现、同步技能和会话级批准会让一次配置影响后续未知动作；没有过期与撤销游标，控制面会失真。

可行动资产

Execution Admission Receipt v0

建议统一 tool_digest、resolved_path、session_owner、grant_scope、recovery_epoch、terminal_verdict 与 replay_ref。

Gemini CLI 0.55.1 把供应链验证与工具发现放进同一版本

发生了什么：0.55.1 新增工具注册表发现，同时修复发布验证中的工作区二进制遮蔽、大小写敏感路径漏拦、memory import 符号链接越界，并将 macOS 沙箱内的 ~/.gitconfig 设为只读。

对 ALUX 的关系：工具发现扩大 Agent 的能力面，供应链和路径修复说明能力入口必须连同来源、文件边界与发布证据一起验证。ALUX 可把工具摘要、解析后路径、发布构件和能力授予绑定到同一收据。

可行动建议与产出物：建议形成 Tool Discovery Provenance Receipt v0，绑定 registry_source、tool_digest、resolved_path、artifact_attestation、sandbox_policy 与 capability_ref。 可沉淀为：Tool Discovery Provenance Receipt v0。

RISC：S 主 · 安全 / 免疫C 辅 · 连接 / 社会

这条消息主要动到机器人的安全 / 免疫：工具发现会扩大攻击面，路径、构件与沙箱验证决定能力是否可信；连接 / 社会为辅，因为注册表正在成为生态入口。

隔离边界是发布说明明确修复符号链接越界，并把 macOS 沙箱中的 ~/.gitconfig 设为只读。

风险边界

具体逃逸与遮蔽路径得到修复，但没有证明对象能力、不可绕过策略闸、跨节点恢复或防篡改重放。

今天的新变化

今天的新变化是 Gemini CLI 在开放工具发现的同时加固发布、路径和沙箱边界，把生态扩展与供应链防守放进同一版本。

对 ALUX 的关系：批准从单次调用扩大到会话，会把风险从一个动作扩散到未来未知动作。ALUX 可将 grant scope、tool digest、session owner、expiry、revocation cursor 和每次 invocation 绑定。

策略审批是工具可在一次批准后于整段对话中继续使用。

技术 / 产品启发

优先产品：Execution Admission Receipt v0。字段建议：tool_digest、artifact_attestation、resolved_path、session_owner、grant_scope、expiry、recovery_epoch、terminal_verdict、replay_ref。

风险边界

ALUX 仍不能被描述为已经完整交付的智能体平台。底层 TVM 已具备原生并发、持久执行、能力安全、运行记录与逐比特重放审计等关键基础；智能体产品层、可观测性、仪表盘、追踪和评估工具仍待构建与融资。TVM 不会让 LLM 本身确定性；它记录模型输出与环境输入，使编排、权限、状态转移和审计可重放、可验证。框架级 trace、检查点、路径修复、会话级批准和人工接管状态都不能单独证明不可伪造能力、跨节点恢复、外部效果去重、原子回滚或中立跨公司协作。
