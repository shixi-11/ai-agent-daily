RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

04Gemini Enterprise for Legal美国 / 企业法律2026-08-25 发布 / 2026-08-26 观察官方公告

Google 把 Gemini Enterprise 做成法律专用 Agent 平台

发生了什么：Google Cloud 推出 Gemini Enterprise for Legal，提供面向律师的专用 Skills、法律系统连接器和第三方 Agent 生态；官方强调平台沿用组织既有的权限与访问控制边界，并与法律数据、研究和工作流服务商连接。

为什么值得关注：企业 Agent 的竞争从通用聊天入口，转向“行业知识、系统连接和原有权限”打包交付。

适合谁看：律所、法务、合规团队，以及做垂直 Agent 平台和企业连接器的产品经理。

试试看

用一份脱敏合同设计试点，分别测试条款提取、引证回链和审批移交，并记录每个 Agent 实际读取了哪些系统。

注意点

这是厂商发布口径；权限继承不等于输出正确或律师保密义务自动满足，具体可用性、地区、价格和第三方数据边界需逐项确认。

05Claude Code美国 / 全球开发者2026-08-25 发布 / 2026-08-26 观察官方发布

Claude Code 2.1.246 收紧自动授权与后台会话

发生了什么：Claude Code 2.1.246 会警告可能误匹配选项的 Bash 通配授权，在 /permissions 中开放 Auto mode 分类规则查看与编辑，并修复 MCP 调用被打断却误报完成、后台会话启动失败、第三方网关凭据被带到 Anthropic 遥测等问题。

为什么值得关注：自动模式真正危险的不是一次拒绝，而是模糊规则、错误终态和凭据跨主机流动同时发生。

适合谁看：使用 Claude Code 自动模式、后台会话、MCP 和第三方兼容网关的团队。

试试看

审查现有 Bash 通配规则，在测试会话中打断一次 MCP 调用，再核对模型收到的是 interrupted 而不是 completed。

注意点

预警并不会自动修复宽泛授权；版本仍包含大量体验修补，关键安全行为应在团队自己的策略和代理环境中回归测试。

01Tencent WeMM-Embedding中国 / 全球开放权重2026-08-25 发布 / 2026-08-26 观察官方开放权重GitHub Stars 130权重许可 Apache-2.0

腾讯开放 WeMM 多模态向量模型全家桶

发生了什么：腾讯微信视觉团队开放 WeMM-Embedding 2B、4B、9B 三档权重、推理与评测代码，可把文本、图像、视频、视觉文档及交错输入映射到同一向量空间；模型支持 Matryoshka 维度裁剪，并给出 vLLM、SGLang 部署配方。

为什么值得关注：Agent 检索不再只处理文字，图片、视频和文档可以进入同一召回层，向量长度也能按成本动态缩减。

适合谁看：做多模态 RAG、视频检索、视觉文档搜索和 Agent 记忆的团队。

试试看

先用 2B 模型在一组图文混合资料上比较 256 与 2048 维召回率、显存和延迟，再决定是否上 4B 或 9B。

注意点

代码、模型参数与公开权重均按 Apache-2.0 提供；官方榜单仍需独立复现，也要核对实际硬件上的显存、延迟与吞吐。

02Ambient Context美国 / macOS 用户2026-08-25 发布 / 2026-08-26 观察社区新仓库GitHub Stars 124许可证 MIT

Ambient Context 把桌面工作记录写成本地记忆

发生了什么：新项目 Ambient Context 通过 macOS 辅助功能树读取当前焦点窗口文字，按天去重写入本地 Markdown，并为 Agent 附带格式说明；它不截屏、不上传，也在落盘前跳过密码字段并过滤常见密钥和卡号形态。

为什么值得关注：个人 Agent 的长期记忆可以从云端全量监控，转向用户可查看、可搜索、可删除的普通文件。

适合谁看：想让编码 Agent 记住工作轨迹，同时坚持本地优先的 macOS 用户。

试试看

只在测试账户构建运行，先录十分钟非敏感工作，再逐项检查私密窗口、终端、密码管理器和锁屏时是否停止采集。

注意点

项目仍是未签名早期版本，辅助功能权限本身很高；规则过滤不是绝对防线，纯文本日志也可能暴露客户名、文档内容和访问路径。

03Mistral Vibe法国 / 全球开发者2026-08-20 发布 / 2026-08-26 观察官方发布GitHub Stars 4,876许可证 Apache-2.0

Mistral Vibe 2.24.3 让运行中配置可直接调整

发生了什么：Mistral 的 Apache-2.0 开源编码 Agent 更新到 2.24.3：Agent 或命令运行时仍可调用斜杠命令和设置选择器，底栏显示进程 PID，连接器启动失败会明确报出；同时升级 Python 依赖以清理已知安全通告。

为什么值得关注：长回合编码任务不必为了查看或调整配置而中断，失败也不再被“没有连接器”这种模糊状态吞掉。

适合谁看：运行终端编码 Agent、子 Agent、MCP 连接器和长时间任务的开发者。

试试看

开一个长命令，在执行中切换设置并查看 PID；随后故意填入错误连接器地址，确认界面能给出可定位的启动错误。

注意点

这是交互与诊断改进，不代表所有运行中配置都能安全热更新；自动批准工具仍会扩大文件与命令执行风险。

06OpenAI custom chip美国 / 全球基础设施2026-08-25 发布 / 2026-08-26 观察可信媒体

OpenAI 称自研芯片已在测试中超过英伟达

发生了什么：Bloomberg 报道，OpenAI 表示与 Broadcom 合作的首款自研 AI 芯片已在内部测试中超过英伟达处理器。公开报道把它描述为面向自家工作负载的定制 ASIC，意味着模型公司正把竞争继续下沉到芯片与数据中心能效。

为什么值得关注：一旦头部模型厂商能为固定推理负载定制硅片，成本、供给和模型架构会被共同优化，而不再只受通用 GPU 路线牵引。

适合谁看：关注推理成本、芯片供应、云基础设施和模型系统协同设计的团队。

试试看

把报道中的比较对象、工作负载、精度、吞吐、功耗和集群规模列成表，缺失项全部留空，等待正式技术披露。

注意点

“超过”来自 OpenAI 内部测试，公开材料尚不足以做同代、同精度、同系统规模的公平比较；量产、良率和部署节奏也未被证明。

07OpenAI Codex usage resets全球 Codex 用户2026-08-26 发布 / 2026-08-26 观察官方说明

OpenAI 明确区分 Codex 自动重置与重置卡

发生了什么：OpenAI 更新 Codex 用量说明：自动或全局重置会直接刷新符合条件的用量窗口，不会留下可保存的卡；重置卡是发到账户的一次性权益，需要用户手动使用，并可能设有到期时间。使用重置卡会刷新符合条件的窗口，但不会改变原定的每周重置日。

为什么值得关注：高强度使用 Codex 时，“额度已被系统刷新”和“账户收到一张可稍后使用的卡”是两种完全不同的状态，自动化和用量安排不能混为一谈。

适合谁看：Codex 高频用户、团队管理员，以及依赖 Codex 定时任务的工作流维护者。

试试看

在 Settings → Usage 或命令行 /status 中分别记录下次计划重置时间与可用重置卡数量；只有看到卡并确认到期条件后再决定何时使用。

注意点

本次更新解释机制，不代表所有用户今天都获得重置。资格、额度、发放和到期随活动、计划、工作区及地区变化；官方未宣布面向所有用户的重置，所以没有统一北京时间。

本期观察：Agent 的真实成本不只来自模型价格。芯片决定供应与效率，用量规则决定工作节奏，两者都会改变 Agent 的可用性。
