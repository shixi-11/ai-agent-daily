RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

注意点

权重开放不等于OSI开源；文本模型采用LFM自定义许可。约1GB是文本版四比特权重口径，不是全模态运行总内存。

注意点

约300条是内部训练样本规模，不是测试集大小；官方未给出评测集规模，72.8%不能当作所有语言或业务的预期准确率。

06Qwen Code中国2026-10-27 发布2026-10-28 观察官方一手来源GitHub Stars 28,759许可证 Apache-2.0

发生了什么：Qwen Code在10月27日合入会话级Workflow模式，默认关闭。开启后，后续普通输入会提醒模型考虑工作流，偏好可随会话恢复；CLI、SDK及部分协议接口可查询和修改状态。该变化目前是开发分支代码，不是已确认的稳定版发行。

为什么值得关注：持续偏好与一次提示分开，能减少反复交代，但也需要区分已请求、工具可用和实际生效。项目把这些状态单独暴露，比一个含义模糊的开关更可检查。

注意点

开关不会自行启动任务，也不改变推理强度、预算或授权限制；Managed、SSH及派生子代理等会话不支持修改该模式。
