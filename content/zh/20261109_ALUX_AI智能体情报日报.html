RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

用自己的话筛掉不想看的信息流

发生了什么：Remedy作者公开展示桌面Chrome扩展：用户用自然语言定义不想看什么，系统按语义而非单纯关键词检查信息流。它可隐藏帖子，也可在检测完成前模糊图像；弹窗保留已移除内容的记录，用户能查看、调整规则或暂停过滤。

为什么值得关注：同一个词可能出现在讨厌的争吵，也可能出现在关心的本地新闻。按意思设置例外，比不断追加屏蔽词更接近个人阅读偏好；过滤结果仍应让人可见、可改。

适合谁看：想减少信息流噪声的桌面读者，以及研究个性化浏览工具的产品团队。

试试看

在Chrome从官网安装，先试一条范围清楚的自定义规则，再检查移除历史。免费首日结束后，免费档仅在一个网站做文字过滤。

注意点

帖子文字和图像会发给其AI模型，不是全本地处理；零留存是厂商声明。Lite每月6.99美元，Plus每月14.99美元，误删与漏判仍可能发生。
