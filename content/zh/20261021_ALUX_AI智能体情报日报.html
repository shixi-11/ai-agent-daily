RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

02OpenAI美国2026-10-20 发布2026-10-21 观察官方一手来源

提示缓存延长到十二小时，先算写入成本

发生了什么：OpenAI于10月20日在Responses API加入12小时提示缓存，可让共享指令、工具和资料跨数小时复用。适用模型中，12小时写入按普通输入价格的2.5倍计费，默认30分钟为1.25倍；两档读取费率相同，写入倍数是总价而非额外附加费。

为什么值得关注：长期运行的助手不必因为工作间隔较长就反复付出完整输入成本。但更长缓存需要更贵的首次写入，适合内容稳定且会多次复用的前缀，不能默认所有请求都更省。

适合谁看：维护持续办公Agent、重复分析资料，以及负责模型费用与数据策略的团队。

试试看

把全天稳定资料放在前部，频繁变化的会话留在后部；用实际缓存读写token数核算两档费用，再决定哪些前缀值得延长保存。

注意点

12小时是最低计费复用窗口，不是删除期限，也不保证每次都降低延迟。新参数适用于支持的模型和Responses API，旧模型保留原机制。

06Vercel美国2026-10-19 发布2026-10-21 观察官方一手来源GitHub Stars 28许可证 Apache-2.0

编码Agent断线后从执行记录继续

发生了什么：Vercel在10月19日的公告中推出durable-harness，为Pi、OpenCode、Claude Code和Codex等执行框架接入持久日志与队列。模型和工具调用先记录意图，再保存结果；进程中断后可由新实例接续，已完成步骤读取记录，不必从头重做。

为什么值得关注：常驻虚拟机只能保住一台机器，不能自动回答“这一步做完没有”。把调用结果和恢复规则显式保存，才有条件让长流程跨进程继续，并减少重复执行或重复计费。

适合谁看：部署云端编码Agent、后台工作流，以及需要处理断线和超时的开发团队。

试试看

先用示例模拟断开连接与终止进程，核对已完成调用是否被复用；把只读查询和有外部副作用的工具分开设置恢复策略，再接真实业务。

注意点

中断的安全工具可以重跑，其他调用可能返回“或已执行”供后续核查。它不是所有外部操作恰好执行一次的通用保证，工具声明与业务幂等仍重要。

05Cohere加拿大2026-10-20 发布2026-10-21 观察官方一手来源

模型先判断能否答对，再检查这次答案

发生了什么：Cohere于10月20日介绍CALIBER训练方法，让推理模型先估计解题成功率，再判断自己刚生成的答案是否正确。团队用3万道数学题训练7B和30B模型；在留出数学集上，7B模型的校准误差从0.059降至0.028，并测试了三组问答数据。

为什么值得关注：“这类题我擅长”与“这一次答案可信”不是同一件事。分别训练两个判断，为决定何时复核提供更细的依据；同时需要看置信度是否能区分正确和错误，而非只对齐总体准确率。

适合谁看：研究模型评估、自动校验、人工复核分配，以及高可靠问答系统的团队。

试试看

阅读论文时同时看校准误差与区分正误的指标；可以先在自有题库记录答题前后置信度，检查它是否真的帮助挑出值得复核的答案。

注意点

改善来自特定训练和基准，不代表任意模型报出的百分数可信。作者尚未验证据此自动检索、求助或弃答的效果，置信度升降也不是正误结论。

07i14与AWS美国2026-10-20 发布2026-10-21 观察官方一手来源

线性注意力把会话状态固定在小内存里

发生了什么：AWS与i14于10月20日介绍Laplace 3B在Trainium2上的训练和服务实现。模型用门控线性注意力把历史压入固定状态，每条序列约29.5MB，不随上下文增长；实现保留Muon优化器，通过原生PyTorch改写内核与通信方式。

为什么值得关注：更长对话通常会吃掉更多缓存，限制并发。固定状态提供另一种成本结构，但压缩历史也意味着信息取舍；应把记忆质量和部署吞吐一起比较，而不是只看节省多少内存。

适合谁看：研究长上下文、推理服务成本，以及尝试非标准注意力架构的工程师。

试试看

沿原文查看内核分块、优化器通信与编译限制，再选择需要反复找回早期细节的任务，比较固定状态方案与现有模型的检索质量。

注意点

29.5MB指每条序列的循环状态，不是整个模型内存。吞吐数字来自指定Trainium2配置；固定状态不等于无损无限记忆，也不代表所有任务更快。

本期观察：今天值得区分三件事：输入能否复用，过程能否恢复，外部动作是否真正完成。缓存、执行记录与连接各有作用，但没有一项能单独包办其余两项。
