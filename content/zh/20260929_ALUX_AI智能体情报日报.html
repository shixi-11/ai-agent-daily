RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

01Claude Sonnet 5.5美国发布于2026-09-28 / 观察于2026-09-29一手资料

Sonnet 5.5把重点放在任务效率

发生了什么：Anthropic发布Sonnet 5.5，已接入Claude、API及主要云平台。厂商称它在编码、视觉和知识工作中更快，并通过减少输出令部分任务成本下降。每百万输入与输出令牌仍分别为2美元、10美元，降的是特定任务用量，而非标价。

为什么值得关注：同一预算下能完成多少工作，比单项榜单更贴近使用体验。已有Sonnet流程可以对照成功率、延迟和总账单，判断升级是否真正合算。

适合谁看：使用Claude Code、建设办公助手，以及负责模型选型和费用管理的团队。

试试看

用一组现有编码或文档任务对照旧版本；API模型名为claude-sonnet-5-5，并检查默认思考强度是否一致。

注意点

速度和节省幅度来自厂商测试，不能视为所有任务的保证；原来关闭思考的API调用需要按新版要求迁移。

02Holo4法国发布于2026-09-28 / 观察于2026-09-29权重许可 27B: CC-BY-NC-4.0; 35B-A3B: Apache-2.0一手资料

Holo4把桌面操作接上代码工具

发生了什么：H Company发布Holo4，包含27B稠密版和35B-A3B混合专家版，提供API与可下载权重。它把桌面、网页及Android界面操作与代码、MCP和API组合起来，同时公开任务轨迹，让读者能查看模型如何完成多步骤操作。

为什么值得关注：电脑操作模型的价值不只在点击准确率。能否在界面和代码之间切换，以及失败过程能否回看，决定它适不适合进入真实的软件工作流。

适合谁看：开发电脑操作助手、测试自动化和桌面应用代理，以及研究操作轨迹的团队。

试试看

先打开官方轨迹查看器，观察FreeCAD或Godot任务如何切换工具；再按设备资源选择API或对应权重。

注意点

27B采用CC-BY-NC-4.0，35B-A3B采用Apache-2.0，商业条件不同；基准结果仍受任务集与运行框架影响。

03Shopify Checkout WebMCP加拿大公告报道于2026-09-28 / 观察于2026-09-29一手资料

Shopify为浏览器助手开放结账工具

发生了什么：Shopify的Checkout WebMCP让浏览器助手读取、更新并完成符合条件的结账流程，买家与助手使用同一浏览器会话中的状态。文档列出get_checkout、update_checkout和complete_checkout；提交订单前必须取得买家明确确认，登录与支付验证仍交给本人。

为什么值得关注：购物助手不必仅靠看图找按钮，但也没有因此获得无限支付权限。共享会话、结构化工具和买家确认共同决定了交易边界，值得电商团队逐项测试。

适合谁看：开发购物助手、维护Shopify商店，或设计浏览器内支付交互的产品与工程团队。

试试看

从官方结账文档检查浏览器支持、代理注册与签名要求；在测试商店走一次修改订单、人工验证和最终确认流程。

注意点

这不是所有浏览器和商店立即通用的接口；适用结账页面、浏览器能力及代理认证条件都要满足，不能跳过买家确认。

05Nibia Fabric全球发布于2026-09-27 / 观察于2026-09-29GitHub Stars 1许可证 Apache-2.0一手资料

Nibia把闲置电脑连成推理集群

发生了什么：Nibia Fabric发布v0.7.0-alpha，尝试把可信局域网内的Mac、Linux和Windows电脑接成分布式GGUF推理系统。主节点提供网页界面和兼容OpenAI的接口，工作节点参与计算；项目还提供Apple Silicon上的本地Metal路径，代码采用Apache-2.0。

为什么值得关注：家里几台内存不大的电脑可能形成新的实验资源，但网络传输也会抵消收益。它提供的是真实可研究的跨设备方案，不是把分散内存变成同一块高速显存。

适合谁看：拥有多台闲置电脑、研究本地模型部署，或想比较分布式与单机推理的开发者。

试试看

按发行页选择系统版本，先在可信局域网连接少量节点，用同一GGUF模型对照单机延迟、稳定性和内存占用。

注意点

当前是实验性Alpha；跨机通信成本与设备组合都会影响结果。不要把总内存相加当作速度保证，先用非敏感样本测试。

08NVIDIA Open Agent Safety美国发布于2026-09-28 / 观察于2026-09-29一手资料

NVIDIA把Agent监控放到运行时之外

发生了什么：NVIDIA发布Open Agent Safety平台，把OpenShell安全运行时与持续监控方案相连。Sentry参考设计使用BlueField-4 DPU，在Agent所在计算环境之外执行监控和隔离；OpenShell已广泛可用，但参考硬件方案不等于所有组件都已成为可即买即用的产品。

为什么值得关注：让执行者同时负责监督自己，容易留下盲点。独立监控路径把安全从提示词扩展到基础设施，不过策略是否有效、隔离是否完整，仍要靠实际部署验证。

适合谁看：运行长期Agent任务、管理企业算力，以及负责基础设施隔离和审计的团队。

试试看

先读官方架构说明，区分可部署的OpenShell软件与Sentry硬件参考设计，再用受控工具调用验证策略和审计记录。

注意点

厂商所称毫秒级隔离不是本刊实测；BlueField硬件路径、软件运行时及第三方处理器支持不能混为同一种部署条件。

适合谁看：关注世界模型、机器人和图形计算路线，以及跟踪芯片产业竞争的研究与投资团队。

试试看

阅读World Labs原始公告，把交割时间、团队安排与未来产品承诺分开；后续重点看公开模型、工具和硬件适配的变化。

注意点

目前是签署协议而非收购完成；本期不把媒体估值当公司已确认金额，也不把未来整合目标写成已交付能力。
