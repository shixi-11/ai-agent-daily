RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

03QuireGlobal open source2026-09-07 发布 / 2026-09-08 观察官方开源发布GitHub Stars 0许可证 AGPL-3.0

为什么值得关注：知识工作最怕出现两份真相：人看编辑器，Agent 改另一份缓存。文件系统作为共同底座，让协作、版本控制和后续自动化回到同一对象上。

注意点

项目处于公开测试阶段，代码采用 AGPL-3.0；“本地优先”不代表所有外接模型都离线运行，生产数据仍需核对所用模型通道。

04KeyclaspGlobal open source2026-09-07 发布 / 2026-09-08 观察官方开源发布GitHub Stars 2许可证未声明

Keyclasp 只把密钥名交给 Agent

发生了什么：Keyclasp v0.2.0 beta 提供本地加密密钥库：Agent 在命令中只引用密钥名称，工具在启动子进程时注入指定值，减少秘密直接出现在提示词和命令文本中的机会。

为什么值得关注：Agent 需要调用真实服务，却不该把凭据变成可复制的上下文。名称引用与执行时注入能缩小暴露面，也把授权动作变成更清楚的审计节点。

适合谁看：开发 Agent、自动化平台、内部工具和凭据治理团队。

试试看

用无价值测试密钥执行一条子命令，检查终端历史、进程参数、错误输出和日志中是否出现明文，再验证撤销后的失败行为。

注意点

项目明确警告：被启动的子进程仍会取得真实秘密，恶意程序可以外泄；它不是沙箱，也不提供操作系统用户隔离。当前版本仍是 beta。

注意点
