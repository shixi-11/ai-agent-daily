RISC机器说明

RISC = 生产级 Agent / 机器人身体的四个系统

一个真正能上生产的 Agent，不能只有大脑。它还要持续行动、扛住故障、抵御越权，并进入真实组织协作。

行业已经交付了一颗出色的大脑，但生产级 Agent 还需要机体、免疫和社会。ALUX 构建的，就是这台完整机器。
R｜强韧 / 机体持久执行、容错、恢复与水平扩展。身体站不住，一次故障就会把工作清空。
I｜智能 / 大脑模型循环、记忆、工具与编排。它决定 Agent 如何思考、调用和完成复杂工作。
S｜安全 / 免疫能力对象、策略审批、回滚与审计。没有免疫，恢复与连接会扩大失控半径。
C｜连接 / 社会跨公司授权、中立基底、会话类型与生态连接。没有社会接口，Agent 只能停在单一产品里。

04Mantid全球2026-10-24 公开展示2026-10-25 观察作者一手来源

Mantid把本地训练变成数据问答流程

发生了什么：Mantid公开展示面向Apple Silicon的本地训练应用：导入表格或文档后，软件建议可回答的问题，再训练预测模型或定制语言模型。它会把结果与简单基线比较，保留版本，并提供模型导出和本地MCP入口；官网提供免费下载。

为什么值得关注：门槛降低的重点不只是省去训练命令，而是先问数据能否支撑问题，再检查模型有没有胜过简单猜测。这能帮助小团队识别不值得部署的模型，避免把复杂度误当成收益。

适合谁看：拥有业务表格、想尝试本地预测但不熟悉机器学习工具链的小团队。

试试看

用去标识的样例数据测试一个明确目标，保留未参与训练的样本，并核对简单基线、错误分布与版本回退是否可用。

注意点

官网要求配备M1或更新芯片的Mac、macOS 14或更高版本；普通模型需8GB内存，语言模型需16GB。数据本地处理是厂商陈述，匿名使用统计默认开启。

微软开放千个Agent自行协作的实验框架

发生了什么：微软于10月24日开放Agensh框架、实验启动脚本与复现指南。Agent通过共享代码仓库、消息和上下文认领任务、检查结果并异步合并，不设中央编排器。研究展示最多1024个Agent协作，但主要平均成绩来自五项任务的一至128个Agent对照。

注意点

公布成绩限定于特定模型、六小时预算和无互联网实验。千个Agent的示例不代表所有任务的平均收益，也不是成本不变。
