RISC 機器說明

RISC = 生產級 Agent / 機器人身體的四個系統

一個真正能上生產的 Agent，不能只有大腦。它要能持續執行，要能判斷和行動，要能抵禦錯誤、攻擊和投毒，也要能進入真實世界的協作網路。

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體容錯、持久執行、故障切換、水平擴充套件。沒有強韌機體，一次崩潰就會帶走全部工作。
I｜智慧 / 大腦推理迴圈、記憶、工具呼叫、任務編排。這是今天所有 Agent 框架最擁擠、也最成熟的競爭層。

C｜連線 / 社會跨公司授權、中立基底、會話型別、協作邊界。沒有連線網路，每家公司的 Agent 都只能困在自己的孤島裡。

發生了什麼：公開文件明確 AgentID 與 ModelScope 解耦，ModelScope 只是 live reference IdP。Agent 本地持有 Ed25519 私鑰，向 IdP 換取短期 JWT；Connected App 根據 iss、aud、exp 與 JWKS 本地驗籤。client/service SDK 已實現 Layer 0 身份與驗證。

可行動建議與產出物：建議形成 AgentID → ALUX Capability Issuance v0，定義 subject、issuer、audience、expiry、capability scope、attenuation、revocation 與 replay binding。 可沉澱為：AgentID → ALUX Capability Issuance v0。

RISC：C 主 · 連線 / 社會S 輔 · 安全 / 免疫

這條訊息主要動到機器人的連線/社會：provider-neutral 身份讓不同 Agent、IdP 與服務擁有共同識別介面；安全/免疫為次維度，因為身份驗證仍需繼續對映為最小許可權。

跨公司委派否協議支援不同 IdP 與服務驗證 Agent 身份，但官方明確審批委派仍未實現。
中立基底否文件明確 provider-neutral，ModelScope 只是參考 IdP；協議仍未證明無單一掌控者的中立執行。
合作/學習視窗

這是中國開源身份生態中最直接的合作視窗之一，可連線 ModelScope、AgentScope 與企業身份團隊。 學習本地金鑰、短期令牌、JWKS 驗籤和 provider-neutral 協議的開發者入口。

風險邊界

本次是公開文件校準而非新版本釋出；官方明確活動上報與審批委派仍屬後續能力，不能寫成已交付完整授權、追蹤或跨公司治理。
