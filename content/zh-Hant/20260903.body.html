RISC機器說明

RISC = 生產級 Agent / 機器人身體的四個系統

一個真正能上生產的 Agent，不能只有大腦。它還要持續行動、扛住故障、抵禦越權，並進入真實組織協作。

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體持久執行、容錯、恢復與水平擴充套件。身體站不住，一次故障就會把工作清空。
I｜智慧 / 大腦模型迴圈、記憶、工具與編排。它決定 Agent 如何思考、呼叫和完成複雜工作。
S｜安全 / 免疫能力物件、策略審批、回滾與審計。沒有免疫，恢復與連線會擴大失控半徑。
C｜連線 / 社會跨公司授權、中立基底、會話型別與生態連線。沒有社會介面，Agent 只能停在單一產品裡。

Claude Code 把組織級 MCP 寫進託管策略

發生了什麼：Claude Code 2.1.259 新增 managedMcpServers，讓組織統一下發 HTTP 與 SSE MCP 服務；無人工值守時可自動拒絕許可權提示。版本還修復併發會話互相覆蓋專案狀態、後臺 Agent 未真正停止，以及託管設定解析失敗後未封閉的問題。

為什麼值得關注：工具接入、無人值守審批和配置失敗開始進入同一控制面，組織可以減少客戶端各自漂移的許可權狀態。

適合誰看：集中管理 Claude Code、MCP 服務和後臺 Agent 的企業團隊。

試試看

在測試組織下發一個只讀 HTTP MCP 服務，開啟無人值守拒絕模式，再併發啟動兩個會話核對配置與停止行為。

注意點

託管 MCP 只接受 HTTP 與 SSE，不會執行命令型條目；客戶端策略也不能替代服務端鑑權、網路隔離與審計。

05Agno美國 / 全球 Agent 工程2026-09-01 釋出 / 2026-09-03 觀察官方開源釋出GitHub Stars 42,018許可證 Apache-2.0

Agno 3.0.5 不再把嵌入失敗偽裝成成功

發生了什麼：Agno 3.0.5 為嵌入過程加入明確的 failed 與 partial 狀態，並提供 EmbeddingError、可選重試和失敗內容再攝取。重新攝取時先生成新嵌入，再替換已有分塊，避免失敗期間把原本可檢索的內容清空。

為什麼值得關注：知識攝取的部分失敗終於成為可觀察狀態，檢索系統也能在更新失敗時保留上一份可用索引。

適合誰看：維護 RAG、知識庫攝取、向量索引和 Agent 資料管線的團隊。

試試看

讓嵌入服務在批處理中途失敗，確認任務標為 partial，舊分塊仍可檢索，並驗證重試後替換順序。

注意點

失敗狀態不等於資料自動一致；併發寫入、外部向量庫事務和重複重試的冪等性仍需按部署環境驗證。
