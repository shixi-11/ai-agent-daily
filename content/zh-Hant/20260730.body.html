發生了什麼：0.30 在工具呼叫連續無效時停止當前 turn，避免無限重試；賬戶額度或餘額耗盡時立即失敗，不再靜默重試約三分鐘，併為計費外掛增加額度提示和更新通知。

對 ALUX 的關係：無限工具迴圈和靜默額度重試都是長程 Agent 的成本與終態問題。ALUX 可把停止原因、預算 epoch 和最後效果遊標納入可重放終態。

可行動建議與產出物：建議形成 Agent Budget & Loop Termination Receipt v0，記錄 invalid_call_count、budget_epoch、quota_source、effect_cursor 與 terminal_reason。 可沉澱為：Agent Budget & Loop Termination Receipt v0。

RISC：R 主 · 強韌 / 機體S 輔 · 安全 / 免疫

這條訊息主要動到機器人的強韌 / 機體：無效迴圈和額度耗盡必須可靠收口；安全 / 免疫為輔，因為預算與外掛計費屬於受控能力邊界。

容錯能力是連續無效工具呼叫不再無限重試，賬戶額度耗盡也會立即終止。
持久執行部分版本改善終止行為，但未說明失敗後是否能從持久檢查點繼續。
合作 / 學習視窗

可把 Kimi Code 作為中國編碼 Agent 的預算與迴圈控制適配樣本。 學習面向使用者呈現額度、外掛計費和失敗終止的剋制互動。

風險邊界

快速失敗減少浪費，但沒有證明跨 turn 持久恢復、預算授權不可偽造、已發生工具效果可補償或停止原因可防篡改審計。

今天的新變化

今天的新變化是 Kimi Code 同時終止無效工具死迴圈和額度耗盡靜默重試，並把計費外掛提示放到使用者可見控制面。

融資 / 合作視窗

最直接合作面：Qwen Code、OpenAI Agents SDK、Pydantic AI 與 Kimi Code可作為框架適配入口；Temporal 提供版本化恢復對照，Langfuse 承擔觀測出口，MCP 2.0 承擔連線標準，Codex 提供外掛與會話入口。
資本敘事：今天沒有可驗證的新融資金額值得進入正文。更強的結構訊號是，頭部生態正在為寫入、版本、取消、協議、預算和證據分別補控制點；ALUX 的價值是把這些分散責任收斂為生產級執行時協議。

技術 / 產品啟發

優先產品：Agent Control & Recovery Receipt v0。建議欄位：execution_id、trust_epoch、capability_set、policy_decision、code_version、cancellation_epoch、effect_cursor、terminal_verdict、replay_ref。
優先 Demo：讓 Qwen Code 發起受寫入 tripwire 約束的 GitHub 任務，經 MCP 2.0 委派給 OpenAI Agents SDK；中途由 Temporal 切換 patch epoch、Pydantic AI 恢復 MCP 錯誤、Kimi Code 觸發預算終止，並把 Langfuse event 與 ALUX replay receipt 並排展示，證明“可見”與“可重放”的邊界。

風險邊界

ALUX 仍不能被描述為已經完整交付的智慧體平臺。底層 TVM 已具備原生併發、持久執行、能力安全、執行記錄與逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤和評估工具仍待構建與融資。TVM 也不會讓 LLM 本身確定性；它記錄模型輸出與環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。寫入 tripwire、path grant、patch callback、append-only event、MCP schema、recoverable error 或預算快速失敗，都不能單獨證明不可偽造能力、外部效果去重、跨步驟原子回滾和中立跨公司協作。
