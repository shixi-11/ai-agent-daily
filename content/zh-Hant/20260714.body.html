RISC = 生產級 Agent / 機器人身體的四個系統

行業已經交付了一顆出色的大腦，但生產級 Agent 還需要機體、免疫和社會。ALUX 構建的，就是這臺完整機器。
R｜強韌 / 機體容錯、持久執行、故障切換、水平擴充套件。沒有強韌機體，一次崩潰就會帶走全部工作。

C｜連線 / 社會跨公司授權、中立基底、會話型別、協作邊界。沒有連線網路，每家公司的 Agent 都只能困在自己的孤島裡。

7 月 13 日首次出現覆蓋 31 家企業的智慧體個人資訊保護行業公約。

融資 / 合作視窗

最直接視窗：MCP runtime、瀏覽器 Agent、開源編碼 Agent、裝置 Agent、隱私與身份治理團隊。共同問題是恢復之後如何證明“仍是同一許可權、同一會話、同一責任主體”。
融資敘事視窗：Cloudflare、Qwen、Stagehand 與 Deep Agents 已把恢復和策略做進產品；ALUX 的差異應落在不可繞過的能力物件、可重放長交易與未來跨公司中立協作。

技術 / 產品啟發

優先產品：MCP Capability Recovery Trace v0。欄位包括 protocolRevision、authState、capabilityAdvertisement、handlerSet、checkpoint、resumeHandshake、approval、toolLog 與 replayVerdict。
優先 Demo：讓 Agent 在 OAuth 尚未完成時休眠，恢復後重新握手並收縮一項工具能力；展示 ALUX 如何拒絕錯誤 ready、保留審批、繼續執行並重放整條長交易。

風險邊界

ALUX 不能被說成已經完整交付智慧體平臺。準確說，當前底層 TVM 已具備併發、持久化執行、能力安全、執行記錄和逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤與評估工具仍是待構建和融資重點。

也不要說 TVM 讓 LLM 本身確定性。準確說，TVM 記錄模型輸出和執行環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。Cloudflare、Qwen、Stagehand 和 Deep Agents 的公開來源證明的是各自產品層能力，不等於已經交付跨公司中立執行時；階躍與行業公約的技術實施細則仍需繼續核實。
