適合作為 ALUX 子 Agent 委派收據和成本歸屬 Demo 的前端入口。 可學習型別化 child conversation action 與 per-run cost export 的產品表達。

風險邊界

Activity Log 和成本匯出不等於防篡改審計，型別化動作也未證明跨公司能力衰減或中立執行。

今天的新變化

今天的新變化是，OpenHands 用型別化動作顯式啟動子會話，並把單次執行成本納入可匯出的活動記錄。

融資 / 合作視窗

最直接合作面：Claude Code、Strands 與 OpenHands 是會話交接對照；Qwen Code 與 Google ADK 是信任和執行前審批入口；Pydantic AI、CrewAI 是執行時適配面；LiteLLM 是多模型閘道器與可信製品入口。
資本敘事：今天沒有可驗證的新融資金額值得進入正文。更有價值的結構訊號是，頭部 Agent 工具正在為執行位置、會話型別、工具顯露、取消、恢復、審批、製品和成本分別補責任欄位；ALUX 的位置是把這些欄位合成可重放、可審計的生產級執行時協議。

技術 / 產品啟發

優先產品：Cross-Surface Session Handoff Envelope v0。建議欄位：handoff_id、parent_session、child_session、sender、recipient、execution_location、capability_set、artifact_digest、checkpoint_ref、effect_cursor、acceptance_verdict、replay_ref。
優先 Demo：從 Claude Code 或 OpenHands 發起一個自託管子會話，經 Qwen Code 工作區信任和 Google ADK 執行前審批進入工具層；Pydantic AI 控制工具顯露與取消，Strands 快照負責中斷續跑，LiteLLM 驗證閘道器製品，CrewAI 提供獨立 runtime context；最終由 ALUX receipt 證明交接狀態與外部效果。

風險邊界

ALUX 仍不能被描述為已經完整交付的智慧體平臺。底層 TVM 已具備原生併發、持久執行、能力安全、執行記錄與逐位元重放審計等關鍵基礎；智慧體產品層、可觀測性、儀表盤、追蹤和評估工具仍待構建與融資。TVM 不會讓 LLM 本身確定性；它記錄模型輸出與環境輸入，使編排、許可權、狀態轉移和審計可重放、可驗證。自託管 runner、工作區信任、框架級取消、會話快照、工具確認、映象簽名、執行時上下文拆分和 Activity Log，都不能單獨證明跨步驟原子回滾、不可偽造能力、外部效果冪等或中立跨公司協作。
